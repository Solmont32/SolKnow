# 量化交易数学基础

量化交易的本质是将市场行为数学化，本节涵盖量化策略开发所需的核心数学工具。

## 内容概览

### 1. 时间序列分析
- 平稳性与单位根检验
- ARIMA/GARCH 模型
- 协整与误差修正模型
- 格兰杰因果检验

### 2. 随机过程
- 布朗运动与几何布朗运动
- 伊藤引理与随机微分方程
- 跳跃扩散模型
- 马尔可夫过程

### 3. 统计套利
- 均值回归与趋势跟踪
- 配对交易策略
- 协整关系检验（Engle-Granger, Johansen）

### 4. 优化理论
- 马科维茨均值-方差模型
- 带约束的投资组合优化
- Black-Litterman 模型
- 风险平价与因子配置

### 5. 数值方法
- 蒙特卡洛模拟
- 有限差分法
- 快速傅里叶变换（FFT）在期权定价中的应用

## 数学符号约定

| 符号 | 含义 |
|------|------|
| $S_t$ | t时刻资产价格 |
| $r_t$ | t时刻收益率，$r_t = \ln(S_t/S_{t-1})$ |
| $\mu$ | 期望收益率 |
| $\sigma$ | 波动率（标准差） |
| $\rho$ | 相关系数 |
| $\Sigma$ | 协方差矩阵 |
