# 实数 (Real Numbers)

实数系统是整个数学分析的数域基础。

## 分类
- **有理数 ($\mathbb{Q}$)**：可表示为两个整数之比的数。
- **无理数**：无限不循环小数，如 $\sqrt{2}, \pi, e$。

## 绝对值与性质
$$|a| = \begin{cases} a & a \ge 0 \\ -a & a < 0 \end{cases}$$
- **非负性**：$|a| \ge 0$。
- **三角不等式**：$|a + b| \le |a| + |b|$。

<KnowledgeCard type="info" title="连续性">
实数集具有 **完备性**（或称连续性），这意味着数轴上的点与实数是一一对应的，没有“空隙”。
</KnowledgeCard>
