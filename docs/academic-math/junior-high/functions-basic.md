# 函数基础 (Functions Basics)

## 概念
变量间的对应关系。

## 一次函数
形式：$y = kx + b$ ($k \ne 0$)。
- 图像是一条直线。
- $k$ 为斜率，$b$ 为截距。

## 反比例函数
形式：$y = \frac{k}{x}$ ($k \ne 0$)。
- 图像是双曲线。

## 二次函数 (初中版)
形式：$y = ax^2 + bx + c$ ($a \ne 0$)。
- 图像是抛物线。
- 顶点公式：$(-\frac{b}{2a}, \frac{4ac-b^2}{4a})$。
