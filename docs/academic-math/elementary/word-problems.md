# 应用题 (Word Problems)

应用题考察将实际问题抽象为数学模型的能力。

## 典型题型

1.  **行程问题**：路程 = 速度 $\times$ 时间。
    - 追及问题、相遇问题。
2.  **工程问题**：工作总量 = 工作效率 $\times$ 工作时间。
    - 常设工作总量为“1”。
3.  **利润问题**：利润 = 售价 - 成本。

<KnowledgeCard type="tip" title="建模思路">
1. **审题**：理清已知量与未知量。
2. **设元**：灵活设置未知数。
3. **列式**：寻找等量关系。
4. **求解并检验**。
