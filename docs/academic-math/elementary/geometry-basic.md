# 基础几何 (Basic Geometry)

## 平面图形
- **正方形**：四条边相等，四个角都是直角。周长=$4a$，面积=$a^2$。
- **长方形**：对边相等，四个角都是直角。周长=$2(a+b)$，面积=$ab$。
- **三角形**：三条边组成的封闭图形。面积=$\frac{1}{2} \times \text{底} \times \text{高}$。
- **圆**：平面上到定点距离等于定长的点的集合。周长=$2\pi r$，面积=$\pi r^2$。

## 立体图形
- **长方体**：体积=$V = abc$。
- **球体**：体积=$V = \frac{4}{3}\pi r^3$。
- **圆柱体**：体积=$V = \pi r^2 h$。
