# 算术基础 (Arithmetic)

## 整数运算
- **加、减、乘、除**。
- **四则混合运算顺序**：先乘除，后加减；有括号先算括号。

## 运算定律
- **交换律**：$a + b = b + a$, $a \times b = b \times a$。
- **结合律**：$(a + b) + c = a + (b + c)$。
- **分配律**：$a \times (b + c) = a \times b + a \times c$。

## 因数与倍数
- **质数与合数**。
- **最大公因数与最小公倍数**。
