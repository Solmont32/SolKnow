# 算术基础 (Arithmetic)

## 四则运算

- 加、减、乘、除的基本运算法则。
- **运算律**：交换律、结合律、分配律。

## 整数的性质

- **奇数与偶数**。
- **质数 (Prime) 与合数**：
  - 质数是只能被 1 和自身整除的自然数（大于 1）。
  - **算术基本定理**：每个大于 1 的自然数都可以唯一地分解为质数的乘积。

<KnowledgeCard type="info" title="最大公约数与最小公倍数">
- **GCD**: 两数公有的最大约数。
- **LCM**: 两数公有的最小倍数。
关系：$a \times b = GCD(a, b) \times LCM(a, b)$。
