# 奥数应用题：数学建模的艺术

应用题的核心在于将复杂的文字描述抽象为简洁的数学等式。

## 一、 核心知识点讲解

### 1. 鸡兔同笼模型
-   **基本思路**：假设法。
-   **核心公式**：
    -   假设全是兔：$鸡数 = (兔脚数 \times 总头数 - 总脚数) \div (兔脚数 - 鸡脚数)$
    -   假设全是鸡：$兔数 = (总脚数 - 鸡脚数 \times 总头数) \div (兔脚数 - 鸡脚数)$

### 2. 行程问题（速度、时间、路程）
-   **相遇问题**：$路程和 = 速度和 \times 相遇时间$
-   **追及问题**：$路程差 = 速度差 \times 追及时间$
-   **流水行船**：
    -   $顺流速度 = 船速 + 水速$
    -   $逆流速度 = 船速 - 水速$

### 3. 工程问题
-   **核心公式**：$工作总量 = 工作效率 \times 工作时间$
-   **技巧**：通常设工作总量为“1”，将效率表示为时间的倒数。

## 二、 经典例题实战

### 例题 1：鸡兔同笼的变体
笼子里有鸡和兔共 $30$ 只，脚共有 $88$ 只。鸡和兔各有多少只？

<details>
<summary>点击查看解析与答案</summary>

#### 解析过程
1.  **假设法**：假设全是鸡。
2.  **脚数差**：如果是 $30$ 只鸡，应该有 $30 \times 2 = 60$ 只脚。
3.  **寻找差距**：实际有 $88$ 只脚，比假设多了 $88 - 60 = 28$ 只脚。
4.  **替换逻辑**：每把一只鸡换成一只兔，脚数增加 $4 - 2 = 2$ 只。
5.  **计算兔数**：$28 \div 2 = 14$ 只兔。
6.  **计算鸡数**：$30 - 14 = 16$ 只鸡。

#### 答案
鸡 16 只，兔 14 只。
</details>

### 例题 2：流水行船问题
一艘船在静水中的速度是每小时 $20$ 千米，水流速度是每小时 $4$ 千米。这艘船在甲、乙两码头之间往返一次，顺流用了 $3$ 小时。求逆流需要多少小时？

<details>
<summary>点击查看解析与答案</summary>

#### 解析过程
1.  **求顺流速度**：$20 + 4 = 24$（千米/小时）。
2.  **求全程路程**：$24 \times 3 = 72$（千米）。
3.  **求逆流速度**：$20 - 4 = 16$（千米/小时）。
4.  **求逆流时间**：$72 \div 16 = 4.5$（小时）。

#### 答案
4.5 小时。
</details>

### 例题 3：工程问题的合作效率
一项工程，甲单独做需要 $10$ 天完成，乙单独做需要 $15$ 天完成。两人合作，多少天可以完成这项工程？

<details>
<summary>点击查看解析与答案</summary>

#### 解析过程
1.  **设总量**：设工作总量为 $1$。
2.  **求效率**：甲的效率是 $\frac{1}{10}$，乙的效率是 $\frac{1}{15}$。
3.  **求合作效率**：$\frac{1}{10} + \frac{1}{15} = \frac{3}{30} + \frac{2}{30} = \frac{5}{30} = \frac{1}{6}$。
4.  **求合作时间**：$1 \div \frac{1}{6} = 6$（天）。

#### 答案
6 天。
</details>
