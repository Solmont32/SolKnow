# 小学奥数 (Elementary Math Olympiad)

小学奥数是训练逻辑表达、建模能力和多路径解题意识的关键阶段。

## 学习路径（对标教材）
1. **数论基础**：整除、余数、质因数分解。
2. **计数方法**：分类讨论、分步计数、抽屉原理。
3. **逻辑推理**：列表法、假设法、排除法、逆向验证。
4. **几何模型**：等积变换、比例关系、割补思想。
5. **代数技巧**：巧算、等差数列、裂项求和。
6. **应用题建模**：和差倍、鸡兔同笼、行程、工程。

## 推荐学习顺序
- 第一轮：先完成 `数论 -> 计数 -> 逻辑` 三个主线章节。
- 第二轮：将每章例题重做一遍并口述“为什么这样列式”。
- 第三轮：进入练习库做分层训练并复盘错题。
