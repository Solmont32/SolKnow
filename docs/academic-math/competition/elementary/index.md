# 小学奥数 (Elementary Math Olympiad)

小学奥数是培养逻辑思维和数学兴趣的关键阶段。

## 核心模块
1.  **数论基础**：奇偶性、质数合数、整除特征。
2.  **计数问题**：加法原理、乘法原理、枚举法。
3.  **应用题**：鸡兔同笼、盈亏问题、牛吃草问题。
4.  **几何初阶**：面积模型（蝴蝶模型、燕尾模型）。

<KnowledgeCard type="info" title="学习建议">
奥数不是为了死记硬背公式，而是为了理解“为什么”。每一个巧妙的解法背后都是严谨的逻辑推导。
</KnowledgeCard>
