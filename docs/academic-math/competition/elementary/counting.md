# 奥数计数：排列组合与枚举

计数问题是奥数中最具思维挑战性的板块之一。

## 1. 基础原理
- **加法原理**：分类计数。
- **乘法原理**：分步计数。

## 2. 常用模型
- **插板法**：解决相同元素分配问题。
- **排除法**：从总量中减去不符合条件的。

---

## 典型例题

### 例题 1：插板法的应用
将 $10$ 个完全相同的苹果分给 $3$ 个小朋友，每人至少分到一个，共有多少种分法？

<details>
<summary>点击查看解析与答案</summary>

#### 解析
1. **模型转化**：$10$ 个苹果排成一排，中间有 $9$ 个空隙。
2. **操作**：从中插入 $2$ 块板，即可将苹果分为 $3$ 份。
3. **计算**：即从 $9$ 个位置中选出 $2$ 个，分法数为 $C(9, 2)$。
4. **结果**：$C(9, 2) = (9 \times 8) / 2 = 36$。

#### 答案
$36$
