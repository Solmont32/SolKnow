# 奥数计数与组合：逻辑与秩序的艺术

组合板块研究的是“有多少种可能”，核心在于分类要 **“不重不漏”**。

## 一、 核心知识点讲解

### 1. 两大基本原理
-   **加法原理（分类计数）**：完成一件事有 $n$ 类办法，每一类办法都能独立完成这件事。总数 = 每一类方法数之 **和**。
-   **乘法原理（分步计数）**：完成一件事需要分 $n$ 个步骤，缺一不可。总数 = 每一步方法数之 **积**。

### 2. 排列与组合初步
-   **排列**：与顺序有关。从 $n$ 个不同元素中取出 $m$ 个排成一列。
-   **组合**：与顺序无关。从 $n$ 个不同元素中取出 $m$ 个合成一组。

### 3. 抽屉原理 (Pigeonhole Principle)
-   **基本形式**：把 $n+1$ 个苹果放进 $n$ 个抽屉，至少有一个抽屉里至少有 $2$ 个苹果。
-   **一般形式**：把 $kn+1$ 个苹果放进 $n$ 个抽屉，至少有一个抽屉里至少有 $k+1$ 个苹果。

### 4. 容斥原理
-   用于解决有重叠部分的计数问题。
-   **两个集合**：$A \cup B = A + B - A \cap B$。

遗漏的，要加上。

## 二、 经典例题实战

### 例题 1：乘法原理的灵活应用
用 $0, 1, 2, 3$ 这四个数字，可以组成多少个没有重复数字的三位数？

<details>
<summary>点击查看解析与答案</summary>

#### 解析过程
1.  **分步思考**：组成三位数需要选定“百位”、“十位”和“个位”。
2.  **第一步（百位）**：由于最高位不能为 $0$，只能从 $1, 2, 3$ 中选，有 **$3$ 种** 选择。
3.  **第二步（十位）**：从剩下的 $3$ 个数字（包含 $0$）中选，有 **$3$ 种** 选择。
4.  **第三步（个位）**：从剩下的 $2$ 个数字中选，有 **$2$ 种** 选择。
5.  **计算总数**：根据乘法原理，$3 \times 3 \times 2 = 18$。

#### 答案
$18$ 个。
</details>

### 例题 2：抽屉原理的构造
口袋里有红、黄、蓝、白四种颜色的球各 $10$ 个。至少要摸出多少个球，才能保证有 $3$ 个球的颜色相同？

<details>
<summary>点击查看解析与答案</summary>

#### 解析过程
1.  **寻找“最坏情况”**：为了“不保证”，我们要尽可能让每种颜色的球都摸得很多但又达不到 $3$ 个。
2.  **构造最差状态**：每种颜色的球都摸出了 $2$ 个。
    - 红：$2$ 个
    - 黄：$2$ 个
    - 蓝：$2$ 个
    - 白：$2$ 个
    - 此时共摸出了 $2 \times 4 = 8$ 个球，依然没有 $3$ 个同色的。
3.  **达成目标**：再摸出 **$1$ 个** 球，无论是什么颜色，都会使某种颜色的球达到 $3$ 个。
4.  **最终数量**：$8 + 1 = 9$。

#### 答案
$9$ 个。
</details>

### 例题 3：插板法（高阶计数）
将 $7$ 个相同的玩具分给 $3$ 个小朋友，每人至少分到一个，共有多少种分法？

<details>
<summary>点击查看解析与答案</summary>

#### 解析过程
1.  **模型转化**：将 $7$ 个玩具排成一排，中间形成了 $6$ 个空隙。
2.  **放置“隔板”**：我们要把玩具分成 $3$ 份，只需要在 $6$ 个空隙中插入 **$2$ 块** 隔板即可。
3.  **组合计算**：即从 $6$ 个位置中选出 $2$ 个，方法数为 $C(6, 2)$。
4.  **计算结果**：$(6 \times 5) \div 2 = 15$。

#### 答案
$15$ 种。
</details>
