# 奥数几何：五大面积模型

小学奥数几何的核心在于“面积转换”，通过比例关系解决复杂图形问题。

## 1. 等底同高模型
两个三角形底相等、高相等，则面积相等。

## 2. 蝴蝶模型
在梯形（或任意四边形）中，对角线交点形成的四个三角形面积具有特定的比例关系：
- $S_1 : S_2 = S_4 : S_3$
- $S_1 \times S_3 = S_2 \times S_4$

<KnowledgeCard type="info" title="模型直观">
蝴蝶模型常用于将已知的局部面积推导至全局。
</KnowledgeCard>

## 典型例题

### 例题 1：蝴蝶模型的应用
已知梯形 $ABCD$ 的对角线交于点 $O$，三角形 $AOB$ 的面积为 $4$，三角形 $BOC$ 的面积为 $8$。求梯形 $ABCD$ 的总面积。

<details>
<summary>点击查看解析与答案</summary>

#### 解析
1. **利用蝴蝶模型**：设 $S_{AOB} = S_1 = 4$，$S_{BOC} = S_2 = 8$。由于 $AB \parallel CD$，由等底同高可知 $S_{ABD} = S_{ABC}$，扣除公共部分 $S_{AOB}$，得 $S_{AOD} = S_{BOC} = 8$（即 $S_4 = 8$）。
2. **比例关系**：$S_1 : S_2 = S_4 : S_3$，即 $4 : 8 = 8 : S_3$。
3. **计算**：$S_3 = (8 \times 8) / 4 = 16$。
4. **总面积**：$S = S_1 + S_2 + S_3 + S_4 = 4 + 8 + 16 + 8 = 36$。

#### 答案
$36$
</details>
