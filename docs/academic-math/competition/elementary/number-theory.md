# 奥数数论：整除与余数

数论是奥数中逻辑性最强、技巧最丰富的板块。

## 1. 整除特征
- **2, 5**: 看末一位。
- **4, 25**: 看末两位。
- **3, 9**: 看各位数字之和。
- **7, 11, 13**: 割位法或“末三位与前段差”。

## 2. 奇偶性分析
- 奇 + 奇 = 偶，奇 + 偶 = 奇。
- 奇 $\times$ 奇 = 奇，奇 $\times$ 偶 = 偶。

## 典型例题

### 例题 1：整除判定
一个五位数 $24x8y$ 能被 $15$ 整除，求这个五位数的最大值。

<details>
<summary>点击查看解析与答案</summary>

#### 解析
1. **分解条件**：能被 $15$ 整除，意味着既能被 $3$ 整除，也能被 $5$ 整除。
2. **被 5 整除**：末位 $y$ 只能是 $0$ 或 $5$。
3. **被 3 整除**：各位数字之和 $(2+4+x+8+y)$ 是 $3$ 的倍数，即 $14+x+y$ 是 $3$ 的倍数。
4. **最大化**：
   - 若 $y=5$，则 $19+x$ 是 $3$ 的倍数，$x$ 最大为 $8$。五位数为 $24885$。
   - 若 $y=0$，则 $14+x$ 是 $3$ 的倍数，$x$ 最大为 $7$。五位数为 $24780$。
5. **结论**：$24885 > 24780$。

#### 答案
$24885$
</details>

### 例题 2：奇偶性的应用
$7$ 只杯子全部口朝上放在桌上，每次翻转其中 $4$ 只杯子。能否经过若干次操作使杯子全部口朝下？

<details>
<summary>点击查看解析与答案</summary>

#### 解析
1. **状态定义**：设口朝上的杯子为 $1$，口朝下的为 $-1$。
2. **奇偶不变性**：翻转 $4$ 只杯子，口朝上的数量变化量一定是 **偶数**（$4$ 个上变下，或 $2$ 上 $2$ 下，或 $4$ 下变上）。
3. **初始状态**：$7$ 个口朝上（奇数）。
4. **目标状态**：$0$ 个口朝上（偶数）。
5. **结论**：由于每次变化都是偶数，奇数永远无法变成偶数。

#### 答案
不能。
</details>
