# 竞赛几何：近代几何定理与证明

高中几何竞赛（纯几何）强调辅助线的艺术与深层的点线面联系。

## 一、 核心知识点讲解

### 1. 经典比例定理（高阶）
-   **梅涅劳斯定理**：三点共线的判定与长度比例计算。
-   **塞瓦定理**：三线共点的判定。
-   **斯图尔特定理 (Stewart's Theorem)**：计算三角形内任意线段的长度。

### 2. 圆与特殊线
-   **九点圆定理**：任何三角形的垂足、中点及垂心与顶点连线的中点九点共圆。
-   **西姆松线 (Simson Line)**：若点 $P$ 在 $\triangle ABC$ 外接圆上，则 $P$ 对三边的垂足共线。
-   **欧拉线**：外心、重心、垂心三点共线且长度比为 $1:2$。

### 3. 调和分割与极点极线
-   研究射影几何在纯几何证明中的投影不变性。

## 二、 经典例题实战

### 例题 1：斯图尔特定理的应用
在 $\triangle ABC$ 中，$AB=5, AC=7, BC=6$。点 $D$ 在 $BC$ 上且 $BD=2$。求 $AD$ 的长度。

<details>
<summary>点击查看解析与答案</summary>

#### 解析过程
1.  **定理公式**：$man + dad = bmb + cnc$（助记口诀）。标准形式：$a(p^2 + mn) = b^2 m + c^2 n$。
    其中 $a=6, b=7, c=5, n=2, m=4, p=AD$。
2.  **代入数值**：
    $6(AD^2 + 4 \times 2) = 7^2 \times 2 + 5^2 \times 4$
3.  **计算**：
    $6(AD^2 + 8) = 49 \times 2 + 25 \times 4$
    $6(AD^2 + 8) = 98 + 100 = 198$
4.  **求解**：
    $AD^2 + 8 = 33 \implies AD^2 = 25$。
5.  **结果**：$AD = 5$。

#### 答案
$5$
</details>
