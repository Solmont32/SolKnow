# 竞赛代数：高阶因式分解技巧

因式分解是初中竞赛代数的核心功底，是解决不等式和方程组的前提。

## 1. 待定系数法
若已知分解后的项的形式，可通过展开后对应系数相等来求解。

## 2. 轮换对称多项式
利用轮换性（将 $a, b, c$ 互换后表达式不变）来推测因式。
- 例如：$a(b-c)^3 + b(c-a)^3 + c(a-b)^3$。

<KnowledgeCard type="tip" title="技巧">
若 $a=b$ 时原式为 $0$，则 $(a-b)$ 必为原式的一个因式。
</KnowledgeCard>

## 典型例题

### 例题 1：双十字相乘法
分解因式：$2x^2 - 7xy + 3y^2 - 5x + 5y + 2$。

<details>
<summary>点击查看解析与答案</summary>

#### 解析
1. **分解二次项**：$2x^2 - 7xy + 3y^2 = (2x - y)(x - 3y)$。
2. **待定系数**：设原式为 $(2x - y + m)(x - 3y + n)$。
3. **对应一次项系数**：
   - $x$ 的系数：$2n + m = -5$
   - $y$ 的系数：$-3m - n = 5$
4. **解方程组**：解得 $m = -1, n = -2$。
5. **验证常数项**：$m \times n = (-1) \times (-2) = 2$，与原式常数项吻合。

#### 答案
$(2x - y - 1)(x - 3y - 2)$
</details>
