# 竞赛代数：高阶恒等变形与根式

初中竞赛代数的核心在于对“结构”的敏感度，通过变换将复杂式子简单化。

## 一、 核心知识点讲解

### 1. 重要恒等式
-   **平方差与完全平方**：$a^2 - b^2 = (a-b)(a+b)$，$a^2 \pm 2ab + b^2 = (a \pm b)^2$。
-   **立方和差公式**：$a^3 \pm b^3 = (a \pm b)(a^2 \mp ab + b^2)$。
-   **三元完全平方**：$(a+b+c)^2 = a^2+b^2+c^2 + 2(ab+bc+ca)$。
-   **欧拉恒等式**：$a^3+b^3+c^3-3abc = (a+b+c)(a^2+b^2+c^2-ab-bc-ca)$。

### 2. 因式分解高阶技巧
-   **双十字相乘法**：处理二次六项式。
-   **待定系数法**：根据已知结构设出因式，通过对比系数求解。
-   **轮换对称性**：若表达式在 $a, b, c$ 轮换下不变，因式也往往具有对称性。

### 3. 分式与根式
-   **分式拆分**：将复杂分式化为部分分式之和。
-   **根式复合**：形如 $\sqrt{a \pm \sqrt{b}}$ 的化简（构造完全平方式）。

## 二、 经典例题实战

### 例题 1：利用对称性分解因式
分解因式：$a(b-c)^3 + b(c-a)^3 + c(a-b)^3$。

<details>
<summary>点击查看解析与答案</summary>

#### 解析过程
1.  **观察因式**：令 $a=b$，原式变为 $b(b-c)^3 + b(c-b)^3 + c(b-b)^3 = b(b-c)^3 - b(b-c)^3 + 0 = 0$。
2.  **提取因式**：根据因式定理，$(a-b)$ 是原式的因式。同理，$(b-c)$ 和 $(c-a)$ 也是。
3.  **设待定系数**：原式为 4 次式（展开项含 $ab^3$ 等），但 $(a-b)(b-c)(c-a)$ 只有 3 次。注意到原式是轮换对称的，补齐一次项：原式 $= k(a+b+c)(a-b)(b-c)(c-a)$。
4.  **求 k 值**：取 $a=0, b=1, c=2$ 代入原式计算得 $k=1$。

#### 答案
$(a+b+c)(a-b)(b-c)(c-a)$
</details>

### 例题 2：根式的巧妙化简
化简：$\sqrt{7 - 4\sqrt{3}}$。

<details>
<summary>点击查看解析与答案</summary>

#### 解析过程
1.  **构造完全平方式**：设 $\sqrt{7 - 4\sqrt{3}} = \sqrt{(\sqrt{x} - \sqrt{y})^2}$。
2.  **展开对比**：$(\sqrt{x} - \sqrt{y})^2 = x + y - 2\sqrt{xy}$。
3.  **建立方程**：
    -   $x + y = 7$
    -   $2\sqrt{xy} = 4\sqrt{3} \implies \sqrt{xy} = 2\sqrt{3} = \sqrt{12} \implies xy = 12$。
4.  **解方程**：容易看出 $x=4, y=3$（或反之）。
5.  **开方**：$\sqrt{(2 - \sqrt{3})^2} = |2 - \sqrt{3}|$。由于 $2 > \sqrt{3}$，结果为 $2 - \sqrt{3}$。

#### 答案
$2 - \sqrt{3}$
</details>
