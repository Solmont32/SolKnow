# 初中数学竞赛

初中数竞是连接基础教育与高中高阶竞赛的桥梁。

## 重点板块
1.  **代数变形**：因式分解技巧、根式运算。
2.  **数论初步**：同余、整除、不定方程。
3.  **几何证明**：圆的性质、相似三角形的高阶应用。
4.  **组合基础**：抽屉原理、简单的计数问题。

<KnowledgeCard type="info" title="学习要点">
初中数竞非常强调 **运算能力** 和 **逻辑严密性**。建议从《数学竞赛教程》等经典书目入手。
</KnowledgeCard>
