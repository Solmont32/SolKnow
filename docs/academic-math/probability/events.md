# 事件与概率 (Events and Probability)

## 基本定义
- **样本空间 ($\Omega$)**：随机试验所有可能结果的集合。
- **事件 ($A$)**：样本空间的子集。
- **概率 ($P(A)$)**：事件 $A$ 发生的可能性，满足 $0 \le P(A) \le 1$。

## 概率公理
1. 非负性：$P(A) \ge 0$。
2. 规范性：$P(\Omega) = 1$。
3. 可列可加性：若 $A_i$ 两两互不相容，则 $P(\cup A_i) = \sum P(A_i)$。

## 条件概率
$P(A|B) = \frac{P(AB)}{P(B)}$ (当 $P(B) > 0$)。

## 全概率公式与贝叶斯公式
- **全概率**：$P(A) = \sum P(A|B_i) P(B_i)$。
- **贝叶斯**：$P(B_j|A) = \frac{P(A|B_j) P(B_j)}{\sum P(A|B_i) P(B_i)}$。
