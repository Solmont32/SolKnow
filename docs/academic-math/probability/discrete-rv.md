# 绂绘暎鍨嬮殢鏈哄彉閲?(Discrete Random Variables)

## 瀹氫箟
闅忔満鍙橀噺 $X$ 鐨勫彇鍊兼槸鏈夐檺鎴栧彲鍒椾釜銆?

## 鍒嗗竷寰?(Probability Mass Function, PMF)
$P(X = x_i) = p_i$锛屾弧瓒?$\sum p_i = 1$銆?

## 甯歌鍒嗗竷
- **$0-1$ 鍒嗗竷**锛?X \sim B(1, p)$銆?
- **浜岄」鍒嗗竷**锛?P(X=k) = \binom{n}{k} p^k (1-p)^{n-k}$銆?
- **娉婃澗鍒嗗竷**锛?P(X=k) = \frac{\lambda^k e^{-\lambda}}{k!}$銆?

## 鏈熸湜涓庢柟宸?
- **鏈熸湜**锛?E[X] = \sum x_i p_i$銆?
- **鏂瑰樊**锛?Var(X) = E[X^2] - (E[X])^2$銆?
