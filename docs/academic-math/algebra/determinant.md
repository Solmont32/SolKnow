# 行列式 (Determinant)

## 定义
行列式是一个将方阵 $A$ 映射为一个标量的函数，记作 $\det(A)$ 或 $|A|$。

## 性质
- **转置不变性**：$|A| = |A^T|$
- **互换变号**：互换两行（或两列），行列式变号。
- **倍法倍增**：若某行（列）乘以常数 $k$，行列式值也乘以 $k$。
- **累加性**：$|A|$ 可以按行或按列展开。

## 代数余子式
设 $M_{ij}$ 是划去第 $i$ 行和第 $j$ 列后的子式，则代数余子式 $A_{ij} = (-1)^{i+j} M_{ij}$。
按第 $i$ 行展开公式：
$$|A| = \sum_{j=1}^{n} a_{ij} A_{ij}$$

## 克拉默法则 (Cramer's Rule)
用于求解线性方程组 $AX = B$。若 $|A| \ne 0$，则方程组有唯一解。
$x_j = \frac{|A_j|}{|A|}$，其中 $A_j$ 是用 $B$ 替换 $A$ 的第 $j$ 列后的矩阵。
