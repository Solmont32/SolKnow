# 二次型 (Quadratic Forms)

## 定义
变量 $x_1, x_2, \dots, x_n$ 的二次型是一个具有如下形式的多项式：
$f(x_1, \dots, x_n) = \sum_{i,j} a_{ij} x_i x_j$
通常可以写成矩阵形式 $x^T A x$，其中 $A$ 是对称矩阵。

## 标准型与规范型
- **标准型**：只含变量平方项的二次型，即 $d_1 y_1^2 + d_2 y_2^2 + \dots + d_n y_n^2$。
- **规范型**：系数只能是 $1, -1, 0$ 的标准型。

## 正定性 (Definiteness)
- **正定**：对所有非零向量 $x$，$x^T A x > 0$。
- **负定**：对所有非零向量 $x$，$x^T A x < 0$。
- **半正定**：对所有向量 $x$，$x^T A x \ge 0$。
