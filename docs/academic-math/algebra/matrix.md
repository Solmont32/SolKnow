# 矩阵 (Matrix)

## 定义
矩阵是由 $m \times n$ 个数排成的矩形表格。

## 基本运算
- **加法**：同型矩阵对应元素相加。
- **数乘**：常数 $k$ 乘以矩阵的每一个元素。
- **矩阵乘法**：设 $A$ 是 $m \times p$ 矩阵，$B$ 是 $p \times n$ 矩阵，结果 $C = AB$ 是 $m \times n$ 矩阵。
  $$c_{ij} = \sum_{k=1}^p a_{ik}b_{kj}$$

## 特殊矩阵
- **单位矩阵 ($I$)**：主对角线全为 1，其余为 0。
- **逆矩阵 ($A^{-1}$)**：若 $AB = BA = I$，则称 $B$ 为 $A$ 的逆矩阵。
- **转置矩阵 ($A^T$)**：行变列，列变行。

## 矩阵的秩 (Rank)
矩阵中不为零的子式的最大阶数，也是行向量组（或列向量组）的极大线性无关组的大小。
