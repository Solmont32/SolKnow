# 矩阵 (Matrices)

## 定义
矩阵是一个由 $m \times n$ 个数排列成的矩形阵列。

## 矩阵运算
- **加法**：同型矩阵对应元素相加。
- **数乘**：标量乘以矩阵的每个元素。
- **乘法**：$(AB)_{ij} = \sum_k A_{ik} B_{kj}$。

## 特殊矩阵
- **单位矩阵 (Identity Matrix)**：主对角线全为 1，其余为 0。
- **逆矩阵 (Inverse Matrix)**：若 $AB = BA = I$，则 $B$ 是 $A$ 的逆，记作 $A^{-1}$。
- **转置矩阵 (Transpose)**：行列互换。

## 行列式 (Determinant)
一个方阵 $A$ 对应的一个标量，记作 $\det(A)$ 或 $|A|$。
