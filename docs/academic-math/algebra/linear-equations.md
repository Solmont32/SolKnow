# 线性方程组 (Linear Equations)

## 基本形式
$$AX = B$$
其中 $A$ 为系数矩阵，$X$ 为未知数向量，$B$ 为常数项向量。

## 解的判定
- **齐次方程组 ($AX = 0$)**：
  - 总有零解。
  - 若 $r(A) < n$，则有非零解。
- **非齐次方程组 ($AX = B$)**：
  - 若 $r(A) \ne r(A, B)$，则无解。
  - 若 $r(A) = r(A, B) = n$，则有唯一解。
  - 若 $r(A) = r(A, B) < n$，则有无穷多解。

## 求解方法
- **高斯消元法**：通过初等行变换将增广矩阵化为行阶梯形或行最简形。
- **克拉默法则**：适用于系数矩阵为方阵且行列式不为零的情况。
