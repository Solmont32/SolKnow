# 基本初等函数 (Functions)

## 指数函数
$y = a^x$ ($a > 0, a \ne 1$)。
- 过定点 $(0, 1)$。

## 对数函数
$y = \log_a x$ ($a > 0, a \ne 1$)。
- 换底公式：$\log_a b = \frac{\log_c b}{\log_c a}$。

## 幂函数
$y = x^\alpha$。

## 函数的单调性与奇偶性
- **单调性**：增函数与减函数。
- **奇偶性**：
  - 奇函数：$f(-x) = -f(x)$（关于原点对称）。
  - 偶函数：$f(-x) = f(x)$（关于 $y$ 轴对称）。
