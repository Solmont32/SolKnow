# 圆锥曲线 (Conic Sections)

## 椭圆 (Ellipse)
到两定点 $F_1, F_2$ 距离之和为常数 ($2a > 2c$) 的点的轨迹。
方程：$\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$。

## 双曲线 (Hyperbola)
到两定点 $F_1, F_2$ 距离之差的绝对值为常数 ($2a < 2c$) 的点的轨迹。
方程：$\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$。

## 抛物线 (Parabola)
到定点 $F$ 和定直线 $l$ 距离相等的点的轨迹。
方程：$y^2 = 2px$。
