# 圆锥曲线 (Conic Sections)

## 椭圆
标准方程：$\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$ ($a > b > 0$)。
- 离心率：$e = \frac{c}{a}$ ($0 < e < 1$)。

## 双曲线
标准方程：$\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$ ($a, b > 0$)。
- 渐近线：$y = \pm \frac{b}{a} x$。

## 抛物线
标准方程：$y^2 = 2px$。
- 离心率：$e = 1$。
