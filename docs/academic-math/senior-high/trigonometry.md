# 三角函数 (Trigonometry)

## 定义
在直角坐标系中，设角 $\alpha$ 的终边上一点为 $(x, y)$，距原点距离为 $r = \sqrt{x^2 + y^2}$：
- $\sin \alpha = \frac{y}{r}$
- $\cos \alpha = \frac{x}{r}$
- $\tan \alpha = \frac{y}{x}$

## 诱导公式
- $\sin(\pi - \alpha) = \sin \alpha$
- $\cos(\pi - \alpha) = -\cos \alpha$

## 三角恒等变换
- **平方关系**：$\sin^2 \alpha + \cos^2 \alpha = 1$
- **正弦定理**：$\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R$
- **余弦定理**：$a^2 = b^2 + c^2 - 2bc \cos A$
