# 积分 (Integrals)

## 不定积分
如果在区间 $I$ 上 $F'(x) = f(x)$，则称 $F(x)$ 为 $f(x)$ 的一个原函数。$f(x)$ 的全体原函数称为 $f(x)$ 的不定积分：
$\int f(x) dx = F(x) + C$

## 定积分 (Riemann Integral)
定积分表示函数与坐标轴围成的面积。

## 微积分基本定理 (Newton-Leibniz Formula)
如果 $f(x)$ 在 $[a, b]$ 上连续，且 $F(x)$ 是 $f(x)$ 的一个原函数，则：
$\int_a^b f(x) dx = F(b) - F(a)$
