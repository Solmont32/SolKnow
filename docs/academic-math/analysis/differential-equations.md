# 微分方程：探索变化的规律

如果代数方程是寻找一个**未知的数**，那么微分方程就是在寻找一个**未知的函数**。它是通过已知该函数与其导数之间的关系，反推出函数原本面貌的强大学科，在物理建模、种群动力学和经济学中有极广泛的应用。

## 一、 核心概念与一阶方程解法

### 1. 基本概念
- **微分方程**：含有未知函数及其导数（或微分）的方程。
- **阶数**：方程中出现的未知函数的**最高阶导数**的阶数。
- **通解**：含有独立任意常数的解，且任意常数的个数等于微分方程的阶数。
- **特解**：由初始条件（如 $y(x_0) = y_0$）确定了任意常数后的解。

### 2. 可分离变量的微分方程
**形式**：$\frac{dy}{dx} = f(x)g(y)$
**解法**：
1. 将所有含有 $y$ 的项移到等号一边，含有 $x$ 的移到另一边：$\frac{dy}{g(y)} = f(x)dx$。
2. 两端同时不定积分：$\int \frac{dy}{g(y)} = \int f(x)dx + C$。

### 3. 一阶线性微分方程
**形式**：$\frac{dy}{dx} + P(x)y = Q(x)$
若 $Q(x) = 0$，称为齐次方程；若 $Q(x) \neq 0$，称为非齐次方程。
**通解公式（常数变易法推导而得）**：
$$y = e^{-\int P(x)dx} \left[ \int Q(x) e^{\int P(x)dx} dx + C \right]$$

<KnowledgeCard type="tip" title="积分因子的直观理解">
一阶线性方程的解法本质上是在方程两边同乘一个“积分因子” $\mu(x) = e^{\int P(x)dx}$，从而使方程左边完美折叠为导数乘积法则的结果 $\frac{d}{dx}(\mu(x) y)$。
</KnowledgeCard>

## 二、 二阶常系数线性微分方程

这类方程在物理的简谐振动和电路分析中占据统治地位。
**形式**：$y'' + py' + qy = f(x)$（其中 $p, q$ 为常数）。

### 1. 齐次方程的解 ($f(x) = 0$)
假设解的形式为 $y = e^{rx}$，代入方程得到**特征方程**：
$$r^2 + pr + q = 0$$
解特征方程求根 $r_1, r_2$，根据判别式 $\Delta = p^2 - 4q$ 决定通解形式：
1. **$\Delta > 0$（两个不等实根）**：$y = C_1 e^{r_1 x} + C_2 e^{r_2 x}$。
2. **$\Delta = 0$（两个相等实根 $r$）**：$y = (C_1 + C_2 x) e^{rx}$。
3. **$\Delta < 0$（一对共轭复根 $\alpha \pm \beta i$）**：$y = e^{\alpha x} (C_1 \cos \beta x + C_2 \sin \beta x)$。

### 2. 非齐次方程的特解 ($f(x) \neq 0$)
定理：非齐次通解 = 齐次通解 $Y(x)$ + 非齐次的一个特解 $y^*(x)$。
特解 $y^*$ 常用**待定系数法**求解，其形式取决于右端 $f(x)$ 的类型（如多项式、指数函数、三角函数等）。

## 三、 高阶实战解析

### 练习 1：求解一阶线性微分方程
求微分方程 $y' - \frac{2}{x} y = x^3$ 的通解 ($x > 0$)。

<details>
<summary>点击查看解析与答案</summary>

#### 解析过程
1. **识别类型**：这是一阶非齐次线性微分方程。
   其中 $P(x) = -\frac{2}{x}$， $Q(x) = x^3$。
2. **计算积分因子**：
   先算积分：$\int P(x)dx = \int -\frac{2}{x} dx = -2\ln x$。（省略常数）
   积分因子：$e^{\int P(x)dx} = e^{-2\ln x} = e^{\ln(x^{-2})} = x^{-2}$。
3. **套用通解公式**：
   公式：$y = e^{-\int P(x)dx} [ \int Q(x) e^{\int P(x)dx} dx + C ]$
   代入：
   $y = \frac{1}{x^{-2}} \left[ \int x^3 \cdot x^{-2} dx + C \right]$
   $y = x^2 \left[ \int x dx + C \right]$
   $y = x^2 \left( \frac{1}{2}x^2 + C \right)$
4. **化简结果**：
   $y = \frac{1}{2}x^4 + Cx^2$。

#### 答案
$y = \frac{1}{2}x^4 + Cx^2$
</details>

### 练习 2：特征方程法（共轭复根情况）
求微分方程 $y'' + 4y' + 13y = 0$ 的通解。

<details>
<summary>点击查看解析与答案</summary>

#### 解析过程
1. **写出特征方程**：
   将导数替换为 $r$ 的幂次：
   $r^2 + 4r + 13 = 0$。
2. **求解特征根**：
   利用求根公式 $r = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$：
   $r = \frac{-4 \pm \sqrt{16 - 52}}{2} = \frac{-4 \pm \sqrt{-36}}{2}$。
   $r = \frac{-4 \pm 6i}{2} = -2 \pm 3i$。
3. **确定根的类型**：
   这是一对共轭复根，其中实部 $\alpha = -2$，虚部 $\beta = 3$。
4. **套用通解模板**：
   对于复根情况，通解公式为 $y = e^{\alpha x} (C_1 \cos \beta x + C_2 \sin \beta x)$。
   代入得：
   $y = e^{-2x} (C_1 \cos 3x + C_2 \sin 3x)$。

#### 答案
$y = e^{-2x} (C_1 \cos 3x + C_2 \sin 3x)$
</details>

### 练习 3：微分方程在物理降温中的应用
（牛顿冷却定律）物体在室温下的冷却速度与物体温度和室温的差成正比。已知室温为 $20^\circ\text{C}$，开水（$100^\circ\text{C}$）在放置 10 分钟后降温至 $60^\circ\text{C}$。求再过 10 分钟水温为多少？

<details>
<summary>点击查看解析与答案</summary>

#### 解析过程
1. **建立微分方程模型**：
   设时间为 $t$，水温为 $T(t)$。冷却速度即导数 $\frac{dT}{dt}$。
   根据定律：$\frac{dT}{dt} = -k(T - 20)$，其中 $k > 0$ 为比例常数。
2. **求解微分方程**（可分离变量）：
   $\frac{dT}{T - 20} = -k dt$
   两边积分：$\ln(T - 20) = -kt + C$
   解得 $T(t) = 20 + e^{-kt+C} = 20 + C_1 e^{-kt}$。
3. **利用初值条件求常数**：
   初始时 $t=0$，$T=100$：$100 = 20 + C_1 e^0 \implies C_1 = 80$。
   所以 $T(t) = 20 + 80 e^{-kt}$。
4. **利用已知条件求 k**：
   $t=10$ 时，$T=60$：
   $60 = 20 + 80 e^{-10k} \implies 40 = 80 e^{-10k} \implies e^{-10k} = \frac{1}{2}$。
5. **计算目标值**：
   求再过 10 分钟（即 $t=20$ 时）的温度：
   $T(20) = 20 + 80 e^{-20k} = 20 + 80 (e^{-10k})^2$。
   代入 $e^{-10k} = 1/2$：
   $T(20) = 20 + 80 \times (\frac{1}{2})^2 = 20 + 80 \times \frac{1}{4} = 20 + 20 = 40$。

#### 答案
$40^\circ\text{C}$
</details>
