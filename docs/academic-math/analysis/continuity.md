# 连续性 (Continuity)

连续性是函数平滑程度的体现，是中值定理等深层结论的基础。

## 一、 核心知识点讲解

### 1. 定义
函数 $f(x)$ 在点 $x_0$ 连续 $\iff \lim_{x \to x_0} f(x) = f(x_0)$。
包含三个要素：点处有定义、极限存在、极限等于函数值。

### 2. 间断点分类
-   **第一类间断点**：左、右极限均存在。
    -   可去间断点：左右极限相等但 $\neq f(x_0)$。
    -   跳跃间断点：左右极限不相等。
-   **第二类间断点**：左、右极限中至少有一个不存在（如无穷间断点、震荡间断点）。

### 3. 闭区间连续函数性质
-   **最值定理**：必有最大值和最小值。
-   **介值定理**：必能取到最小值与最大值之间的任何值。
-   **零点定理**：若 $f(a) \cdot f(b) < 0$，则 $\exists \xi \in (a, b)$ 使得 $f(\xi) = 0$。

### 4. 一致连续性 (Uniform Continuity)
-   **定义**：称 $f(x)$ 在区间 $I$ 上一致连续，若 $\forall \epsilon > 0, \exists \delta > 0$，使得当 $x_1, x_2 \in I$ 且 $|x_1 - x_2| < \delta$ 时，恒有 $|f(x_1) - f(x_2)| < \epsilon$。
-   **Cantor 定理**：闭区间 $[a, b]$ 上的连续函数必在该区间上一致连续。
-   **判别准则**：
    -   若 $f(x)$ 在 $(a, b)$ 内连续且极限 $\lim_{x \to a^+} f(x)$ 与 $\lim_{x \to b^-} f(x)$ 均存在，则 $f(x)$ 在 $(a, b)$ 上一致连续。
    -   若 $f'(x)$ 在区间 $I$ 上有界，则 $f(x)$ 在 $I$ 上一致连续（Lipschitz 条件）。

### 5. Heine-Borel 有限覆盖定理
-   **定理内容**：若 $[a, b]$ 是一个闭区间，$\mathcal{F}$ 是 $[a, b]$ 的一个开覆盖（即 $\mathcal{F}$ 是由开区间组成的集合族，且 $[a, b] \subseteq \bigcup_{G \in \mathcal{F}} G$），则从 $\mathcal{F}$ 中必能选出有限个开区间来覆盖 $[a, b]$。
-   **地位**：有限覆盖定理是实数完备性公理之一，常用于将局部性质推广为全局性质。

## 二、 深度例题实战

### 例题 1：一致连续性的判定
证明 $f(x) = \sin(1/x)$ 在 $(0, 1]$ 上不是一致连续的。

<details>
<summary>点击查看解析与答案</summary>

#### 解析过程
1.  **取特殊点序列**：选取 $x_n = \frac{1}{2n\pi + \pi/2}$ 和 $x'_n = \frac{1}{2n\pi}$。
2.  **计算间距**：当 $n \to \infty$ 时，$|x_n - x'_n| \to 0$。
3.  **计算函数值差**：
    $|f(x_n) - f(x'_n)| = |\sin(2n\pi + \pi/2) - \sin(2n\pi)| = |1 - 0| = 1$。
4.  **结论**：取 $\epsilon_0 = 1/2$，无论 $\delta$ 多么小，总能找到 $x_n, x'_n$ 满足距离小于 $\delta$ 但函数值差不小于 $\epsilon_0$，故不一致连续。

#### 答案
证明如上，利用一致连续性的否定定义（取点列法）。
</details>

### 例题 2：根号函数的一致连续性
证明 $f(x) = \sqrt{x}$ 在 $[0, +\infty)$ 上一致连续。

<details>
<summary>点击查看解析与答案</summary>

#### 解析过程
1.  **区间拆分**：将 $[0, +\infty)$ 拆分为 $[0, 1]$ 和 $[1, +\infty)$。
2.  **闭区间部分**：在 $[0, 1]$ 上，$\sqrt{x}$ 连续且区间闭，由 Cantor 定理知一致连续。
3.  **无穷区间部分**：在 $[1, +\infty)$ 上，$f'(x) = \frac{1}{2\sqrt{x}} \le \frac{1}{2}$。导数有界，故由 Lipschitz 条件知一致连续。
4.  **拼接**：两个重叠区间上均一致连续，则在并集上一致连续。

#### 答案
利用 Cantor 定理与导数有界性判定。
</details>

### 例题 3：有限覆盖定理的应用
利用有限覆盖定理证明：若 $f(x)$ 在闭区间 $[a, b]$ 上连续，则 $f(x)$ 在该区间上有界。

<details>
<summary>点击查看解析与答案</summary>

#### 解析过程
1.  **局部有界性**：由于 $f(x)$ 在 $x_0 \in [a, b]$ 连续，对 $\epsilon=1$，存在 $\delta_{x_0} > 0$ 使得在 $U(x_0, \delta_{x_0})$ 内 $|f(x)| < |f(x_0)| + 1$（局部有界）。
2.  **构造开覆盖**：集合族 $\mathcal{F} = \{ (x - \delta_x, x + \delta_x) \mid x \in [a, b] \}$ 覆盖了 $[a, b]$。
3.  **应用定理**：存在有限个开区间覆盖 $[a, b]$，记为 $I_1, I_2, \dots, I_n$。
4.  **得出结论**：在每个 $I_k$ 上 $f(x)$ 都有界，取 $M = \max\{M_1, \dots, M_n\}$，则 $f(x)$ 在 $[a, b]$ 上全局有界。

#### 答案
通过有限覆盖定理将局部有界性推广至全局。
</details>

### 例题 4：Darboux 函数性质
设 $f(x)$ 在 $[a, b]$ 上连续，且 $f(a) < f(b)$。证明：对任意 $\eta \in (f(a), f(b))$，集合 $E = \{x \in [a, b] \mid f(x) = \eta\}$ 是闭集。

<details>
<summary>点击查看解析与答案</summary>

#### 解析过程
1.  **考虑补集**：设 $g(x) = f(x) - \eta$，则 $E = \{x \mid g(x) = 0\}$。
2.  **连续性应用**：由于 $f$ 连续，故 $g$ 也是连续函数。
3.  **开集原像**：$E^c = \{x \mid g(x) \neq 0\} = \{x \mid g(x) > 0\} \cup \{x \mid g(x) < 0\}$。
4.  **结论**：连续函数下开集的原像是开集，或者直接用点列极限性质证明。若 $x_n \in E$ 且 $x_n \to x_0$，则 $g(x_0) = \lim g(x_n) = 0$，故 $x_0 \in E$。

#### 答案
利用连续函数下闭集的原像是闭集（或点列极限定义）。
</details>

### 例题 5：一致连续性的保持
设 $f(x)$ 在 $\mathbb{R}$ 上一致连续，且 $\lim_{x \to \infty} f(x) = 0$。证明 $f(x)$ 在 $\mathbb{R}$ 上是一致连续的（这是一个性质确认题）。

<details>
<summary>点击查看解析与答案</summary>

#### 解析过程
1.  **利用定义**：对 $\epsilon > 0$，因极限为 0，存在 $A > 0$ 使得当 $|x| > A$ 时 $|f(x)| < \epsilon/2$。
2.  **区间划分**：考虑 $[-A-1, A+1]$。
3.  **Cantor 定理**：在该闭区间上 $f$ 一致连续，存在 $\delta_1$。
4.  **全域讨论**：选取 $\delta = \min\{\delta_1, 1\}$，分别讨论 $x, y$ 在 $[-A-1, A+1]$ 内、外以及跨越边界的情况。

#### 答案
结合无穷远处的衰减性与有限闭区间的一致连续性进行证明。
</details>
