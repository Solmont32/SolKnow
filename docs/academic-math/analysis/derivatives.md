# 瀵兼暟 (Derivatives)

## 瀹氫箟
鍑芥暟 $f(x)$ 鍦?$x_0$ 澶勭殑瀵兼暟瀹氫箟涓猴細
$f'(x_0) = \lim_{h \to 0} \frac{f(x_0 + h) - f(x_0)}{h}$

## 姹傚娉曞垯
- **鍔犳硶娉曞垯**锛?(u \pm v)' = u' \pm v'$
- **涔樻硶娉曞垯**锛?(uv)' = u'v + uv'$
- **闄ゆ硶娉曞垯**锛?(\frac{u}{v})' = \frac{u'v - uv'}{v^2}$
- **閾惧紡娉曞垯**锛?\frac{dy}{dx} = \frac{dy}{du} \cdot \frac{du}{dx}$

## 甯歌瀵兼暟鍏紡
- $(x^n)' = n x^{n-1}$
- $(\sin x)' = \cos x$
- $(e^x)' = e^x$
- $(\ln x)' = \frac{1}{x}$
