# 导数 (Derivatives)

## 定义
函数 $f(x)$ 在 $x_0$ 处的导数定义为：
$f'(x_0) = \lim_{h \to 0} \frac{f(x_0 + h) - f(x_0)}{h}$

## 求导法则
- **加法法则**：$(u \pm v)' = u' \pm v'$
- **乘法法则**：$(uv)' = u'v + uv'$
- **除法法则**：$(\frac{u}{v})' = \frac{u'v - uv'}{v^2}$
- **链式法则**：$\frac{dy}{dx} = \frac{dy}{du} \cdot \frac{du}{dx}$

## 常见导数公式
- $(x^n)' = n x^{n-1}$
- $(\sin x)' = \cos x$
- $(e^x)' = e^x$
- $(\ln x)' = \frac{1}{x}$
