# 集合论 (Set Theory)

## 基本概念
- **集合**：一些确定的、互异的对象组成的整体。
- **子集**：如果 $A$ 的每个元素都是 $B$ 的元素，则 $A \subseteq B$。

## 集合运算
- **并集 (Union, $\cup$)**：$A \cup B = \{x \mid x \in A \text{ 或 } x \in B\}$
- **交集 (Intersection, $\cap$)**：$A \cap B = \{x \mid x \in A \text{ 且 } x \in B\}$
- **补集 (Complement)**：在全集 $U$ 中，$\bar{A} = \{x \in U \mid x \notin A\}$

## 关系与函数
- **笛卡尔积**：$A \times B = \{(a, b) \mid a \in A, b \in B\}$
- **等价关系**：满足自反性、对称性和传递性的关系。
