# 抽样分布 (Sampling Distribution)

## 基本概念
- **总体与样本**：研究对象的全体称为总体，选出的部分称为样本。
- **统计量**：样本的函数，且不包含任何未知参数。常用统计量有样本均值 $\bar{X}$ 和样本方差 $S^2$。

## 三大抽样分布
1. **$\chi^2$ 分布 (卡方分布)**：$n$ 个独立标准正态随机变量的平方和。
2. **$t$ 分布 (学生分布)**：常用于样本量较小、总体方差未知时的均值检验。
3. **$F$ 分布**：两个独立卡方分布除以其自由度之比，常用于方差齐性检验和方差分析。

## 正态总体的抽样分布定理
- $\bar{X} \sim N(\mu, \sigma^2/n)$。
- $(n-1)S^2/\sigma^2 \sim \chi^2(n-1)$。
- 且 $\bar{X}$ 与 $S^2$ 相互独立。
