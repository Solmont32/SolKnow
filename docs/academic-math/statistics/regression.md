# 回归分析 (Regression Analysis)

## 一元线性回归
研究一个自变量 $x$ 与一个因变量 $y$ 之间的线性关系：
$$y = \beta_0 + \beta_1 x + \epsilon$$
其中 $\epsilon \sim N(0, \sigma^2)$ 是误差项。

## 最小二乘法 (OLS)
寻找估计量 $\hat{\beta}_0$ 和 $\hat{\beta}_1$，使得残差平方和 $Q$ 最小：
$$Q = \sum_{i=1}^n (y_i - \hat{y}_i)^2$$

## 显著性检验
- **回归方程的显著性 (F 检验)**：判断整个回归模型是否有效。
- **回归系数的显著性 (t 检验)**：判断自变量 $x$ 对 $y$ 的影响是否显著。

## 相关系数 ($r$)
衡量变量间线性相关程度强弱的指标，范围在 $[-1, 1]$ 之间。
- $|r| \to 1$：强相关。
- $r \to 0$：不相关。
