# 假设检验 (Hypothesis Testing)

## 基本步骤
1. 建立假设：原假设 $H_0$ 与备择假设 $H_1$。
2. 选择显著性水平 $\alpha$（如 0.05）。
3. 构造检验统计量。
4. 计算 $P$ 值或查找临界值。
5. 作出判断：若 $P < \alpha$，拒绝 $H_0$。

## 两类错误
- **第一类错误 (弃真)**：$H_0$ 为真却拒绝了。概率为 $\alpha$。
- **第二类错误 (取伪)**：$H_0$ 为假却接受了。概率为 $\beta$。

## 常见检验
- **Z 检验**：总体方差已知。
- **T 检验**：总体方差未知。
