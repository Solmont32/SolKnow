# 假设检验 (Hypothesis Testing)

## 基本思想
利用“小概率事件原理”进行反证法推断。

## 步骤
1. **建立假设**：
   - 原假设 $H_0$（通常是希望推翻的结论）。
   - 备择假设 $H_1$。
2. **选择统计量**：根据总体分布和已知条件选择 $Z, t, \chi^2$ 或 $F$ 统计量。
3. **确定显著性水平 ($\alpha$)**：常用 0.05 或 0.01。
4. **计算拒绝域**：根据 $\alpha$ 和分布表确定。
5. **作出判断**：若观测值落在拒绝域内，则拒绝 $H_0$。

## 两类错误
- **第一类错误 (弃真)**：$H_0$ 为真却拒绝了它。概率为 $\alpha$。
- **第二类错误 (取伪)**：$H_0$ 为假却接受了它。概率为 $\beta$。
