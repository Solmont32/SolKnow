# 线性 DP (Linear DP)

线性 DP 是动态规划中最基础的一类，其状态转移方程通常是沿着线性序列进行的。

## 最长上升子序列 (LIS)

给定一个序列，求其最长上升子序列的长度。

### 1. $O(n^2)$ 朴素实现
设 $f[i]$ 表示以第 $i$ 个数结尾的最长上升子序列的长度。
$$f[i] = \max(f[j] + 1) \quad (j < i, a[j] < a[i])$$

### 2. $O(n \log n)$ 优化
使用一个辅助数组 $d[k]$ 表示长度为 $k$ 的上升子序列末尾元素的最小值。由于 $d$ 数组是单调递增的，可以使用二分查找进行优化。

```cpp
vector<int> d;
for (int x : a) {
    if (d.empty() || x > d.back()) d.push_back(x);
    else *lower_bound(d.begin(), d.end(), x) = x;
}
return d.size();
```

## 最长公共子序列 (LCS)

求序列 $A$ 和序列 $B$ 的最长公共子序列长度。

### 状态表示
设 $f[i][j]$ 表示 $A$ 的前 $i$ 个字符和 $B$ 的前 $j$ 个字符的最长公共子序列长度。

### 状态转移
- 若 $A[i] == B[j]$，则 $f[i][j] = f[i-1][j-1] + 1$。
- 若 $A[i] \neq B[j]$，则 $f[i][j] = \max(f[i-1][j], f[i][j-1])$。

## 编辑距离 (Edit Distance)

给定两个字符串 $A$ 和 $B$，计算将 $A$ 转换成 $B$ 所需的最少操作次数（插入、删除、替换）。

### 状态表示
$f[i][j]$ 表示 $A$ 的前 $i$ 个字符转换到 $B$ 的前 $j$ 个字符的最少步数。

### 状态转移
- **替换**：$f[i-1][j-1] + (A[i] == B[j] ? 0 : 1)$
- **删除**：$f[i-1][j] + 1$
- **插入**：$f[i][j-1] + 1$
