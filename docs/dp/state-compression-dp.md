# 状态压缩动态规划 (State Compression DP)

状态压缩 DP 是利用位运算将一个集合、一种配置或某种棋盘格局压缩成一个整数，作为 DP 状态的一部分。其核心在于将**指数级的搜索空间**转化为**多项式级别的动态规划**。

---

## 核心建模前提

1. **规模限制**：关键维度的规模通常极小（$N \le 20$），使得 $2^N$ 在时间可接受范围内。
2. **集合特性**：状态可以表达为“选与不选”、“开与关”或某种有限离散集合。

---

## 1. 经典模型：旅行商问题 (Hamiltonian Path/TSP)

给定 $N$ 个点及两点间的距离，求经过所有点且每个点恰好一次的最短路径。
状态：$f[S][u]$ 表示当前经过的点集为 $S$（二进制压缩），且当前正处于点 $u$ 的最短距离。

**转移方程**：
$$f[S][u] = \min_{v \in S, v \neq u} \{ f[S \oplus (1 \ll u)][v] + \text{dist}(v, u) \}$$

---

## 2. 经典模型：棋盘覆盖 (Tile Covering)

如“玉米地”、“炮兵阵地”等问题。通常通过行与行之间的约束进行转移。
状态：$f[i][S]$ 表示处理完前 $i$ 行，且第 $i$ 行的布局状态为 $S$ 时的方案数或最优解。

**位运算技巧**：
- `(S >> j) & 1`：检查第 $j$ 位是否为 1。
- `S | (1 << j)`：将第 $j$ 位置为 1。
- `S & (S << 1)`：检查是否有相邻的 1（在某些棋盘约束中常用）。

---

## 3. 高阶技巧：子集枚举

给定状态 $S$，枚举其所有子集 $sub$：
```cpp
for (int sub = S; sub; sub = (sub - 1) & S) {
    // 处理子集 sub
}
```
总复杂度分析：对于所有状态 $S$ 枚举子集，复杂度为 $O(3^N)$ 而非 $O(4^N)$。

## 配套练习与解答

### 练习 1：最短 Hamilton 路径
给定一个图，求从点 $0$ 到点 $N-1$ 的最短 Hamilton 路径。

<details>
<summary>点击查看代码模板</summary>

```cpp
memset(f, 0x3f, sizeof f);
f[1][0] = 0;
for (int i = 1; i < (1 << n); i++)
    for (int j = 0; j < n; j++)
        if ((i >> j) & 1)
            for (int k = 0; k < n; k++)
                if (((i ^ (1 << j)) >> k) & 1)
                    f[i][j] = min(f[i][j], f[i ^ (1 << j)][k] + weight[k][j]);
```
</details>

### 练习 2：集合划分问题
将 $N$ 个数划分为若干个和不超过 $W$ 的子集，求最少划分数。

<details>
<summary>点击查看解题思路</summary>

$f[S]$：状态 $S$ 下的最少划分数。
$g[S]$：在 $f[S]$ 最优的前提下，当前组剩余的最大可用容量。
依次向 $S$ 中加入一个元素 $x$ 进行转移。
</details>

### 练习 3：蒙德里安的梦想 (POJ 2411)
用 $2 \times 1$ 的长方形填充 $N \times M$ 的棋盘。

<details>
<summary>点击查看解题思路</summary>

核心在于处理“竖放”的长方形。
$f[i][j]$：第 $i$ 行状态为 $j$（表示从 $i-1$ 行突出来的列）。
转移：$f[i][j] = \sum f[i-1][k]$，其中 $k$ 与 $j$ 必须兼容。
</details>
