# 状态压缩 DP (State Compression DP)

状态压缩 DP 是一种利用二进制位（或其他进制位）将某种集合状态压缩为一个整数，作为 DP 状态的一部分的动态规划方法。

## 适用条件

- 问题中某一维的状态较小（通常 $n \leq 20$）。
- 状态可以表示为一个集合，或者某种二值性（选或不选、开或关）。

## 位运算基础

- `(i >> j) & 1`：取出 $i$ 的第 $j$ 位。
- `i | (1 << j)`：将 $i$ 的第 $j$ 位置为 1。
- `i ^ (1 << j)`：将 $i$ 的第 $j$ 位翻转。

## 经典模型：最短 Hamilton 路径

给定一个带权无向图，求从点 0 到点 $n-1$ 的最短路径长度，且每个点恰好经过一次。

### 状态表示

$f[i][j]$ 表示当前经过的点的集合状态为 $i$（二进制表示），且当前正处于点 $j$ 的最短路径长度。

### 状态转移

设 $i'$ 为集合 $i$ 移除点 $j$ 后的状态，即 $i' = i \oplus (1 \ll j)$。

$$f[i][j] = \min_{k \in i', k \neq j} (f[i'][k] + \text{dist}[k][j])$$

### 代码实现 (C++)

```cpp
memset(f, 0x3f, sizeof f);
f[1][0] = 0; // 从点 0 开始
for (int i = 1; i < (1 << n); i++) {
    for (int j = 0; j < n; j++) {
        if ((i >> j) & 1) { // 如果当前集合包含点 j
            for (int k = 0; k < n; k++) {
                if (((i >> k) & 1) && k != j) { // 枚举上一个点 k
                    f[i][j] = min(f[i][j], f[i ^ (1 << j)][k] + dist[k][j]);
                }
            }
        }
    }
}
return f[(1 << n) - 1][n - 1];
```

## 应用场景

1. **旅行商问题 (TSP)**。
2. **棋盘覆盖/贴瓷砖问题**。
3. **哈密顿路径问题**。
