# 区间 DP (Range DP)

区间 DP 是指在一段区间上进行动态规划，通常通过合并小区间的最优解来得到大区间的最优解。

## 基本特征
1. **状态定义**：$f[i][j]$ 表示区间 $[i, j]$ 内的最优解。
2. **转移方向**：通常通过枚举中间点 $k$ ($i \leq k < j$)，将大区间拆分为 $[i, k]$ 和 $[k+1, j]$ 两部分。
3. **计算顺序**：通常按区间长度由小到大进行计算。

## 经典模型：石子合并

设有 $n$ 堆石子排成一排，每次只能合并相邻的两堆，合并的代价为两堆石子的重量之和。求将 $n$ 堆石子合并成一堆的最小代价。

### 状态表示
$f[i][j]$ 表示合并区间 $[i, j]$ 的最小代价。

### 状态转移
$$f[i][j] = \min_{i \leq k < j}(f[i][k] + f[k+1][j]) + \text{sum}(i, j)$$
其中 $\text{sum}(i, j)$ 表示区间内的石子总重（可用前缀和优化）。

### 代码实现 (C++)
```cpp
for (int len = 2; len <= n; len++) { // 遍历区间长度
    for (int i = 1; i + len - 1 <= n; i++) { // 遍历起始点
        int j = i + len - 1;
        f[i][j] = INF;
        for (int k = i; k < j; k++) { // 枚举中间点
            f[i][j] = min(f[i][j], f[i][k] + f[k+1][j] + s[j] - s[i-1]);
        }
    }
}
```

## 应用场景
1. **矩阵乘法链**：$O(n^3)$。
2. **多边形三角剖分**。
3. **最长回文子序列**。
