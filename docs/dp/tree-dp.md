# 树形 DP (Tree DP)

树形 DP 是在树这种结构上进行的动态规划，通常通过自底向上（从叶子到根）的方式，利用子树的状态来推导父节点的状态。

## 特征

- **遍历顺序**：通常使用 DFS 进行。
- **状态转移**：在递归回溯时，利用子节点的结果更新当前节点。

## 经典模型：没有上司的舞会

给定一棵树，每个点都有一个权值。要求选择一个点集，使得在这个点集中，任意两个点之间没有边相连，求点权之和的最大值。

### 状态表示

- $f[u][0]$ 表示不选 $u$ 点时，以 $u$ 为根的子树的最大权值和。
- $f[u][1]$ 表示选择 $u$ 点时，以 $u$ 为根的子树的最大权值和。

### 状态转移

设 $v$ 是 $u$ 的子节点：

- 如果选择 $u$，$v$ 就一定不能选：$f[u][1] = \sum f[v][0] + w[u]$
- 如果不选 $u$，$v$ 可以选也可以不选：$f[u][0] = \sum \max(f[v][0], f[v][1])$

### 代码实现 (C++)

```cpp
void dfs(int u) {
    f[u][1] = w[u];
    f[u][0] = 0;
    for (int i = head[u]; i; i = nxt[i]) {
        int v = ver[i];
        dfs(v);
        f[u][1] += f[v][0];
        f[u][0] += max(f[v][0], f[v][1]);
    }
}
```

## 应用场景

1. **树的重心/直径**。
2. **树上背包问题**。
3. **基环树 DP**。
