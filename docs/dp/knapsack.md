# 背包 DP (Knapsack Dynamic Programming)

背包问题是动态规划中的核心模型之一，核心矛盾是“有限容量 + 价值最大化”。

## 一、问题抽象

给定 $n$ 件物品，第 $i$ 件物品体积为 $w_i$，价值为 $v_i$，背包容量为 $W$。

目标：在不超过容量的前提下，最大化总价值。

常见变体：

- `0/1 背包`：每件物品最多选 1 次。
- `完全背包`：每件物品可选无限次。
- `多重背包`：每件物品可选 $c_i$ 次。
- `分组背包`：每组最多选 1 件。

## 二、状态设计模板

最常用状态：

$$

\text{dp}[j] = \text{容量恰为或不超过 } j \text{ 时可获得的最大价值}


$$

初始化：

- 最大值问题常用 `dp[0]=0`，其余为 0（若允许不装满）。
- 若要求“恰好装满”，除 `dp[0]=0` 外其余应初始化为负无穷。

## 三、0/1 背包

### 1. 转移方程

$$

\text{dp}[j] = \max(\text{dp}[j],\ \text{dp}[j-w_i] + v_i),\quad j \in [w_i, W]


$$

### 2. 为什么要倒序枚举容量

0/1 背包中每件物品只能使用一次，必须使用
`for (j = W; j >= w[i]; --j)`。

倒序保证本轮 `dp[j-w_i]` 仍是“上一轮物品集”的结果，避免同一件物品被重复使用。

### 3. 参考代码

```cpp
int knapsack01(int n, int W, const vector<int>& w, const vector<int>& v) {
    vector<int> dp(W + 1, 0);
    for (int i = 0; i < n; ++i) {
        for (int j = W; j >= w[i]; --j) {
            dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
        }
    }
    return dp[W];
}
```

### 4. 例题 A（基础）

物品：$(w,v)=(2,3),(3,4),(4,5),(5,8)$，$W=8$。

最优选法为第 2 件 + 第 4 件，总体积 $3+5=8$，总价值 $4+8=12$。

### 5. 例题 B（恰好装满）

若要求必须恰好装满容量 $W$，将不可达状态设为 $-\infty$，最后判断 `dp[W]` 是否仍不可达。

## 四、完全背包

### 1. 转移方程

完全背包与 0/1 背包公式相同，但容量枚举方向不同：

$$

\text{dp}[j] = \max(\text{dp}[j],\ \text{dp}[j-w_i] + v_i),\quad j \in [w_i, W]


$$

### 2. 为什么要正序枚举容量

完全背包允许同一物品重复使用，使用
`for (j = w[i]; j <= W; ++j)`，即可让当前轮新值继续参与转移。

### 3. 例题 C（模板）

硬币面值 `1, 3, 4`，求凑出总和 `6` 的最大价值（价值等于面值）。

由于可重复选，最优可取 `3+3` 或 `4+1+1`，价值均为 6。

## 五、多重背包

每件物品可选至多 $c_i$ 次。

常见两种做法：

- 朴素做法：三重循环，复杂度 $O(nWc_i)$。
- 二进制拆分：将 $c_i$ 拆为若干个 0/1 物品（1,2,4,...），总复杂度降为 $O(nW\log c_i)$。

### 例题 D（二进制拆分）

某物品 $(w,v,c)=(3,5,13)$，可拆成数量为 `1,2,4,6` 的四个组块，对应体积与价值按倍数扩展后，转化为 0/1 背包求解。

## 六、分组背包

有 $g$ 组物品，每组最多选 1 件。状态转移：

$$

\text{dp}[j] = \max\left(\text{dp}[j],\ \text{dp}[j-w_{k}] + v_{k}\right),\ \text{其中 } k \in \text{当前组}


$$

实现时，通常先复制上一组结果，避免同组多选。

## 七、竞赛高频易错点

1. 0/1 与完全背包的容量循环方向写反。
2. “恰好装满”却用 0 初始化所有状态。
3. 多组测试未清空 `dp`。
4. 数据范围大时 `int` 溢出，需用 `long long`。

## 八、综合例题（教材风格）

### 例题 E：双约束背包（二维费用）

每件物品有体积 $w_i$、时间 $t_i$、价值 $v_i$，限制 $W,T$，每件最多选一次。

状态：`dp[j][k]` 表示体积不超过 `j`、时间不超过 `k` 的最大价值。

转移：

$$

\text{dp}[j][k] = \max(\text{dp}[j][k],\ \text{dp}[j-w_i][k-t_i] + v_i)


$$

循环顺序对两个维度都应倒序。

### 例题 F：方案数版本

若问题改为“有多少种方式恰好装满容量 $W$”，可令 `dp[0]=1`，按题意改写为加法转移。

### 练习 1（基础）

`0/1 背包`：$W=10$，物品 $(w,v)$ 为 $(2,1),(3,3),(4,5),(7,9)$，求最大价值。

可行高价值组合：

- $7+3=10$，价值 $9+3=12$
- $4+3+2=9$，价值 $5+3+1=9$

最优为 12。

**答案**：12。

</details>

### 练习 2（基础）

解释为何 0/1 背包若用正序枚举 `j` 会出错，并给出一个最小反例。

<details>

<summary>点击查看过程与答案</summary>

反例：只有 1 件物品，$w=2,v=3$，$W=4$。

若正序枚举：

- `j=2` 时 `dp[2]=3`
- `j=4` 时会读到本轮刚更新的 `dp[2]=3`，得到 `dp[4]=6`

相当于同一件物品被选 2 次，违背 0/1 约束。

**答案**：正序会污染同轮状态，导致重复选同一件物品。

</details>

### 练习 3（提高）

完全背包：物品 $(w,v)=(2,3),(3,4)$，$W=7$，求最大价值。

<details>

<summary>点击查看过程与答案</summary>

尝试组合：

- $2+2+3=7$，价值 $3+3+4=10$
- $2+2+2=6$，价值 9
- $3+3=6$，价值 8

最优为 10。

**答案**：10。

</details>

### 练习 4（提高）

多重背包：单种物品 $(w,v,c)=(5,6,5)$，说明如何二进制拆分，并写出拆分后的“组块数量”。

<details>

<summary>点击查看过程与答案</summary>

将 5 拆成 `1 + 2 + 2`（或 `1 + 2 + 2` 对应最后剩余）。

对应组块：

- 1 件：体积 5，价值 6
- 2 件：体积 10，价值 12
- 2 件：体积 10，价值 12

然后按 0/1 背包处理这 3 个组块。

**答案**：可拆为 3 个组块，数量为 `1,2,2`。

</details>

### 练习 5（挑战）

分组背包中，为什么“组内循环”通常要基于上一组状态而不能原地直接滚动？

<details>

<summary>点击查看过程与答案</summary>

若直接在同一 `dp` 上更新，组内后选物品可能读到本组前面物品已更新的值，等价于同组选多件。

标准做法：

- 使用 `prev = dp` 备份上一组
- 当前组每个候选都从 `prev` 转移

**答案**：为保证“每组最多选一件”，必须避免组内状态互相污染。

</details>
