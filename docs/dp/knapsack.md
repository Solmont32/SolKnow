# 背包问题体系 (Knapsack Problem System)

背包问题是组合优化中的经典模型，其核心逻辑在于**有限预算下的资源最大化利用**。

---

## 1. 0/1 背包：每种物品仅一件

每件物品体积 $w_i$，价值 $v_i$，背包容量 $W$。
$$f[i][j] = \max(f[i-1][j], f[i-1][j-w_i] + v_i)$$

### 滚动数组优化
由于 $f[i]$ 仅依赖 $f[i-1]$，可优化为一维空间。为防止同一物品被多次重复选取，**必须倒序遍历容量**：
```cpp
for (int i = 1; i <= n; i++)
    for (int j = W; j >= w[i]; j--) // 倒序
        f[j] = max(f[j], f[j - w[i]] + v[i]);
```

---

## 2. 完全背包：物品无限量

$$f[j] = \max(f[j], f[j-w_i] + v_i)$$
**正序遍历容量**：因为同一物品可重复选取，当前轮更新的值可以被再次使用。
```cpp
for (int i = 1; i <= n; i++)
    for (int j = w[i]; j <= W; j++) // 正序
        f[j] = max(f[j], f[j - w[i]] + v[i]);
```

---

## 3. 多重背包：物品有限量 $c_i$

### 二进制拆分优化 $O(NW \log C)$
将 $c_i$ 件物品拆分为 $1, 2, 4, \dots, 2^k, c_i - (2^{k+1}-1)$ 组，每组视为一个 0/1 背包中的独立物品。

### 单调队列优化 $O(NW)$
利用单调队列维护滑动窗口最大值，实现理论最优复杂度。

---

## 4. 分组背包：每组最多选一件

$$f[j] = \max(f[j], f[j - w_{ik}] + v_{ik})$$
**注意循环顺序**：先枚举组，再枚举容量（倒序），最后枚举组内物品。

---

## 5. 树上背包（依赖背包）

如果选取物品 $i$ 必须先选取其父节点 $p$，则构成树形依赖。
定义 $f[u][j]$ 为以 $u$ 为根的子树，在容量 $j$ 下的最大价值。
这是一个典型的**树形 DP**，通过子树合并实现。

## 配套练习与解答

### 练习 1：恰好装满
若要求背包**必须恰好装满**，初始化应如何处理？

<details>
<summary>点击查看解题思路</summary>

- `f[0] = 0`
- 其余 `f[i] = -INF`（最大化价值）或 `INF`（最小化价值）。
这样只有从 $0$ 转移过来的状态才是有效的。
</details>

### 练习 2：方案数计数
给定容量 $W$ 和硬币面值，求有多少种方式凑出 $W$。

<details>
<summary>点击查看解题思路</summary>

$$f[j] = \sum f[j - w_i]$$
初始条件 `f[0] = 1`。如果是组合数（不考虑顺序），外层循环枚举硬币；如果是排列数（考虑顺序），外层循环枚举容量。
</details>

### 练习 3：多重背包单调队列优化模板
尝试写出 $O(NW)$ 复杂度的多重背包核心代码。

<details>
<summary>点击查看代码实现</summary>

```cpp
for (int i = 1; i <= n; i++) {
    for (int r = 0; r < w[i]; r++) { // 枚举余数
        deque<int> q;
        for (int j = r; j <= W; j += w[i]) {
            while (!q.empty() && f[q.back()] - (q.back() - r) / w[i] * v[i] <= f[j] - (j - r) / w[i] * v[i])
                q.pop_back();
            q.push_back(j);
            if (q.front() < j - c[i] * w[i]) q.pop_front();
            new_f[j] = f[q.front()] + (j - q.front()) / w[i] * v[i];
        }
    }
    f = new_f;
}
```
</details>
