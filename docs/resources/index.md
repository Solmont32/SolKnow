# 资源导航 (Resource Navigation)

这里收集了优秀的学习资源、竞赛平台和实用工具。

## 竞赛平台 (Platforms)
- [Codeforces](https://codeforces.com/) - 著名的全球算法竞赛平台
- [AtCoder](https://atcoder.jp/) - 日本高质量算法竞赛平台
- [LeetCode](https://leetcode.cn/) - 职场面试刷题首选
- [LuoGu](https://www.luogu.com.cn/) - 国内最大的算法竞赛社区

## 学习资源 (Learning)
- [OI Wiki](https://oi-wiki.org/) - 极具参考价值的算法竞赛知识库
- [Hello 算法](https://www.hello-algo.com/) - 动画图解数据结构与算法
- [VisuAlgo](https://visualgo.net/zh) - 算法可视化学习

## 实用工具 (Tools)
- [OEIS](https://oeis.org/) - 整数数列查询
- [Wolfram Alpha](https://www.wolframalpha.com/) - 万能数学计算引擎
- [Overleaf](https://www.overleaf.com/) - 在线 LaTeX 编辑器
