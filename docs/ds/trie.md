# 字典树 (Trie)

字典树（又称前缀树）是一种用于高效存储和检索字符串数据集中的键的树形结构。

## 性质

- 根节点不包含字符，除根节点外每一个节点都只包含一个字符。
- 从根节点到某一节点，路径上经过的字符连接起来，为该节点对应的字符串。
- 每个节点的所有子节点包含的字符都不相同。

## 操作流程

1. **插入 (Insert)**：根据字符路径向下游走，若路径不存在则新建节点；在末尾标记该位置为一个完整单词。
2. **查询 (Search)**：按字符查找，若中途断开则表示不存在；最后检查是否有结束标记。
3. **前缀匹配 (StartsWith)**：按字符查找，若能走完路径则说明存在该前缀。

## 复杂度分析

- **时间复杂度**：$O(L)$，其中 $L$ 是目标字符串的长度。与字典中字符串的总数无关。
- **空间复杂度**：由于节点共享公共前缀，可以节省空间，但在字符集很大（如 Unicode）时，空间消耗较大。

## C++ 简单实现

```cpp
const int MAXN = 100005; // 预分配节点
int trie[MAXN][26], cnt[MAXN], id = 0;

void insert(string s) {
    int p = 0;
    for (char c : s) {
        int v = c - 'a';
        if (!trie[p][v]) trie[p][v] = ++id;
        p = trie[p][v];
    }
    cnt[p]++; // 记录以该点结束的单词数
}

bool query(string s) {
    int p = 0;
    for (char c : s) {
        int v = c - 'a';
        if (!trie[p][v]) return false;
        p = trie[p][v];
    }
    return cnt[p] > 0;
}
```

## 应用场景

1. **前缀匹配**：如输入法自动联想、URL 路由匹配。
2. **词频统计**：统计同一个单词出现的次数。
3. **01-Trie**：解决最大异或对问题。
