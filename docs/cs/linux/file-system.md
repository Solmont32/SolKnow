# Linux 文件系统 (FHS)

Linux 采用单一树状结构的文件系统，遵循 **FHS (Filesystem Hierarchy Standard)** 标准。

## 目录布局
- `/`：根目录，系统的起点。
- `/bin`：存放所有用户都可使用的基本命令。
- `/sbin`：存放管理员 (root) 使用的系统管理命令。
- `/etc`：系统核心配置文件存放处。
- `/home`：所有普通用户的家目录。
- `/root`：超级用户 (root) 的家目录。
- `/tmp`：临时文件目录。
- `/usr`：安装的应用程序及库文件。
- `/var`：存放经常变化的文件（如日志、缓存）。
- `/dev`：包含所有硬件设备的虚拟文件。
- `/proc`：虚拟文件系统，包含系统运行时的信息。

## 常用路径表示
- `.`：当前目录。
- `..`：上一级目录。
- `~`：当前用户的家目录。
- `-`：上一次所在的目录。

## 挂载 (Mount)
Linux 所有的存储设备（硬盘、U盘）都必须**挂载**到文件树的某个目录下才能访问。
- `mount /dev/sdb1 /mnt`：将设备挂载到 `/mnt`。
- `umount /mnt`：卸载设备。
