# Linux 基础命令

掌握 Linux 命令是系统管理和开发的第一步。

## 文件与目录操作

- `ls`：列出目录内容 (`-l` 详细模式, `-a` 显示隐藏文件)。
- `cd`：切换工作目录。
- `pwd`：显示当前路径。
- `cp`：复制文件或目录 (`-r` 递归)。
- `mv`：移动或重命名文件。
- `rm`：删除文件或目录 (`-rf` 强制递归，慎用)。
- `mkdir`：创建目录。

## 文本查看与处理

- `cat`：连接并显示文件内容。
- `more` / `less`：分屏查看长文件。
- `head` / `tail`：查看文件头/尾几行 (`tail -f` 实时追踪日志)。
- `grep`：强大的文本搜索工具。
- `find`：在目录树中搜索文件。

## 系统状态与监控

- `top` / `htop`：实时显示进程与资源占用。
- `df`：查看磁盘空间。
- `free`：查看内存使用情况。
- `ps`：查看当前进程快照 (`ps aux`)。
- `kill`：发送信号给进程 (`kill -9 PID`)。

## 帮助命令

- `man`：查看命令手册 (Manual)。
- `--help`：大多数命令自带的简要说明。
