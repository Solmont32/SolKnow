# C 语言基础语法

C 语言是一种强类型语言，每一段代码都直接操作机器底层的逻辑。

## 数据类型

- **基本类型**：`int`, `float`, `double`, `char`。
- **派生类型**：数组、结构体、联合体、指针。
- **布尔类型**：在 `stdbool.h` 中定义，或者使用 `0` 代表假，非 `0` 代表真。

## 控制流

- **条件判断**：`if-else`, `switch-case`。
- **循环结构**：`for`, `while`, `do-while`。

## 数组 (Arrays)

数组是连续内存块的表示。

```c
int arr[5] = {1, 2, 3, 4, 5};
// arr 实际上是指向首元素的常量指针
```

## 输入输出

C 语言通过标准库 `<stdio.h>` 提供输入输出功能：

- `printf("%d", x);`：格式化输出。
- `scanf("%d", &x);`：格式化输入（注意取地址符 `&`）。

## 核心要点

1. **强类型**：必须声明变量类型。
2. **零偏移索引**：数组索引从 0 开始。
3. **函数入口**：每个程序必须有 `int main()` 函数。
