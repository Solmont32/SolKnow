# 指针详解 (Pointers)

指针是 C 语言最强大的特性之一，它允许程序直接操作内存地址。

## 基本概念

- **地址 (&)**：内存中存储单元的编号。
- **解引用 (\*)**：访问指针所指向地址中的值。

## 指针变量

声明一个指针变量：`int *ptr;`，表示 `ptr` 存储的是一个 `int` 类型变量的地址。

```c
int a = 10;
int *p = &a; // p 存储 a 的地址
printf("%p", p); // 输出地址
printf("%d", *p); // 输出 a 的值 10
```

## 指针与数组

在 C 语言中，数组名实际上是指向数组第一个元素的指针。

- `a[i]` 等价于 `*(a + i)`。

## 指针运算

- `p++`：移动到下一个元素的地址（增加量为数据类型的长度）。
- `p1 - p2`：计算两个地址之间的元素个数。

## 函数指针

允许将函数作为参数传递，是实现回调的基础。
`void (*func_ptr)(int);`

## 常见坑点

- **野指针**：未初始化的指针，指向不确定的地址。
- **空指针**：`NULL`，表示不指向任何地方，访问会引发段错误。
- **重复解引用**：指针的指针 (`int **pp`)。
