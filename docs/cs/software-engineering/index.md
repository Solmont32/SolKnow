# 软件工程 (Software Engineering)

软件工程是应用计算机科学、数学和项目管理原理来开发、运行和维护软件的学科。

## 核心内容

### 软件开发生命周期 (SDLC)

- **需求分析**: 明确用户需求与系统约束。
- **设计阶段**: 架构设计 (High-level) 与详细设计 (Low-level)。
- **编码实现**: 选择合适的语言与开发环境。
- **测试验证**: 单元测试、集成测试、系统测试与验收测试。
- **运维与演化**: 监控、修复缺陷与需求变更。

### 版本控制 (Git)

- [Git 基础](git-basics): 提交、分支与合并。
- [Git 工作流](git-workflow): Git Flow, GitHub Flow 与协作模式。

### 敏捷开发 (Agile)

- **Scrum**: 角色 (Product Owner, Scrum Master, Team), 仪式 (Sprint, Standup, Review, Retrospective)。
- **Kanban**: 可视化工作流与限制在制品 (WIP)。

### 设计模式

- 创建型 (Creational): Singleton, Factory, Builder.
- 结构型 (Structural): Adapter, Composite, Decorator.
- 行为型 (Behavioral): Strategy, Observer, Command.
