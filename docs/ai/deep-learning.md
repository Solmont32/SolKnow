# 深度学习 (DL)

基于人工神经网络的机器学习子集。

## 核心概念
- **神经元 (Neuron)**
- **激活函数**：ReLU, Sigmoid, Tanh。
- **反向传播 (Backpropagation)**
- **卷积神经网络 (CNN)**：用于图像。
- **循环神经网络 (RNN/LSTM)**：用于序列数据。

<KnowledgeCard type="info" title="数学基础">
深度学习的底层是 **多元微积分**（梯度下降）和 **线性代数**（张量运算）。
</KnowledgeCard>
