# 人工智能 (Artificial Intelligence)

人工智能是研究、开发用于模拟、延伸和扩展人的智能的理论、方法、技术及应用系统的一门新的技术科学。

## 知识图谱
-   **机器学习 (ML)**：AI 的核心，通过数据训练模型。
-   **深度学习 (DL)**：基于人工神经网络的机器学习子集。
-   **自然语言处理 (NLP)**：让机器理解、生成人类语言。
-   **计算机视觉 (CV)**：让机器“看见”并理解图像。

## 核心算法分类
1.  **监督学习**：分类（SVM, 决策树）、回归。
2.  **无监督学习**：聚类（K-Means）、降维（PCA）。
3.  **强化学习**：Q-Learning, 策略梯度。
