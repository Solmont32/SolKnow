# 自然语言处理 (NLP)

让机器理解并生成人类语言。

## 演进历程

1. **统计 NLP**：N-gram 模型。
2. **神经网络 NLP**：Word2Vec, RNN。
3. **Transformer 时代**：Attention 机制、BERT。
4. **大语言模型 (LLM)**：GPT-3, Llama。
