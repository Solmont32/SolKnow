# 机器学习 (ML)

机器学习是人工智能的核心子集，研究如何通过数据改善计算机算法。

## 核心算法

- **线性回归 (Linear Regression)**
- **逻辑回归 (Logistic Regression)**
- **决策树与随机森林**
- **支持向量机 (SVM)**

<KnowledgeCard type="tip" title="核心公式">
最小二乘法损失函数：

$$J(\theta) = \frac{1}{2m} \sum_{i=1}^m (h_\theta(x^{(i)}) - y^{(i)})^2$$

</KnowledgeCard>
