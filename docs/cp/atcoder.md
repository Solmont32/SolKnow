# AtCoder 竞技指南

AtCoder 是来自日本的高质量算法竞赛平台，其题目风格偏向数学思维和逻辑推导。

## 比赛体系
- **ABC (AtCoder Beginner Contest)**：非常适合初学者，由浅入深。
- **ARC (AtCoder Regular Contest)**：注重思维转换。
- **AGC (AtCoder Grand Contest)**：顶尖脑力对决。

<KnowledgeCard type="tip" title="解题风格">
AtCoder 的题目通常代码量不大，但需要极强的数学建模能力。如果卡题了，试着在纸上推导一下特殊性质。
</KnowledgeCard>
