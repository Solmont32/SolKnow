# 复杂度分析与常见估算

## 1. 时间复杂度

衡量算法运行时间的增长速度。竞赛中常见的量级：

- $O(1)$: 常数级
- $O(\log n)$: 二分查找
- $O(n)$: 遍历
- $O(n \log n)$: 快速排序、归并排序、堆
- $O(n^2)$: 嵌套循环
- $O(2^n)$: 指数级（如 DFS）

## 2. 竞赛中的经验估算

通常 $1$ 秒内可以处理大约 $10^7 \sim 10^8$ 次运算。

- $n \le 10$: $O(n!)$
- $n \le 20$: $O(2^n)$
- $n \le 500$: $O(n^3)$
- $n \le 5000$: $O(n^2)$
- $n \le 10^5$: $O(n \log n)$ 或 $O(n \sqrt{n})$
- $n \le 10^6$: $O(n)$
- $n \le 10^9$: $O(\log n)$ 或 $O(1)$

## 3. 空间复杂度

通常内存限制为 128MB 或 256MB。

- 一个 `int` 占 4 字节。
- $10^7$ 个 `int` 大约占用 40MB 内存。
- 竞赛中声明全局大数组（如 $10^6$ 级别）是常见的。
