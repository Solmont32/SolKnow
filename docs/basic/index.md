## 学习建议

1. **先理解再记忆**：二分的边界、排序的划分、差分的互逆，理解其背后的数学原理（如单调性、容斥原理）比死记模板更重要。
2. **手写代码**：对于排序和二分模板，务必能手写无误。
3. **复杂度意识**：在看到数据范围时，应能瞬间反应出该使用 $O(n)$, $O(n \log n)$ 还是 $O(\log n)$ 的算法。
