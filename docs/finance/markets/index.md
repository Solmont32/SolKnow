# 金融市场与机构

金融市场是资金融通的场所，金融机构是连接资金盈余方和短缺方的中介。

## 金融市场分类

### 按交易标的物分类

```
金融市场体系
─────────────────────────────────────────
├── 货币市场 (Money Market)
│   ├── 同业拆借市场
│   ├── 回购协议市场
│   ├── 商业票据市场
│   ├── 银行承兑汇票市场
│   └── 大额可转让存单市场
│
├── 资本市场 (Capital Market)
│   ├── 股票市场
│   │   ├── 一级市场（发行市场）
│   │   └── 二级市场（流通市场）
│   ├── 债券市场
│   │   ├── 政府债券
│   │   ├── 金融债券
│   │   └── 公司债券
│   └── 基金市场
│
├── 衍生品市场 (Derivatives Market)
│   ├── 期货市场
│   ├── 期权市场
│   ├── 互换市场

```
