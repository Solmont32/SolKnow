# 金融知识库

欢迎来到金融知识库，这里系统整理金融学核心理论、投资方法与实践应用。

## 知识库概述

## 学习路径

### 初学者路线
1. **金融基础** - 货币、信用、利率基础概念
2. **时间价值** - 现值、终值、年金计算
3. **基础投资** - 股票、债券基本特性
4. **财务报表** - 三大报表基础分析

### 进阶路线
1. **资产定价** - CAPM、APT、有效市场假说
2. **投资组合** - 马科维茨理论、风险分散
3. **衍生品定价** - 期权定价、期货套利
4. **公司估值** - DCF、相对估值法

### 专业路线
1. **固收分析** - 利率风险、久期、凸性
2. **高级衍生** - 奇异期权、结构化产品
3. **风险管理** - VaR、压力测试、信用评级
4. **行为金融** - 市场异象、投资者心理

## 与量化交易知识库的区别

| 维度 | 金融知识库 | 量化交易知识库 |
|------|-----------|---------------|
| **侧重点** | 金融理论、投资原理 | 策略实现、程序化交易 |
| **数学深度** | 中等（应用层面） | 较深（建模与算法） |
| **技术实现** | 无/Excel为主 | Python/C++编程 |
| **适用人群** | 金融从业者、CFA考生 | 量化研究员、交易员 |
| **实践性** | 理论框架 | 实盘系统 |

两个知识库相辅相成：金融知识库提供理论基础，量化交易知识库提供技术实现手段。
