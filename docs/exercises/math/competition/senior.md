## 练习 1：不等式证明
已知 $a, b, c > 0$，证明：$a^3 + b^3 + c^3 \ge 3abc$。

<details>
<summary>点击查看解析与答案</summary>

#### 解析
1. **利用均值不等式**：对于三个正数 $a^3, b^3, c^3$。
2. **计算**：$\frac{a^3 + b^3 + c^3}{3} \ge \sqrt[3]{a^3 b^3 c^3}$。
3. **化简**：$\frac{a^3 + b^3 + c^3}{3} \ge abc \implies a^3 + b^3 + c^3 \ge 3abc$。

#### 答案
证毕。
</details>
