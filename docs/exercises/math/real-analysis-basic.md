# 实数分析：实数系与确界原理

## 练习 1：确界概念辨析
判断下列命题是否正确，并给出反例：
1. 若集合 $S$ 有上界，则 $\sup S$ 一定属于 $S$。
2. 若 $\sup S = \inf S$，则 $S$ 必为单元素集合。
3. 任何非空有限集必有最大值，且最大值即为其上确界。

---

## 练习 2：确界证明题 (深度)
1. **确界性质推导**：设 $S \subseteq \mathbb{R}$ 有上界。证明：若对任意 $\epsilon > 0$，存在 $x \in S$ 使得 $x > M - \epsilon$，且 $M$ 是 $S$ 的一个上界，则 $M = \sup S$。
2. **戴德金分割练习**：设 $(A, B)$ 是实数集的一个戴德金分割，且 $A$ 没有最大元。证明 $B$ 一定有最小元且该最小元即为该分割产生的实数。

---

## 练习 3：综合计算与证明
1. 求集合 $S = \{ \frac{x}{x+1} \mid x > 0 \}$ 的上确界与下确界。
2. 设 $S = \{ \sin n \mid n \in \mathbb{N} \}$。已知 $\sup S = 1$ 且 $\inf S = -1$（由于 $\pi$ 是无理数产生的稠密性）。请说明为什么该集合没有最大值和最小值？
