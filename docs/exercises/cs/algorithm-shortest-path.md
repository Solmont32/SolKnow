# 算法竞赛练习：最短路专题

本页与 [`最短路算法`](/docs/graph/shortest-path) 联动，按“基础 -> 提高 -> 挑战”组织，全部采用折叠答案。

## 基础题

### 练习 1：Dijkstra 手算

有向图边：$1\to2(1), 1\to3(4), 2\to3(2), 2\to4(6), 3\to4(3)$。
求 $d(1,4)$。

<details>

<summary>点击查看过程与答案</summary>

从 1 出发：

- `dist[2]=1`
- `dist[3]=min(4,1+2)=3`
- `dist[4]=min(1+6,3+3)=6`

**答案**：$d(1,4)=6$。

</details>

### 练习 2：算法判定

下列场景应选什么算法？

1. 单源，边权均非负。
2. 单源，存在负边并需检测负环。
3. 全源且点数约 250。

<details>

<summary>点击查看过程与答案</summary>

1. Dijkstra。
2. Bellman-Ford（或可检测负环的 SPFA 版本）。
3. Floyd-Warshall。

**答案**：依次为 Dijkstra、Bellman-Ford、Floyd。

</details>

## 提高题

### 练习 3：Bellman-Ford 判负环

给边：$1\to2(1), 2\to3(-2), 3\to2(-2), 3\to4(1)$。源点为 1。
问：是否存在可达负环？

<details>

<summary>点击查看过程与答案</summary>

环 $2\to3\to2$ 权和为 $-4$，且从 1 可达 2，因此该负环源点可达。

**答案**：存在可达负环。

</details>

### 练习 4：最短路重构

在最短路算法中维护 `pre[]` 数组的作用是什么？如何还原路径？

<details>

<summary>点击查看过程与答案</summary>

`pre[v]` 记录“最优转移到 v 的前驱点”。
从终点 `t` 开始反复令 `t=pre[t]` 直到源点，逆序即最短路径。

**答案**：`pre[]` 用于路径重构，终点回溯后反转即可得到路径。

</details>

## 挑战题

### 练习 5：边数受限最短路

给定最多经过 $K$ 条边的限制，为什么普通 Dijkstra 可能不适用？应如何建模？

<details>

<summary>点击查看过程与答案</summary>

普通 Dijkstra 的状态只有“点”，未区分已用边数，无法直接表达“最多 $K$ 条边”约束。
可用分层图或 `dp[k][v]`（第 k 层表示用了 k 条边）做 Bellman-Ford/最短路。

**答案**：需把“边数”并入状态，常用分层图或 `dp[k][v]`。

</details>

### 练习 7：分层图建模（免费 $k$ 次）
有 $n$ 个点 $m$ 条边，您可以选择最多 $k$ 条边使其权值为 0。求 $S$ 到 $T$ 的最小代价。请描述分层图的构建方法。

<details>
<summary>点击查看过程与答案</summary>

**建模步骤**：
1. 建立 $k+1$ 层相同的图（第 0 层到第 $k$ 层）。
2. **层内边**：对每一层 $i \in [0, k]$，若原图有边 $(u, v, w)$，则连边 $(u_i, v_i, w)$。
3. **跨层边**：若原图有边 $(u, v, w)$，则连边 $(u_i, v_{i+1}, 0)$，表示在这一步使用了 1 次免费机会。
4. **终点**：计算 $dist(S_0, \text{any } T_i)$ 的最小值。

**答案**：通过 $k+1$ 层构图，层间连 0 权边模拟免费操作。

</details>

### 练习 8：分层图计算（有限状态）
点 1, 2, 3。边：$1\to2(10), 2\to3(10), 1\to3(15)$。您可以让 **1 条** 边的权值减半。求从 1 到 3 的最短路。

<details>
<summary>点击查看过程与答案</summary>

分层图层 0：$1_0\to2_0(10), 2_0\to3_0(10), 1_0\to3_0(15)$
分层图层 1：$1_1\to2_1(10), 2_1\to3_1(10), 1_1\to3_1(15)$
跨层边（减半）：$1_0\to2_1(5), 2_0\to3_1(5), 1_0\to3_1(7.5)$

计算最短路：
- $dist(1_0, 3_0) = 15$
- $dist(1_0, 3_1) = \min(15/2=7.5, \ 10+10/2=15, \ 10/2+10=15) = 7.5$

**答案**：最短距离为 7.5。

</details>
