# 算法竞赛练习：强连通分量（SCC）

建议先学习：[`强连通分量（Tarjan / SCC）`](/docs/graph/tarjan)

---

## 练习 1（基础）

给定有向图 `n=5`，边为：

- `1->2, 2->1, 2->3, 3->4, 4->3, 4->5`

问：SCC 个数是多少？每个 SCC 可写成哪些点集？

<details>

<summary>点击展开过程与答案</summary>

- `1,2` 互相可达，为一个 SCC。
- `3,4` 互相可达，为一个 SCC。
- `5` 单独一个 SCC。

答案：共有 3 个 SCC，分别为 `{1,2}`、`{3,4}`、`{5}`。

</details>

## 练习 2（基础）

若 Tarjan 求得 `sccCnt = 1`，可以推出什么结论？

<details>

<summary>点击展开过程与答案</summary>

可以推出原有向图强连通（任意两点互相可达）。

</details>

## 练习 3（提高）

某图缩点后 DAG 的入度为 0 的 SCC 有 3 个，出度为 0 的 SCC 有 5 个，且 `sccCnt > 1`。

问：最少加几条边能使原图强连通？

<details>

<summary>点击展开过程与答案</summary>

结论公式：若 `sccCnt > 1`，答案 `max(入度0个数, 出度0个数)`。

所以最少加 `max(3,5)=5` 条边。

</details>

## 练习 4（提高）

在 Tarjan 中，处理边 `u -> v` 时，若 `v` 已访问且 `v` 在栈中，为什么使用 `dfn[v]` 更新 `low[u]` 而不是 `low[v]`？

<details>

<summary>点击展开过程与答案</summary>

该边是指向当前 DFS 栈内祖先（或栈内先访问点）的回边，表示可直接回到 `v` 的发现时刻。

`low[v]` 可能包含 `v` 子树向下探索得到的信息，不应通过一条回边“跨层继承”；因此应更新为 `min(low[u], dfn[v])`。

</details>

## 练习 5（挑战）

在 2-SAT 蕴含图中，变量 `x_i` 对应两个点 `i`（真）与 `i+n`（假）。

可满足性的 Tarjan 判定条件是什么？

<details>

<summary>点击展开过程与答案</summary>

对任意变量 `i`，若 `i` 与 `i+n` 属于同一 SCC，则不可满足。

若所有变量都满足 `comp[i] != comp[i+n]`，则公式可满足。

</details>

## 练习 6（挑战）

“受欢迎的牛”类问题中，为什么当缩点图有多个出度为 0 的 SCC 时答案为 0？

<details>

<summary>点击展开过程与答案</summary>

若有多个出度 0 SCC，它们之间在缩点 DAG 中互不可达，任何一个 SCC 都无法到达另一个出度 0 SCC。

因此不存在“能到达所有点”的统一终点 SCC，答案为 0。

</details>
