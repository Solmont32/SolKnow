# 拓扑排序 (Topological Sort)

拓扑排序是对有向无环图（DAG）的顶点的一种排序，使得如果图中存在一条从 $u$ 到 $v$ 的有向边，则在排序中 $u$ 必须出现在 $v$ 之前。

## 原理 (Kahn 算法)

1. 计算所有顶点的**入度 (in-degree)**。
2. 将所有入度为 0 的顶点放入队列。
3. 当队列不为空时：
   - 弹出队头顶点 $u$。
   - 遍历 $u$ 的出边 $(u, v)$，将 $v$ 的入度减 1。
   - 如果 $v$ 的入度变为 0，则将 $v$ 放入队列。
4. 如果弹出的顶点总数小于图的顶点数，则图中存在环，无法进行拓扑排序。

## 复杂度分析
- **时间复杂度**：$O(n + m)$。
- **空间复杂度**：$O(n + m)$。

## 代码实现 (C++)
```cpp
int in[MAXN], q[MAXN], head[MAXN], cnt = 0;
// 计算入度 in[v]++ ...

int l = 1, r = 0;
for (int i = 1; i <= n; i++)
    if (in[i] == 0) q[++r] = i;

while (l <= r) {
    int u = q[l++];
    cnt++;
    for (int i = head[u]; i; i = nxt[i]) {
        int v = ver[i];
        if (--in[v] == 0) q[++r] = v;
    }
}

if (cnt == n) // 排序结果在 q 中
else // 图中有环
```

## 应用场景
1. **任务调度/编译顺序依赖**。
2. **检测图是否有环**。
3. **DAG 上的动态规划**：在拓扑序的基础上进行 DP。
