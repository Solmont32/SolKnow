# 最短路算法 (Shortest Path)

最短路算法用于寻找图中两点之间边权和最小的路径。

## 单源最短路 (Single Source)

### 1. Dijkstra 算法
- **特点**：适用于**非负权边**。
- **复杂度**：$O(m \log n)$（优先队列优化）。
- **实现**：维护一个 `dist` 数组，每次取出当前距离最小的点 $u$，用其出边更新相邻点的 `dist`。

### 2. Bellman-Ford 算法
- **特点**：适用于包含**负权边**的图，能检测**负环**。
- **原理**：对所有边进行 $n-1$ 次松弛操作。
- **复杂度**：$O(nm)$。

### 3. SPFA (Shortest Path Faster Algorithm)
- **原理**：Bellman-Ford 的优化版本，使用队列存储可能被更新的点。
- **特点**：在随机图中表现优异（$O(km)$），但在某些构造图中（如网格图）会退化到 $O(nm)$。

## 全源最短路 (All Pairs)

### Floyd-Warshall 算法
- **特点**：解决任意两点之间的最短路。
- **原理**：基于动态规划。$f[k][i][j]$ 表示经过前 $k$ 个点中转，$i$ 到 $j$ 的最短距离。
- **复杂度**：$O(n^3)$。
- **实现**：
```cpp
for (int k = 1; k <= n; k++)
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= n; j++)
            d[i][j] = min(d[i][j], d[i][k] + d[k][j]);
```

## 算法对比
| 算法 | 适用范围 | 负权边 | 负环 | 复杂度 |
| :--- | :--- | :---: | :---: | :--- |
| Dijkstra | 单源 | 不支持 | 不支持 | $O(m \log n)$ |
| SPFA | 单源 | 支持 | 支持检测 | $O(km)$ |
| Bellman-Ford | 单源 | 支持 | 支持检测 | $O(nm)$ |
| Floyd | 全源 | 支持 | 不支持 | $O(n^3)$ |
