# SolKnow (知岛)

沉浸式的 **算法竞赛笔记** 与 **数学知识体系**。
整合图文教程与 B 站视频讲解，打造属于你的结构化数字大脑。

---

## 🌟 项目亮点
- **三足鼎立**: 涵盖算法竞赛、系统数学、计算机科学三大核心板块。
- **视觉驱动**: 采用 `framer-motion` 动效、`Lucide` 图标与玻璃拟态设计。
- **视频整合**: 核心笔记均配备 B 站嵌入式视频解析。
- **公式支持**: 基于 KaTeX 的高质量数学公式渲染。
