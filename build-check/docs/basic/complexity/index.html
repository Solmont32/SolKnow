复杂度分析与常见估算

1. 时间复杂度​

衡量算法运行时间的增长速度。竞赛中常见的量级：

  • O(1)O(1)O(1): 常数级
  • O(log⁡n)O(\log n)O(logn): 二分查找
  • O(n)O(n)O(n): 遍历
  • O(nlog⁡n)O(n \log n)O(nlogn): 快速排序、归并排序、堆
  • O(n2)O(n^2)O(n2): 嵌套循环
  • O(2n)O(2^n)O(2n): 指数级（如 DFS）

2. 竞赛中的经验估算​

通常 111 秒内可以处理大约 107∼10810^7 \sim 10^8107∼108 次运算。

  • n≤10n \le 10n≤10: O(n!)O(n!)O(n!)
  • n≤20n \le 20n≤20: O(2n)O(2^n)O(2n)
  • n≤500n \le 500n≤500: O(n3)O(n^3)O(n3)
  • n≤5000n \le 5000n≤5000: O(n2)O(n^2)O(n2)
  • n≤105n \le 10^5n≤105: O(nlog⁡n)O(n \log n)O(nlogn) 或 O(nn)O(n \sqrt{n})O(nn​)
  • n≤106n \le 10^6n≤106: O(n)O(n)O(n)
  • n≤109n \le 10^9n≤109: O(log⁡n)O(\log n)O(logn) 或 O(1)O(1)O(1)

3. 空间复杂度​
