微分方程：探索变化的规律

如果代数方程是寻找一个未知的数，那么微分方程就是在寻找一个未知的函数。它是通过已知该函数与其导数之间的关系，反推出函数原本面貌的强大学科，在物理建模、种群动力学和经济学中有极广泛的应用。

一、 常微分方程的初等解法​

在处理一阶方程时，除了最基本的可分离变量和线性方程外，还有几种常见的初等类型：

1. 伯努利方程 (Bernoulli Equation)​

形式：dydx+P(x)y=Q(x)yn\frac{dy}{dx} + P(x)y = Q(x)y^ndxdy​+P(x)y=Q(x)yn （其中 n≠0,1n \neq 0, 1n=0,1）。 解法：

  1. 两端除以 yny^nyn：y−ndydx+P(x)y1−n=Q(x)y^{-n} \frac{dy}{dx} + P(x)y^{1-n} = Q(x)y−ndxdy​+P(x)y1−n=Q(x)。
  2. 令 z=y1−nz = y^{1-n}z=y1−n，则 dzdx=(1−n)y−ndydx\frac{dz}{dx} = (1-n)y^{-n} \frac{dy}{dx}dxdz​=(1−n)y−ndxdy​。
  3. 代入原式，化为关于 zzz 的一阶线性微分方程：11−ndzdx+P(x)z=Q(x)\frac{1}{1-n} \frac{dz}{dx} + P(x)z = Q(x)1−n1​dxdz​+P(x)z=Q(x)。

2. 全微分方程 (Exact Equation)​

形式：M(x,y)dx+N(x,y)dy=0M(x, y)dx + N(x, y)dy = 0M(x,y)dx+N(x,y)dy=0。 判别条件：如果区域内满足 ∂M∂y=∂N∂x\frac{\partial M}{\partial y} = \frac{\partial N}{\partial x}∂y∂M​=∂x∂N​，则方程是全微分的。 解法： 寻找函数 u(x,y)u(x, y)u(x,y) 使得 du=Mdx+Ndy=0du = Mdx + Ndy = 0du=Mdx+Ndy=0，则通解为 u(x,y)=Cu(x, y) = Cu(x,y)=C。 计算公式：u(x,y)=∫x0xM(t,y)dt+∫y0yN(x0,t)dtu(x, y) = \int_{x_0}^x M(t, y) dt + \int_{y_0}^y N(x_0, t) dtu(x,y)=∫x0​x​M(t,y)dt+∫y0​y​N(x0​,t)dt。

全微分化的“点金石”：积分因子

若方程不满足全微分条件，有时可乘以一个因子 μ(x,y)\mu(x, y)μ(x,y) 使其变为全微分方程。例如，若 1N(∂M∂y−∂N∂x)\frac{1}{N}(\frac{\partial M}{\partial y} - \frac{\partial N}{\partial x})N1​(∂y∂M​−∂x∂N​) 仅是 xxx 的函数 f(x)f(x)f(x)，则积分因子为 μ(x)=e∫f(x)dx\mu(x) = e^{\int f(x)dx}μ(x)=e∫f(x)dx。

二、 可降阶的高阶方程​

对于某些特殊的高阶方程，可以通过变量代换将其化为低阶方程求解。

1. y(n)=f(x)y^{(n)} = f(x)y(n)=f(x) 型​

这类方程只需通过连续积分 nnn 次即可求解。通解包含 nnn 个任意常数。

2. 不显含 yyy 的方程：F(x,y′,y′′)=0F(x, y', y'') = 0F(x,y′,y′′)=0​

方法：令 p=y′p = y'p=y′，则 y′′=dpdxy'' = \frac{dp}{dx}y′′=dxdp​。 方程变为关于 ppp 的一阶方程 F(x,p,dpdx)=0F(x, p, \frac{dp}{dx}) = 0F(x,p,dxdp​)=0。求出 p(x,C1)p(x, C_1)p(x,C1​) 后，再通过 y=∫pdx+C2y = \int p dx + C_2y=∫pdx+C2​ 得到原函数的解。

3. 不显含 xxx 的方程：F(y,y′,y′′)=0F(y, y', y'') = 0F(y,y′,y′′)=0​

方法：令 p=y′p = y'p=y′，将 yyy 视为自变量。 利用复合函数求导法则：y′′=dpdx=dpdy⋅dydx=pdpdyy'' = \frac{dp}{dx} = \frac{dp}{dy} \cdot \frac{dy}{dx} = p \frac{dp}{dy}y′′=dxdp​=dydp​⋅dxdy​=pdydp​。 原方程化为关于 ppp 和 yyy 的一阶方程 F(y,p,pdpdy)=0F(y, p, p \frac{dp}{dy}) = 0F(y,p,pdydp​)=0。

三、 高阶线性微分方程​

1. 解空间结构​

对于 nnn 阶齐次线性方程 L[y]=y(n)+pn−1(x)y(n−1)+⋯+p0(x)y=0L[y] = y^{(n)} + p_{n-1}(x)y^{(n-1)} + \dots + p_0(x)y = 0L[y]=y(n)+pn−1​(x)y(n−1)+⋯+p0​(x)y=0：

  • 解空间的维度：方程的所有解构成一个 nnn 维向量空间。
  • 线性无关判别：使用 Wronski 行列式 W(x)W(x)W(x)。若 W(x)≠0W(x) \neq 0W(x)=0，则解组线性无关。

3. 欧拉方程 (Euler Equation)​

形式：xny(n)+an−1xn−1y(n−1)+⋯+a0y=f(x)x^n y^{(n)} + a_{n-1} x^{n-1} y^{(n-1)} + \dots + a_0 y = f(x)xny(n)+an−1​xn−1y(n−1)+⋯+a0​y=f(x)。 解法：引入变换 x=etx = e^tx=et，化为常系数方程。

四、 常微分方程组 (Systems of ODEs)​

在复杂系统中，变量间往往相互耦合。我们主要研究一阶方程组。

1. 一阶齐次线性方程组​

形式：y′=Ay\mathbf{y}' = A\mathbf{y}y′=Ay，其中 AAA 为常数矩阵。 通解构造：

  1. 不同实特征值：若有 nnn 个实特征值 λi\lambda_iλi​ 和线性无关的特征向量 vi\mathbf{v}_ivi​，通解为 y=∑Civieλit\mathbf{y} = \sum C_i \mathbf{v}_i e^{ \lambda_i t}y=∑Ci​vi​eλi​t。
  2. 复特征值：若特征值为 α±βi\alpha \pm \beta iα±βi，对应特征向量为 a±bi\mathbf{a} \pm \mathbf{b}ia±bi，则产生两个实值解： y1=eαt(acos⁡βt−bsin⁡βt)\mathbf{y}_1 = e^{\alpha t}(\mathbf{a} \cos \beta t - \mathbf{b} \sin \beta t)y1​=eαt(acosβt−bsinβt) y2=eαt(asin⁡βt+bcos⁡βt)\mathbf{y}_2 = e^{\alpha t}(\mathbf{a} \sin \beta t + \mathbf{b} \cos \beta t)y2​=eαt(asinβt+bcosβt)

3. 非齐次线性方程组​

形式：y′=Ay+g(t)\mathbf{y}' = A\mathbf{y} + \mathbf{g}(t)y′=Ay+g(t)。 常数变易法公式： y(t)=eAty0+∫0teA(t−s)g(s)ds\mathbf{y}(t) = e^{At}\mathbf{y}_0 + \int_0^t e^{A(t-s)}\mathbf{g}(s) dsy(t)=eAty0​+∫0t​eA(t−s)g(s)ds

五、 稳定性理论初步 (Stability Theory)​

稳定性研究的是：当初始条件发生微小扰动时，系统的解在无穷远处的行为。

1. 平衡点 (Equilibrium Points)​

对于自治系统 dxdt=f(x)\frac{d\mathbf{x}}{dt} = \mathbf{f}(\mathbf{x})dtdx​=f(x)，满足 f(x∗)=0\mathbf{f}(\mathbf{x}^*) = 0f(x∗)=0 的点 x∗\mathbf{x}^*x∗ 称为平衡点（或奇点）。

2. 稳定性定义 (Liapunov Stability)​

  • 稳定 (Stable)：若对任意 ϵ>0\epsilon > 0ϵ>0，存在 δ>0\delta > 0δ>0，使得当 ∥x(0)−x∗∥<δ\|\mathbf{x}(0) - \mathbf{x}^*\| < \delta∥x(0)−x∗∥<δ 时，对所有 t≥0t \ge 0t≥0 均有 ∥x(t)−x∗∥<ϵ\|\mathbf{x}(t) - \mathbf{x}^*\| < \epsilon∥x(t)−x∗∥<ϵ。
  • 渐近稳定 (Asymptotically Stable)：首先是稳定的，且 lim⁡t→∞x(t)=x∗\lim_{t \to \infty} \mathbf{x}(t) = \mathbf{x}^*limt→∞​x(t)=x∗。
  • 不稳定 (Unstable)：非稳定的点。

3. 二阶线性系统的平衡点分类​

考虑 x′=Ax\mathbf{x}' = A\mathbf{x}x′=Ax，令 λ1,λ2\lambda_1, \lambda_2λ1​,λ2​ 为 AAA 的特征值：

  1. λ1,λ2<0\lambda_1, \lambda_2 < 0λ1​,λ2​<0 (或 Re(λ)<0\text{Re}(\lambda) < 0Re(λ)<0)：稳定结点/焦点（渐近稳定）。
  2. λ1,λ2>0\lambda_1, \lambda_2 > 0λ1​,λ2​>0 (或 Re(λ)>0\text{Re}(\lambda) > 0Re(λ)>0)：不稳定结点/焦点（不稳定）。
  3. λ1<0<λ2\lambda_1 < 0 < \lambda_2λ1​<0<λ2​：鞍点 (Saddle Point)（不稳定）。
  4. λ=±βi\lambda = \pm \beta iλ=±βi (纯虚根)：中心点 (Center)（稳定，但非渐近稳定）。
线性化原则

对于非线性系统 x′=f(x)\mathbf{x}' = \mathbf{f}(\mathbf{x})x′=f(x)，在其平衡点 x∗\mathbf{x}^*x∗ 处的稳定性通常可以通过考察其 Jacobian 矩阵 J=∂f∂x∣x∗J = \frac{\partial \mathbf{f}}{\partial \mathbf{x}}|_{\mathbf{x}^*}J=∂x∂f​∣x∗​ 的特征值来判定。
