第十二章 数项级数 (Numerical Series)

级数是分析学中处理无限求和问题的核心工具，是连接离散与连续、代数与分析的桥梁。本节重点讨论数项级数的敛散性判别及其分析性质。

1. 数项级数基本概念​

对于数列 {an}\{a_n\}{an​}，其无限求和 ∑n=1∞an\sum_{n=1}^\infty a_n∑n=1∞​an​ 称为 数项级数。

  • 部分和：Sn=∑i=1naiS_n = \sum_{i=1}^n a_iSn​=∑i=1n​ai​。
  • 收敛性：若 lim⁡n→∞Sn=S\lim_{n \to \infty} S_n = Slimn→∞​Sn​=S 存在（有限），则级数收敛，称 SSS 为其和；否则级数发散。
  • 必要条件：若 ∑an\sum a_n∑an​ 收敛，则 lim⁡n→∞an=0\lim_{n \to \infty} a_n = 0limn→∞​an​=0。（注意：逆命题不成立，如调和级数 ∑1n\sum \frac{1}{n}∑n1​）。
  • 柯西收敛准则：∑an\sum a_n∑an​ 收敛   ⟺  ∀ϵ>0,∃N,∀n>N,∀p∈N+,∣an+1+⋯+an+p∣<ϵ\iff \forall \epsilon > 0, \exists N, \forall n > N, \forall p \in \mathbb{N}_+, |a_{n+1} + \dots + a_{n+p}| < \epsilon⟺∀ϵ>0,∃N,∀n>N,∀p∈N+​,∣an+1​+⋯+an+p​∣<ϵ。

2. 正项级数判别法 (Positive Term Series)​

若 an≥0a_n \geq 0an​≥0，则级数 ∑an\sum a_n∑an​ 的敛散性判别有如下工具：

2.1 比较判别法 (Comparison Test)​

设 0≤an≤bn0 \leq a_n \leq b_n0≤an​≤bn​：

  • 若 ∑bn\sum b_n∑bn​ 收敛，则 ∑an\sum a_n∑an​ 收敛；
  • 若 ∑an\sum a_n∑an​ 发散，则 ∑bn\sum b_n∑bn​ 发散。
极限形式 (Limit Comparison Test)

若 lim⁡n→∞anbn=l\lim_{n \to \infty} \frac{a_n}{b_n} = llimn→∞​bn​an​​=l：

  • 0<l<∞0 < l < \infty0<l<∞：∑an\sum a_n∑an​ 与 ∑bn\sum b_n∑bn​ 同敛散；
  • l=0l = 0l=0：∑bn\sum b_n∑bn​ 收敛   ⟹  ∑an\implies \sum a_n⟹∑an​ 收敛；
  • l=∞l = \inftyl=∞：∑bn\sum b_n∑bn​ 发散   ⟹  ∑an\implies \sum a_n⟹∑an​ 发散。

2.2 比值与根值判别法​

  • 比值判别法 (D'Alembert)：设 r=lim⁡n→∞an+1anr = \lim_{n \to \infty} \frac{a_{n+1}}{a_n}r=limn→∞​an​an+1​​。
    • r<1r < 1r<1 收敛；r>1r > 1r>1 发散；r=1r = 1r=1 失效。
  • 根值判别法 (Cauchy)：设 ρ=lim⁡n→∞ann\rho = \lim_{n \to \infty} \sqrt[n]{a_n}ρ=limn→∞​nan​​。
    • ρ<1\rho < 1ρ<1 收敛；ρ>1\rho > 1ρ>1 发散；ρ=1\rho = 1ρ=1 失效。

注意：根值判别法的适用范围比比值判别法更广（若比值极限存在，则根值极限必存在且相等）。

2.3 积分判别法 (Integral Test)​

若 f(x)f(x)f(x) 是 [1,∞)[1, \infty)[1,∞) 上的非负、递减连续函数，且 f(n)=anf(n) = a_nf(n)=an​，则： ∑n=1∞an 收敛  ⟺  ∫1∞f(x)dx 收敛\sum_{n=1}^\infty a_n \text{ 收敛} \iff \int_1^\infty f(x) dx \text{ 收敛}∑n=1∞​an​ 收敛⟺∫1∞​f(x)dx 收敛

余项估计

若级数收敛，其余项 Rn=∑k=n+1∞akR_n = \sum_{k=n+1}^\infty a_kRn​=∑k=n+1∞​ak​ 满足： ∫n+1∞f(x)dx≤Rn≤∫n∞f(x)dx\int_{n+1}^\infty f(x) dx \leq R_n \leq \int_n^\infty f(x) dx∫n+1∞​f(x)dx≤Rn​≤∫n∞​f(x)dx

2.4 Raabe 判别法 (深度扩展)​

当比值判别法失效（r=1r=1r=1）时，Raabe 判别法通过更高阶的渐近分析给出结论： 设 K=lim⁡n→∞n(anan+1−1)K = \lim_{n \to \infty} n \left( \frac{a_n}{a_{n+1}} - 1 \right)K=limn→∞​n(an+1​an​​−1)。

  • K>1K > 1K>1：级数收敛。
  • K<1K < 1K<1：级数发散。
  • K=1K = 1K=1：失效（需更精细的判别法，如 Gauss 判别法）。

2.5 Gauss 判别法 (完备化工具)​

若正项级数满足： anan+1=1+μn+θnn1+λ(λ>0,∣θn∣ 有界)\frac{a_n}{a_{n+1}} = 1 + \frac{\mu}{n} + \frac{\theta_n}{n^{1+\lambda}} \quad (\lambda > 0, |\theta_n| \text{ 有界})an+1​an​​=1+nμ​+n1+λθn​​(λ>0,∣θn​∣ 有界)

  • 若 μ>1\mu > 1μ>1，级数收敛。
  • 若 μ≤1\mu \leq 1μ≤1，级数发散。

Gauss 判别法是处理超几何级数等复杂项级数的终极利器，它涵盖了比值法与 Raabe 法。

3. 变号级数 (Series with Arbitrary Terms)​

3.1 交错级数与 Leibniz 判别法​

形如 ∑(−1)n−1an\sum (-1)^{n-1} a_n∑(−1)n−1an​ (an>0a_n > 0an​>0) 的级数。若 {an}\{a_n\}{an​} 单调不增且趋于 0，则级数收敛。

3.2 绝对收敛与条件收敛​

  • 绝对收敛：∑∣an∣\sum |a_n|∑∣an​∣ 收敛。绝对收敛级数具有类似于有限和的优良性质（如可交换性、乘法性质）。
  • 条件收敛：∑an\sum a_n∑an​ 收敛但 ∑∣an∣\sum |a_n|∑∣an​∣ 发散。
Riemann 重排定理 (Riemann Rearrangement Theorem)

若级数 ∑an\sum a_n∑an​ 条件收敛，则对于任意实数 SSS（包括 ±∞\pm\infty±∞），必存在一种重排方式，使得重排后的级数和为 SSS。

3.3 级数的乘积 (Cauchy Product)​

设 A=∑n=0∞an,B=∑n=0∞bnA = \sum_{n=0}^\infty a_n, B = \sum_{n=0}^\infty b_nA=∑n=0∞​an​,B=∑n=0∞​bn​。定义其 Cauchy 乘积为 ∑n=0∞cn\sum_{n=0}^\infty c_n∑n=0∞​cn​，其中 cn=∑k=0nakbn−kc_n = \sum_{k=0}^n a_k b_{n-k}cn​=∑k=0n​ak​bn−k​。

  • Mertens 定理：若两级数至少有一个绝对收敛，且另一个收敛，则其 Cauchy 乘积收敛于 ABABAB。
  • 若两个级数都绝对收敛，则其乘积也绝对收敛。
