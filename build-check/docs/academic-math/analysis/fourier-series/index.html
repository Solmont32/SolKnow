Fourier 级数 (Fourier Series)

Fourier 级数（傅里叶级数）是分析学中处理周期现象的核心工具。它的基本思想是：任何符合一定条件的周期函数，都可以表示为一系列正弦和余弦函数的叠加。这一理论不仅在纯数学（如偏微分方程、数论）中至关重要，也是现代信号处理、量子力学及通信工程的数学基石。

1. Fourier 系数与三角级数​

1.1 正交函数系​

三角函数系 {1,cos⁡x,sin⁡x,cos⁡2x,sin⁡2x,…,cos⁡nx,sin⁡nx,… }\{1, \cos x, \sin x, \cos 2x, \sin 2x, \dots, \cos nx, \sin nx, \dots\}{1,cosx,sinx,cos2x,sin2x,…,cosnx,sinnx,…} 在区间 [−π,π][-\pi, \pi][−π,π] 上具有 正交性：

  • ∫−ππcos⁡nxsin⁡mx dx=0\int_{-\pi}^\pi \cos nx \sin mx \, dx = 0∫−ππ​cosnxsinmxdx=0 (对所有 n,mn, mn,m)
  • ∫−ππcos⁡nxcos⁡mx dx={0,n≠mπ,n=m≠02π,n=m=0\int_{-\pi}^\pi \cos nx \cos mx \, dx = \begin{cases} 0, & n \neq m \\ \pi, & n = m \neq 0 \\ 2\pi, & n = m = 0 \end{cases}∫−ππ​cosnxcosmxdx=⎩⎨⎧​0,π,2π,​n=mn=m=0n=m=0​

2. Dirichlet 收敛定理：什么时候可以写等号？​

Fourier 级数是否收敛于 f(x)f(x)f(x) 是一个深刻的问题。Dirichlet 给出了最实用的判定准则。

Dirichlet 收敛定理 (点收敛判定)

若 f(x)f(x)f(x) 是周期为 2π2\pi2π 的函数，且在一个周期内满足以下 Dirichlet 条件：

  1. 分段连续：仅有有限个第一类间断点。
  2. 分段单调：仅有有限个极值点。

则 f(x)f(x)f(x) 的 Fourier 级数 S(x)S(x)S(x) 在每一点 xxx 处均收敛，且： S(x)=f(x+0)+f(x−0)2S(x) = \frac{f(x+0) + f(x-0)}{2}S(x)=2f(x+0)+f(x−0)​

  • 在 连续点 xxx 处，S(x)=f(x)S(x) = f(x)S(x)=f(x)；
  • 在 间断点 xxx 处，S(x)S(x)S(x) 收敛于左右极限的平均值。

2.1 深入解析​

  • 物理直觉：在突变点，级数倾向于取“中间值”，这体现了三角级数作为光滑函数逼近非光滑函数时的平滑特性。
  • 一致收敛性：若 f(x)f(x)f(x) 全线连续且分段光滑，则其余 Fourier 级数在整个实轴上 一致收敛 于 f(x)f(x)f(x)。

3. 正弦级数、余弦级数与周期延拓​

对于定义在 [0,π][0, \pi][0,π] 上的非周期函数 f(x)f(x)f(x)，我们可以通过 延拓 将其展开。

3.1 奇延拓 (Odd Extension) →\to→ 正弦级数​

定义 F(x)={f(x),0≤x≤π−f(−x),−π≤x<0F(x) = \begin{cases} f(x), & 0 \le x \le \pi \\ -f(-x), & -\pi \le x < 0 \end{cases}F(x)={f(x),−f(−x),​0≤x≤π−π≤x<0​。 此时 an=0a_n = 0an​=0，级数仅包含正弦项： f(x)∼∑n=1∞bnsin⁡nx,bn=2π∫0πf(x)sin⁡nx dxf(x) \sim \sum_{n=1}^\infty b_n \sin nx, \quad b_n = \frac{2}{\pi} \int_0^\pi f(x) \sin nx \, dxf(x)∼∑n=1∞​bn​sinnx,bn​=π2​∫0π​f(x)sinnxdx

3.2 偶延拓 (Even Extension) →\to→ 余弦级数​

定义 F(x)={f(x),0≤x≤πf(−x),−π≤x<0F(x) = \begin{cases} f(x), & 0 \le x \le \pi \\ f(-x), & -\pi \le x < 0 \end{cases}F(x)={f(x),f(−x),​0≤x≤π−π≤x<0​。 此时 bn=0b_n = 0bn​=0，级数仅包含常数项和余弦项： f(x)∼a02+∑n=1∞ancos⁡nx,an=2π∫0πf(x)cos⁡nx dxf(x) \sim \frac{a_0}{2} + \sum_{n=1}^\infty a_n \cos nx, \quad a_n = \frac{2}{\pi} \int_0^\pi f(x) \cos nx \, dxf(x)∼2a0​​+∑n=1∞​an​cosnx,an​=π2​∫0π​f(x)cosnxdx

3.3 复杂非周期函数的处理​

若函数定义在 [a,b][a, b][a,b] 上，通常先平移至 [0,L][0, L][0,L]，再根据需要进行周期延拓。

  • 普通周期延拓：直接令 f(x+L)=f(x)f(x+L) = f(x)f(x+L)=f(x)，通常在端点处会引入间断。
  • 反射延拓：如上述奇/偶延拓，通常能保持端点的连续性，从而提高收敛速度。

4. Gibbs 现象：逼近的代价​

当 f(x)f(x)f(x) 存在跳变间断点时，Fourier 级数的部分和 SN(x)S_N(x)SN​(x) 在间断点附近会产生“振荡”和“过冲”。

4.1 数学刻画​

设 f(x)f(x)f(x) 在 x0x_0x0​ 处有一个跳变间断点，跳变高度为 h=∣f(x0+0)−f(x0−0)∣h = |f(x_0+0) - f(x_0-0)|h=∣f(x0​+0)−f(x0​−0)∣。其第 NNN 阶部分和 SN(x)S_N(x)SN​(x) 在 x0x_0x0​ 附近的第一个极大值与函数值之差趋于： lim⁡N→∞SN(xmax)=f(x0+0)+h2[2π∫0πsin⁡ttdt−1]\lim_{N \to \infty} S_N(x_{max}) = f(x_0+0) + \frac{h}{2} \left[ \frac{2}{\pi} \int_0^\pi \frac{\sin t}{t} dt - 1 \right]limN→∞​SN​(xmax​)=f(x0​+0)+2h​[π2​∫0π​tsint​dt−1] 其中常量 G=2πSi(π)≈1.17897…G = \frac{2}{\pi} \text{Si}(\pi) \approx 1.17897 \dotsG=π2​Si(π)≈1.17897…。

  • 过冲百分比：(G−1)/2≈0.08949⋯≈9%(G - 1) / 2 \approx 0.08949 \dots \approx 9\%(G−1)/2≈0.08949⋯≈9%。
  • 本质分析：Gibbs 现象揭示了用光滑正交基逼近非光滑信号时的能量分布特性。即使增加谐波项数，过冲幅度也不会消失，仅是过冲点向间断点无限靠拢。这体现了 L2L^2L2 空间均方收敛并不保证点态一致收敛。
工程视角

在图像处理中，Gibbs 现象表现为“振铃效应”(Ringing artifacts)。在 JPEG 压缩等频域算法中，必须通过窗函数 (Windowing) 或低通滤波来抑制这种由于频谱截断引起的伪影。

5. Parseval 等式：能量守恒定律​

从 Hilbert 空间的视角看，Fourier 展开是正交基下的投影。

5.1 Parseval 公式​

若 f(x)f(x)f(x) 在 [−π,π][-\pi, \pi][−π,π] 上平方可积，则其平均功率等于各谐波分量功率之和： 1π∫−ππ∣f(x)∣2dx=a022+∑n=1∞(an2+bn2)\frac{1}{\pi} \int_{-\pi}^\pi |f(x)|^2 dx = \frac{a_0^2}{2} + \sum_{n=1}^\infty (a_n^2 + b_n^2)π1​∫−ππ​∣f(x)∣2dx=2a02​​+∑n=1∞​(an2​+bn2​)

5.2 应用价值​

  1. 求级数和：它是计算如 ∑1n2,∑1n4\sum \frac{1}{n^2}, \sum \frac{1}{n^4}∑n21​,∑n41​ 等数项级数的强力工具。
  2. 误差分析：用于评估用前 NNN 项逼近原函数时的均方误差。
