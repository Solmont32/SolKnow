第十七章 多元函数微分学

多元函数微分学的核心思想是局部线性化。我们将一元微积分中的导数和微分概念推广到高维空间，研究函数在各个方向上的变化率以及最优线性逼近。

一、 偏导数与全微分​

1. 偏导数 (Partial Derivatives)​

设 z=f(x,y)z = f(x, y)z=f(x,y) 在点 (x0,y0)(x_0, y_0)(x0​,y0​) 的邻域内有定义。固定 y=y0y = y_0y=y0​，定义： fx(x0,y0)=lim⁡Δx→0f(x0+Δx,y0)−f(x0,y0)Δxf_x(x_0, y_0) = \lim_{\Delta x \to 0} \frac{f(x_0 + \Delta x, y_0) - f(x_0, y_0)}{\Delta x}fx​(x0​,y0​)=limΔx→0​Δxf(x0​+Δx,y0​)−f(x0​,y0​)​ 这是函数沿坐标轴方向的变化率。

2. 全微分 (Total Differential)​

定义：若函数增量可表示为 Δz=AΔx+BΔy+o(ρ)\Delta z = A \Delta x + B \Delta y + o(\rho)Δz=AΔx+BΔy+o(ρ)，其中 ρ=(Δx)2+(Δy)2\rho = \sqrt{(\Delta x)^2 + (\Delta y)^2}ρ=(Δx)2+(Δy)2​，则称函数在点 (x,y)(x, y)(x,y) 可微。

全微分存在性判定“四步走”​

判定一个多元函数在某点 (x0,y0)(x_0, y_0)(x0​,y0​) 是否可微，通常遵循以下严谨步骤：

  1. 连续性检验（必要条件）：若函数在该点不连续，则必不可微。
  2. 求偏导数：利用定义求出 fx(x0,y0)f_x(x_0, y_0)fx​(x0​,y0​) 和 fy(x0,y0)f_y(x_0, y_0)fy​(x0​,y0​)。若偏导数不存在，则必不可微。
  3. 构造线性增量：写出全增量 Δz=f(x0+Δx,y0+Δy)−f(x0,y0)\Delta z = f(x_0+\Delta x, y_0+\Delta y) - f(x_0, y_0)Δz=f(x0​+Δx,y0​+Δy)−f(x0​,y0​)。
  4. 极限判定（充分必要条件）：计算以下极限： lim⁡(Δx,Δy)→(0,0)Δz−[fx(x0,y0)Δx+fy(x0,y0)Δy](Δx)2+(Δy)2\lim_{(\Delta x, \Delta y) \to (0, 0)} \frac{\Delta z - [f_x(x_0, y_0)\Delta x + f_y(x_0, y_0)\Delta y]}{\sqrt{(\Delta x)^2 + (\Delta y)^2}}lim(Δx,Δy)→(0,0)​(Δx)2+(Δy)2​Δz−[fx​(x0​,y0​)Δx+fy​(x0​,y0​)Δy]​ 若极限为 000，则可微；否则不可微。

关键定理回顾：

  • 必要条件：可微 ⇒\Rightarrow⇒ 连续 且 偏导数存在。
  • 充分条件：偏导数在点 (x,y)(x, y)(x,y) 连续 ⇒\Rightarrow⇒ 函数在该点可微。
  • 注意：偏导数存在并不意味着函数连续，更不意味着可微。

经典反例：偏导数存在但不可微​

考虑函数： f(x,y)={xyx2+y2,(x,y)≠(0,0)0,(x,y)=(0,0)f(x, y) = \begin{cases} \frac{xy}{\sqrt{x^2+y^2}}, & (x, y) \neq (0, 0) \\ 0, & (x, y) = (0, 0) \end{cases}f(x,y)={x2+y2​xy​,0,​(x,y)=(0,0)(x,y)=(0,0)​

  • 偏导数：利用定义可算得 fx(0,0)=0,fy(0,0)=0f_x(0,0)=0, f_y(0,0)=0fx​(0,0)=0,fy​(0,0)=0。
  • 全微分判定： lim⁡(Δx,Δy)→(0,0)ΔxΔy(Δx)2+(Δy)2−0(Δx)2+(Δy)2=lim⁡ρ→0ρ2cos⁡θsin⁡θρ2=cos⁡θsin⁡θ\lim_{(\Delta x, \Delta y) \to (0, 0)} \frac{\frac{\Delta x \Delta y}{\sqrt{(\Delta x)^2+(\Delta y)^2}} - 0}{\sqrt{(\Delta x)^2+(\Delta y)^2}} = \lim_{\rho \to 0} \frac{\rho^2 \cos \theta \sin \theta}{\rho^2} = \cos \theta \sin \thetalim(Δx,Δy)→(0,0)​(Δx)2+(Δy)2​(Δx)2+(Δy)2​ΔxΔy​−0​=limρ→0​ρ2ρ2cosθsinθ​=cosθsinθ 极限随角度 θ\thetaθ 变化而不为 000，故在该点不可微。

二、 复合函数求导与高阶导数​

1. 链式法则 (Chain Rule)​

设 z=f(u,v)z = f(u, v)z=f(u,v)，u=ϕ(x,y)u = \phi(x, y)u=ϕ(x,y)，v=ψ(x,y)v = \psi(x, y)v=ψ(x,y)，则： ∂z∂x=∂z∂u∂u∂x+∂z∂v∂v∂x\frac{\partial z}{\partial x} = \frac{\partial z}{\partial u} \frac{\partial u}{\partial x} + \frac{\partial z}{\partial v} \frac{\partial v}{\partial x}∂x∂z​=∂u∂z​∂x∂u​+∂v∂z​∂x∂v​

2. 高阶偏导数与 Clairaut 定理​

若混合偏导数 fxyf_{xy}fxy​ 与 fyxf_{yx}fyx​ 连续，则它们相等：fxy=fyxf_{xy} = f_{yx}fxy​=fyx​。

三、 方向导数与梯度 (Directional Derivative & Gradient)​

1. 方向导数​

函数 fff 沿方向 l=(cos⁡α,cos⁡β)\mathbf{l} = (\cos \alpha, \cos \beta)l=(cosα,cosβ) 的变化率： ∂f∂l=fxcos⁡α+fycos⁡β\frac{\partial f}{\partial l} = f_x \cos \alpha + f_y \cos \beta∂l∂f​=fx​cosα+fy​cosβ

2. 梯度 (Gradient)​

向量 ∇f=(fx,fy)\nabla f = (f_x, f_y)∇f=(fx​,fy​) 称为梯度。

  • 物理意义：梯度方向是函数增加最快的方向，其模长是最大变化率。

四、 多元 Taylor 公式 (Taylor's Formula)​

深度例题 1：利用 Taylor 展开求极值​
