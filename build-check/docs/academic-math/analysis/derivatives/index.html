导数与微分：瞬时变化的数学显微镜

微积分的核心思想是以直代曲、以恒定代变化。导数正是寻找这条“切线”的工具，而微分则是利用这条切线进行局部线性逼近的理论基础。本章将从定义出发，深入探讨求导法则。

一、 导数与微分的核心理论​

1. 导数的严格定义​

2. 微分的概念​

如果函数在点 x0x_0x0​ 处的增量可以表示为： Δy=AΔx+o(Δx)\Delta y = A \Delta x + o(\Delta x)Δy=AΔx+o(Δx) （其中 AAA 是与 Δx\Delta xΔx 无关的常数），则称函数在该点可微，并且称 AΔxA \Delta xAΔx 为函数的微分，记作 dydydy。 核心结论：一元函数可导与可微是等价的，且 A=f′(x0)A = f'(x_0)A=f′(x0​)，即 dy=f′(x0)dxdy = f'(x_0) dxdy=f′(x0​)dx。 几何意义：导数是切线的斜率，微分 dydydy 是切线上纵坐标的增量，而 Δy\Delta yΔy 是曲线上纵坐标的增量。当 Δx\Delta xΔx 很小时，dy≈Δydy \approx \Delta ydy≈Δy（以直代曲）。

3. 高阶导数与莱布尼茨公式​

如果导函数 f′(x)f'(x)f′(x) 依然可导，其导数称为二阶导数 f′′(x)f''(x)f′′(x)。依此类推可得 nnn 阶导数 f(n)(x)f^{(n)}(x)f(n)(x)。 两个函数的乘积的 nnn 阶导数（莱布尼茨公式）： (uv)(n)=∑k=0n(nk)u(n−k)v(k)(uv)^{(n)} = \sum_{k=0}^n \binom{n}{k} u^{(n-k)} v^{(k)}(uv)(n)=∑k=0n​(kn​)u(n−k)v(k) 形式上与二项式定理完全一致。
