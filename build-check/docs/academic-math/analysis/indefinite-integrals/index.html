不定积分：寻找反导数的艺术

如果说微分是把一个复杂的整体拆解为无穷小的碎片，那么积分就是将这些碎片重新拼装。不定积分作为求导的逆运算，是整个积分学的基石。与求导的机械化法则不同，求不定积分是一项充满创造性和试错的“艺术”。

一、 核心理论与基本方法​

1. 原函数与不定积分的定义​

原函数：如果在区间 III 上，对于任意 xxx 都有 F′(x)=f(x)F'(x) = f(x)F′(x)=f(x) 或 dF(x)=f(x)dxdF(x) = f(x)dxdF(x)=f(x)dx，则称 F(x)F(x)F(x) 为 f(x)f(x)f(x) 在该区间上的一个原函数。 不定积分：函数 f(x)f(x)f(x) 的所有原函数的全体称为 f(x)f(x)f(x) 的不定积分，记作： ∫f(x)dx=F(x)+C\int f(x) dx = F(x) + C∫f(x)dx=F(x)+C 其中 ∫\int∫ 是积分号，f(x)f(x)f(x) 是被积函数，CCC 是任意常数。

核心性质：

  • (∫f(x)dx)′=f(x)(\int f(x) dx)' = f(x)(∫f(x)dx)′=f(x)
  • ∫F′(x)dx=F(x)+C\int F'(x) dx = F(x) + C∫F′(x)dx=F(x)+C
  • 线性性质：∫[af(x)+bg(x)]dx=a∫f(x)dx+b∫g(x)dx\int [a f(x) + b g(x)] dx = a \int f(x) dx + b \int g(x) dx∫[af(x)+bg(x)]dx=a∫f(x)dx+b∫g(x)dx

2. 第一类换元法（凑微分法）​

这是最常用的积分技巧，核心思想是将积分变量与被积函数的一部分结合，凑成一个新变量的微分。 公式：若 ∫f(u)du=F(u)+C\int f(u) du = F(u) + C∫f(u)du=F(u)+C，则： ∫f(ϕ(x))ϕ′(x)dx=∫f(ϕ(x))d(ϕ(x))=F(ϕ(x))+C\int f(\phi(x)) \phi'(x) dx = \int f(\phi(x)) d(\phi(x)) = F(\phi(x)) + C∫f(ϕ(x))ϕ′(x)dx=∫f(ϕ(x))d(ϕ(x))=F(ϕ(x))+C 常见凑微分类型：

  • xdx=12d(x2)x dx = \frac{1}{2} d(x^2)xdx=21​d(x2)
  • 1xdx=d(ln⁡∣x∣)\frac{1}{x} dx = d(\ln|x|)x1​dx=d(ln∣x∣)
  • cos⁡xdx=d(sin⁡x)\cos x dx = d(\sin x)cosxdx=d(sinx)
  • exdx=d(ex)e^x dx = d(e^x)exdx=d(ex)

3. 第二类换元法 (Integration by Substitution)​

当凑微分法失效，特别是遇到复杂的根式或分式时，我们主动引入一个新变量 x=ψ(t)x = \psi(t)x=ψ(t)。 常用代换类型：

  1. 三角代换：
    • 遇到 a2−x2\sqrt{a^2 - x^2}a2−x2​，令 x=asin⁡tx = a \sin tx=asint。
    • 遇到 x2+a2\sqrt{x^2 + a^2}x2+a2​，令 x=atan⁡tx = a \tan tx=atant。
    • 遇到 x2−a2\sqrt{x^2 - a^2}x2−a2​，令 x=asec⁡tx = a \sec tx=asect。
  2. 倒代换 (x=1/tx = 1/tx=1/t)：常用于分母次数显著高于分子的情形。
  3. 根式代换：令 t=ax+bnt = \sqrt[n]{ax+b}t=nax+b​ 或 t=ax+bcx+dnt = \sqrt[n]{\frac{ax+b}{cx+d}}t=ncx+dax+b​​ 消去根号。

4. 分部积分法 (Integration by Parts)​

源于乘积的求导法则 (uv)′=u′v+uv′(uv)' = u'v + uv'(uv)′=u′v+uv′。 公式： ∫udv=uv−∫vdu\int u dv = uv - \int v du∫udv=uv−∫vdu 核心技巧：

  • LIATE 法则：优先选反对幂三指作为 uuu。
  • 循环型：如 ∫eaxsin⁡bxdx\int e^{ax} \sin bx dx∫eaxsinbxdx，需两次分部积分后移项求解。
  • 递推型：用于求解含 nnn 次幂的积分（如 In=∫sin⁡nxdxI_n = \int \sin^n x dxIn​=∫sinnxdx）。
原函数存在定理

并非所有函数都有原函数。连续函数一定有原函数。但即便有原函数，也未必能用“初等函数”表示出来（如 ∫e−x2dx,∫sin⁡xxdx\int e^{-x^2} dx, \int \frac{\sin x}{x} dx∫e−x2dx,∫xsinx​dx 等著名的“积不出”函数）。

二、 有理函数与特殊函数积分技巧​

1. 有理函数积分 (Rational Functions)​

对于 R(x)=P(x)Q(x)R(x) = \frac{P(x)}{Q(x)}R(x)=Q(x)P(x)​：

  1. 化为真分式：若 deg⁡(P)≥deg⁡(Q)\deg(P) \ge \deg(Q)deg(P)≥deg(Q)，先进行多项式除法。

  2. 部分分式分解：根据 Q(x)Q(x)Q(x) 的因式分解（实数域内必可分解为一次项与二次项之积）：

    • 1(x−a)k→A1x−a+⋯+Ak(x−a)k\frac{1}{(x-a)^k} \to \frac{A_1}{x-a} + \dots + \frac{A_k}{(x-a)^k}(x−a)k1​→x−aA1​​+⋯+(x−a)kAk​​
    • Mx+N(x2+px+q)k→\frac{Mx+N}{(x^2+px+q)^k} \to(x2+px+q)kMx+N​→ 利用配方化为 ∫dt(t2+1)k\int \frac{dt}{(t^2+1)^k}∫(t2+1)kdt​ 类型。

  3. Hermite-Ostrogradsky 方法： 当分母 Q(x)Q(x)Q(x) 含有高次重根时，部分分式分解极其繁琐。利用此方法可将积分写为： ∫P(x)Q(x)dx=P1(x)Q1(x)+∫P2(x)Q2(x)dx\int \frac{P(x)}{Q(x)} dx = \frac{P_1(x)}{Q_1(x)} + \int \frac{P_2(x)}{Q_2(x)} dx∫Q(x)P(x)​dx=Q1​(x)P1​(x)​+∫Q2​(x)P2​(x)​dx 其中：

    • Q1(x)=gcd⁡(Q(x),Q′(x))Q_1(x) = \gcd(Q(x), Q'(x))Q1​(x)=gcd(Q(x),Q′(x))（包含所有重因式，但次数减1）。
    • Q2(x)=Q(x)/Q1(x)Q_2(x) = Q(x) / Q_1(x)Q2​(x)=Q(x)/Q1​(x)（包含所有因式，但均为单因式）。
    • P1(x),P2(x)P_1(x), P_2(x)P1​(x),P2​(x) 为待定系数多项式，deg⁡(P1)<deg⁡(Q1),deg⁡(P2)<deg⁡(Q2)\deg(P_1) < \deg(Q_1), \deg(P_2) < \deg(Q_2)deg(P1​)<deg(Q1​),deg(P2​)<deg(Q2​)。 步骤：对等式两边求导，利用待定系数法求解 P1,P2P_1, P_2P1​,P2​。这避免了对高次幂部分的直接积分。

2. 三角函数有理式技巧 (Trigonometric Rational Expressions)​

对于 ∫R(sin⁡x,cos⁡x)dx\int R(\sin x, \cos x) dx∫R(sinx,cosx)dx：

  1. 万能代换 (Universal Substitution)：令 t=tan⁡x2t = \tan \frac{x}{2}t=tan2x​，则 sin⁡x=2t1+t2,cos⁡x=1−t21+t2,dx=2dt1+t2\sin x = \frac{2t}{1+t^2}, \cos x = \frac{1-t^2}{1+t^2}, dx = \frac{2 dt}{1+t^2}sinx=1+t22t​,cosx=1+t21−t2​,dx=1+t22dt​。适用于所有情况，但计算量往往最大。
  2. 特殊对称代换：
    • 若 R(−sin⁡x,cos⁡x)=−R(sin⁡x,cos⁡x)R(-\sin x, \cos x) = -R(\sin x, \cos x)R(−sinx,cosx)=−R(sinx,cosx)（关于 sin⁡x\sin xsinx 奇），令 u=cos⁡xu = \cos xu=cosx。
    • 若 R(sin⁡x,−cos⁡x)=−R(sin⁡x,cos⁡x)R(\sin x, -\cos x) = -R(\sin x, \cos x)R(sinx,−cosx)=−R(sinx,cosx)（关于 cos⁡x\cos xcosx 奇），令 u=sin⁡xu = \sin xu=sinx。
    • 若 R(−sin⁡x,−cos⁡x)=R(sin⁡x,cos⁡x)R(-\sin x, -\cos x) = R(\sin x, \cos x)R(−sinx,−cosx)=R(sinx,cosx)（关于 sin⁡x,cos⁡x\sin x, \cos xsinx,cosx 均奇或均偶），令 u=tan⁡xu = \tan xu=tanx。

3. 无理函数积分 (Euler Substitutions)​

对于 ∫R(x,ax2+bx+c)dx\int R(x, \sqrt{ax^2+bx+c}) dx∫R(x,ax2+bx+c​)dx，利用 Euler 代换：

  1. 若 a>0a > 0a>0，令 ax2+bx+c=±ax+t\sqrt{ax^2+bx+c} = \pm \sqrt{a}x + tax2+bx+c​=±a​x+t。
  2. 若 c>0c > 0c>0，令 ax2+bx+c=xt±c\sqrt{ax^2+bx+c} = xt \pm \sqrt{c}ax2+bx+c​=xt±c​。
  3. 若 ax2+bx+c=a(x−x1)(x−x2)ax^2+bx+c = a(x-x_1)(x-x_2)ax2+bx+c=a(x−x1​)(x−x2​)，令 ax2+bx+c=t(x−x1)\sqrt{ax^2+bx+c} = t(x-x_1)ax2+bx+c​=t(x−x1​)。
