反常积分：敛散性判别与 Cauchy 主值

在定积分的定义中，我们要求积分区间是有界的，且被积函数也是有界的。当这两个条件之一不满足时，便产生了反常积分（也称广义积分）。本章将系统讨论反常积分的敛散性判别法及 Cauchy 主值的概念。

一、 基本定义​

1. 无穷限反常积分 (Infinite Interval)​

设 f(x)f(x)f(x) 在 [a,+∞)[a, +\infty)[a,+∞) 上可积。定义： ∫a+∞f(x)dx=lim⁡A→+∞∫aAf(x)dx\int_a^{+\infty} f(x) dx = \lim_{A \to +\infty} \int_a^A f(x) dx∫a+∞​f(x)dx=limA→+∞​∫aA​f(x)dx 若极限存在，称积分收敛；否则称发散。

2. 瑕积分 (Unbounded Function)​

设 f(x)f(x)f(x) 在 (a,b](a, b](a,b] 上可积，但在点 aaa 的右邻域内无界（称 aaa 为瑕点）。定义： ∫abf(x)dx=lim⁡ϵ→0+∫a+ϵbf(x)dx\int_a^b f(x) dx = \lim_{\epsilon \to 0^+} \int_{a+\epsilon}^b f(x) dx∫ab​f(x)dx=limϵ→0+​∫a+ϵb​f(x)dx

二、 非负函数项反常积分的判别法​

对于非负函数 f(x)≥0f(x) \ge 0f(x)≥0，反常积分的收敛性等价于变上限积分的有界性。

1. 比较判别法 (Comparison Test)​

设 0≤f(x)≤g(x)0 \le f(x) \le g(x)0≤f(x)≤g(x)：

  • 若 ∫a+∞g(x)dx\int_a^{+\infty} g(x) dx∫a+∞​g(x)dx 收敛，则 ∫a+∞f(x)dx\int_a^{+\infty} f(x) dx∫a+∞​f(x)dx 收敛。
  • 若 ∫a+∞f(x)dx\int_a^{+\infty} f(x) dx∫a+∞​f(x)dx 发散，则 ∫a+∞g(x)dx\int_a^{+\infty} g(x) dx∫a+∞​g(x)dx 发散。

2. 极限比较判别法 (Limit Comparison Test)​

若 f(x),g(x)>0f(x), g(x) > 0f(x),g(x)>0，且 lim⁡x→+∞f(x)g(x)=L\lim_{x \to +\infty} \frac{f(x)}{g(x)} = Llimx→+∞​g(x)f(x)​=L：

  • 若 0<L<+∞0 < L < +\infty0<L<+∞，则 ∫f\int f∫f 与 ∫g\int g∫g 同敛散。
  • 若 L=0L = 0L=0 且 ∫g\int g∫g 收敛，则 ∫f\int f∫f 收敛。
  • 若 L=+∞L = +\inftyL=+∞ 且 ∫g\int g∫g 发散，则 ∫f\int f∫f 发散。

常用参考函数 (ppp-级数)： ∫a+∞1xpdx\int_a^{+\infty} \frac{1}{x^p} dx∫a+∞​xp1​dx 在 p>1p > 1p>1 时收敛，p≤1p \le 1p≤1 时发散。

四、 Cauchy 主值 (Cauchy Principal Value)​

对于在区间内部有瑕点或无穷区间的积分，若普通的对称极限存在，我们称之为 Cauchy 主值，记作 P.V.∫P.V. \intP.V.∫。

1. 内部瑕点的主值​

若 c∈(a,b)c \in (a, b)c∈(a,b) 是 f(x)f(x)f(x) 的瑕点： P.V.∫abf(x)dx=lim⁡ϵ→0+(∫ac−ϵf(x)dx+∫c+ϵbf(x)dx)P.V. \int_a^b f(x) dx = \lim_{\epsilon \to 0^+} \left( \int_a^{c-\epsilon} f(x) dx + \int_{c+\epsilon}^b f(x) dx \right)P.V.∫ab​f(x)dx=limϵ→0+​(∫ac−ϵ​f(x)dx+∫c+ϵb​f(x)dx)

2. 无穷区间的主值​

P.V.∫−∞+∞f(x)dx=lim⁡A→+∞∫−AAf(x)dxP.V. \int_{-\infty}^{+\infty} f(x) dx = \lim_{A \to +\infty} \int_{-A}^A f(x) dxP.V.∫−∞+∞​f(x)dx=limA→+∞​∫−AA​f(x)dx

注意：积分收敛必有主值存在且相等，但主值存在未必积分收敛（例如 ∫−∞+∞xdx\int_{- \infty}^{+\infty} x dx∫−∞+∞​xdx 发散，但其主值为 0）。
