定积分的高级应用：几何与物理的微元重构

定积分真正的威力在于它的“微元法”（元素法）。任何一个能够被无限分割，且每一微小部分的贡献可以线性叠加的物理或几何量，都可以用定积分来精确计算。本章将对标《数学分析》Ch 10，深入探讨如何建立积分模型，并给出严格的微元推导。

微元法 (Differential Element Method) 核心思想

步骤：

  1. 分割：选取积分变量 x∈[a,b]x \in [a, b]x∈[a,b]，将区间无限细分。
  2. 近似：在微小区间 [x,x+dx][x, x+dx][x,x+dx] 上，将目标量的变化量 ΔQ\Delta QΔQ 近似为关于 dxdxdx 的线性项 dQ=f(x)dxdQ = f(x)dxdQ=f(x)dx（即微分）。
  3. 求和与极限：将所有微元累加并取极限，即得到积分式 Q=∫abf(x)dxQ = \int_a^b f(x) dxQ=∫ab​f(x)dx。

一、 几何应用模型与推导​

1. 旋转体的体积 (Volume of Revolution)​

(1) 圆盘法 (Disk Method) - 绕 xxx 轴​

推导：考虑由曲线 y=f(x)y = f(x)y=f(x)，xxx 轴及直线 x=a,x=bx=a, x=bx=a,x=b 围成的曲边梯形绕 xxx 轴旋转。 在 [x,x+dx][x, x+dx][x,x+dx] 处，取一垂直于 xxx 轴的薄片，其旋转后近似为一个底圆半径为 y=f(x)y=f(x)y=f(x)，厚度为 dxdxdx 的圆柱体。 其体积微元为： dV=π[f(x)]2dxdV = \pi [f(x)]^2 dxdV=π[f(x)]2dx 总公式：Vx=π∫abf2(x)dxV_x = \pi \int_a^b f^2(x) dxVx​=π∫ab​f2(x)dx

(2) 柱壳法 (Shell Method) - 绕 yyy 轴​

2. 平面曲线的弧长 (Arc Length)​

推导：设曲线方程为 y=f(x)y = f(x)y=f(x)。在 [x,x+dx][x, x+dx][x,x+dx] 上的弧段 Δs\Delta sΔs 可用线段长度近似。 由勾股定理： Δs≈(Δx)2+(Δy)2=1+(ΔyΔx)2Δx\Delta s \approx \sqrt{(\Delta x)^2 + (\Delta y)^2} = \sqrt{1 + \left(\frac{\Delta y}{\Delta x}\right)^2} \Delta xΔs≈(Δx)2+(Δy)2​=1+(ΔxΔy​)2​Δx 取极限得到弧长微元： ds=1+[f′(x)]2dxds = \sqrt{1 + [f'(x)]^2} dxds=1+[f′(x)]2​dx 总公式：L=∫ab1+[f′(x)]2dxL = \int_a^b \sqrt{1 + [f'(x)]^2} dxL=∫ab​1+[f′(x)]2​dx

3. 旋转曲面的侧面积 (Surface Area)​

推导：曲线 y=f(x)y=f(x)y=f(x) 绕 xxx 轴旋转所得曲面的侧面积。 在 [x,x+dx][x, x+dx][x,x+dx] 处，圆周长为 2πf(x)2\pi f(x)2πf(x)，对应的侧向宽度为弧长微元 dsdsds。 其面积微元（近似为圆台侧面积）为： dS=2πf(x)ds=2πf(x)1+[f′(x)]2dxdS = 2\pi f(x) ds = 2\pi f(x) \sqrt{1 + [f'(x)]^2} dxdS=2πf(x)ds=2πf(x)1+[f′(x)]2​dx 总公式：A=2π∫abf(x)1+[f′(x)]2dxA = 2\pi \int_a^b f(x) \sqrt{1 + [f'(x)]^2} dxA=2π∫ab​f(x)1+[f′(x)]2​dx

求半径为 RRR 的圆 x2+y2=R2x^2 + y^2 = R^2x2+y2=R2 绕 xxx 轴旋转一周所得球面的表面积。

解析过程​

  1. 参数化：取上半圆 y=R2−x2y = \sqrt{R^2 - x^2}y=R2−x2​，x∈[−R,R]x \in [-R, R]x∈[−R,R]。
  2. 计算导数：y′=−xR2−x2y' = \frac{-x}{\sqrt{R^2 - x^2}}y′=R2−x2​−x​。

  4. 建立积分： A=2π∫−RRyds=2π∫−RRR2−x2⋅RR2−x2dxA = 2\pi \int_{-R}^R y ds = 2\pi \int_{-R}^R \sqrt{R^2-x^2} \cdot \frac{R}{\sqrt{R^2-x^2}} dxA=2π∫−RR​yds=2π∫−RR​R2−x2​⋅R2−x2​R​dx

练习 3：引力叠加——环形对质点的引力​

一匀质细圆环，半径为 RRR，质量为 MMM。在圆环轴线上距离中心 hhh 处有一质量为 mmm 的质点。求圆环对该质点的引力。

解析过程​

  1. 对称性分析：由于圆环的对称性，质点受到的垂直于轴线方向的力相互抵消，合力沿轴线方向。
  2. 建立微元：在圆环上取质量为 dMdMdM 的小段。它与质点的距离为 r=R2+h2r = \sqrt{R^2 + h^2}r=R2+h2​。
  3. 分力计算：该段对质点的引力为 dF′=GmdMr2dF' = G\frac{m dM}{r^2}dF′=Gr2mdM​。 沿轴线的分力为 dF=dF′cos⁡αdF = dF' \cos \alphadF=dF′cosα，其中 cos⁡α=hr=hR2+h2\cos \alpha = \frac{h}{r} = \frac{h}{\sqrt{R^2+h^2}}cosα=rh​=R2+h2​h​。
