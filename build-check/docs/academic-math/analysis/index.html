数学分析 (Mathematical Analysis)

数学分析是以实数作为研究对象，以极限作为核心工具，研究函数的一门数学分支。它是近代数学的基础，也是计算机科学（算法复杂度分析、信号处理、机器学习、图形学）的灵魂。

本知识库严格对标 华东师范大学《数学分析》第五版 的教学大纲，旨在为零基础学习者提供最严密、最直观、最具工业感的学习路径。

📘 上册：一元微积分与实数理论 (Volume 1)​

第一部分：极限与连续 (Chapters 1-4)​

  • 第一章 实数集与函数：确界原理、阿基米德性质、函数基本性质。
  • 第二章 数列极限：ϵ−N\epsilon-Nϵ−N 定义、单调有界原理、Cauchy 收敛准则。
  • 第三章 函数极限：ϵ−δ\epsilon-\deltaϵ−δ 定义、等价无穷小、洛必达法则。
  • 第四章 函数的连续性：连续性概念、闭区间连续函数性质。

第二部分：微分学 (Chapters 5-7)​

  • 第五章 导数与微分：导数定义、求导法则、高阶导数。
  • 第六章 微分中值定理及其应用：Rolle 定理、Lagrange 定理、Taylor 公式。
    • (续) 凸函数、不等式与极值应用：Jensen 不等式、Young/Hölder 不等式证明。
  • 第七章 实数的完备性：七大等价定理（闭区间套、聚点、有限覆盖等）。

第三部分：积分学 (Chapters 8-11)​

  • 第八章 不定积分：换元法、分部积分法、有理函数积分。
  • 第九章 定积分：Riemann 积分定义、微积分基本定理 (FTC)。
  • 第十章 定积分的应用：面积、体积、弧长、物理应用。
  • 第十一章 反常积分：无穷限积分、瑕积分、敛散性判别。

📙 下册：级数与多元微积分 (Volume 2)​

第四部分：级数理论 (Chapters 12-15)​

  • 第十二章 数项级数：正项级数判别法、交错级数。
  • 第十三章 函数列与函数项级数：一致收敛性、分析性质。
  • 第十四章 幂级数：收敛半径、Taylor 展开、解析性。
  • 第十五章 傅里叶级数：Fourier 展开、收敛定理、Parseval 等式。

第五部分：多元微积分 (Chapters 16-22)​

  • 第十六章 多元函数的极限与连续：二元极限、连续性。
  • 第十七章 多元函数微分学：全微分、偏导数、Taylor 公式。
    • (续) 空间曲线与曲面的微分几何：切向量、法向量、曲率与挠率。
  • 第十八章 隐函数定理及其应用：隐函数存在定理、Lagrange 乘数法。
  • 第十九章 含参量积分：含参量正常/反常积分、Beta/Gamma 函数。
  • 第二十章 重积分：二重/三重积分、变量替换、Jacobi 行列式。
  • 第二十一章 曲线积分：第一/二型曲线积分、Green 公式。
  • 第二十二章 曲面积分：第一/二型曲面积分、Gauss 公式、Stokes 公式。
  • 第二十三章 矢量分析与场论初步：Hamilton 算子、梯度、散度与旋度。

🚀 进阶与专题补充 (Supplements)​

为了满足更高阶的学习需求，本库额外提供了以下专题：

  • 分析学不等式全书：系统化梳理 Young, Hölder, Minkowski 等核心工具。
  • Riemann-Stieltjes 积分：Lebesgue 积分的序曲。
  • 常微分方程初步：动态系统的数学描述。
  • 无穷乘积：与级数并行的无限运算。
  • 点集拓扑进阶：从欧氏空间到抽象度量空间。

✍️ 练习与实战 (Exercises)​

每个章节末尾均关联了配套练习，你也可以直接进入 数学分析练习库 进行针对性强化。

学习建议：分析学的严密性需要通过大量的 ϵ\epsilonϵ 练习来磨练。建议在阅读理论时，务必亲手推导一遍核心定理的证明。
