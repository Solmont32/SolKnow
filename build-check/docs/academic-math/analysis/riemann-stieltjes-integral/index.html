Riemann-Stieltjes 积分

Riemann 积分虽然强大，但在处理离散与连续混合分布、或者函数在某些点处具有“阶跃”性质时显得捉襟见肘。Riemann-Stieltjes (R-S) 积分通过引入“控制函数” α(x)\alpha(x)α(x)，将积分从单纯的面积累加升华为一种更广义的测度累加。

一、 Riemann-Stieltjes 积分理论​

1. 定义​

设 f(x)f(x)f(x) 和 α(x)\alpha(x)α(x) 是定义在 [a,b][a, b][a,b] 上的有界函数。对于 [a,b][a, b][a,b] 的任一划分 P:a=x0<x1<⋯<xn=bP: a = x_0 < x_1 < \dots < x_n = bP:a=x0​<x1​<⋯<xn​=b，在每个小区间 [xi−1,xi][x_{i-1}, x_i][xi−1​,xi​] 上任取一点 ξi\xi_iξi​，作和式： S(P,f,α)=∑i=1nf(ξi)[α(xi)−α(xi−1)]S(P, f, \alpha) = \sum_{i=1}^n f(\xi_i) [\alpha(x_i) - \alpha(x_{i-1})]S(P,f,α)=∑i=1n​f(ξi​)[α(xi​)−α(xi−1​)] 若当划分的模 λ(P)→0\lambda(P) \to 0λ(P)→0 时，该和式的极限存在且与划分 PPP 及 ξi\xi_iξi​ 的选取无关，则称 fff 关于 α\alphaα 在 [a,b][a, b][a,b] 上是 Riemann-Stieltjes 可积的，记作 f∈R(α)f \in \mathcal{R}(\alpha)f∈R(α)，积分值为： ∫abf(x)dα(x)\int_a^b f(x) d\alpha(x)∫ab​f(x)dα(x)

2. 存在性条件 (Existence Conditions)​

R-S 积分的存在性比 Riemann 积分更为苛刻。核心定理如下：

  • 定理 1 (连续性与有界变差)：若 f∈C[a,b]f \in \mathcal{C}[a, b]f∈C[a,b]（连续）且 α∈BV[a,b]\alpha \in \mathcal{BV}[a, b]α∈BV[a,b]（有界变差，如单调函数），则 f∈R(α)f \in \mathcal{R}(\alpha)f∈R(α)。
  • 定理 2 (单调性)：若 f∈C[a,b]f \in \mathcal{C}[a, b]f∈C[a,b] 且 α\alphaα 在 [a,b][a, b][a,b] 上单调，则 f∈R(α)f \in \mathcal{R}(\alpha)f∈R(α)。
  • 定理 3 (不可积判定 - 同侧不连续)：若 fff 与 α\alphaα 在同一点 c∈[a,b]c \in [a, b]c∈[a,b] 处均不连续，且为同侧不连续（即在该点同时左不连续或同时右不连续），则 f∉R(α)f \notin \mathcal{R}(\alpha)f∈/R(α)。
    • 直观理解：若在跳跃点处两函数同时变动，和式 f(ξi)Δαif(\xi_i)\Delta \alpha_if(ξi​)Δαi​ 的值将取决于 ξi\xi_iξi​ 靠近跳跃点的哪一侧，导致极限不唯一。

3. 与 Riemann 积分的转换​

R-S 积分是 Riemann 积分的推广。在特定条件下可以相互转换：

  • 光滑转换：若 α(x)\alpha(x)α(x) 在 [a,b][a, b][a,b] 上具有连续导数 α′(x)\alpha'(x)α′(x)，则： ∫abf(x)dα(x)=∫abf(x)α′(x)dx\int_a^b f(x) d\alpha(x) = \int_a^b f(x) \alpha'(x) dx∫ab​f(x)dα(x)=∫ab​f(x)α′(x)dx
  • 分部积分公式：若 ∫abfdα\int_a^b f d\alpha∫ab​fdα 存在，则 ∫abαdf\int_a^b \alpha df∫ab​αdf 也存在，且： ∫abfdα+∫abαdf=f(b)α(b)−f(a)α(a)\int_a^b f d\alpha + \int_a^b \alpha df = f(b)\alpha(b) - f(a)\alpha(a)∫ab​fdα+∫ab​αdf=f(b)α(b)−f(a)α(a) 这在处理 fff 较复杂而 α\alphaα 较简单（如阶梯函数）的情况时非常有用。

二、 阶梯函数积分与物理、概率直观​

当 α(x)\alpha(x)α(x) 是阶梯函数时，R-S 积分呈现出极其简洁的离散形式。

1. 物理与概率直观​

  • 物理意义：若 f(x)f(x)f(x) 为单位长度的力，α(x)\alpha(x)α(x) 为位移，则积分表示功。若 α(x)\alpha(x)α(x) 在某些点有跳跃，则表示在该点有力做了瞬时功。
  • 概率意义 (核心)：若 α(x)\alpha(x)α(x) 是随机变量 XXX 的累积分布函数 (CDF)，记为 F(x)F(x)F(x)，则 ∫g(x)dF(x)\int g(x) dF(x)∫g(x)dF(x) 即为 g(X)g(X)g(X) 的期望 E[g(X)]E[g(X)]E[g(X)]。这完美统一了离散型（FFF 为阶梯函数）和连续型（FFF 可导）随机变量的期望表达。

2. 阶梯函数计算准则​

设 α(x)\alpha(x)α(x) 是阶梯函数，在点 ck∈(a,b)c_k \in (a, b)ck​∈(a,b) 处有跳跃 sk=α(ck+)−α(ck−)s_k = \alpha(c_k^+) - \alpha(c_k^-)sk​=α(ck+​)−α(ck−​)，则： ∫abfdα=∑kf(ck)sk\int_a^b f d\alpha = \sum_k f(c_k) s_k∫ab​fdα=∑k​f(ck​)sk​ （需注意端点处的跳跃处理）。

三、 概率论中的深度应用：统一期望理论​

在初等概率论中，离散型随机变量的期望用求和表示，连续型用 Riemann 积分表示。R-S 积分则通过分布函数 F(x)F(x)F(x) 将二者完美统一，尤其在处理混合型随机变量时展现出不可替代的优越性。

1. 混合型随机变量的期望计算​

混合型随机变量既有连续的概率密度，又在某些点处有概率质量（跳跃点）。其期望公式为： E[g(X)]=∫−∞+∞g(x)dF(x)=∫x∈Contg(x)F′(x)dx+∑kg(xk)ΔF(xk)E[g(X)] = \int_{-\infty}^{+\infty} g(x) dF(x) = \int_{x \in \text{Cont}} g(x) F'(x) dx + \sum_{k} g(x_k) \Delta F(x_k)E[g(X)]=∫−∞+∞​g(x)dF(x)=∫x∈Cont​g(x)F′(x)dx+∑k​g(xk​)ΔF(xk​) 其中 ΔF(xk)=P(X=xk)\Delta F(x_k) = P(X = x_k)ΔF(xk​)=P(X=xk​) 是跳跃点处的概率。

2. 生存分析与精算应用​

在精算学中，剩余寿命 TTT 常被建模为混合型。例如，一个人在未来一年内死亡的概率由连续风险函数（密度的连续部分）描述，但如果在一年届满时还活着，则在“生存”这一时刻具有概率质量。
