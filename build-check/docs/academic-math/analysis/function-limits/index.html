函数极限：连续与突变的边界

如果说数列极限研究的是离散点集的终极趋势，那么函数极限则将我们的视野拉宽到了整个实数连续统。它是研究函数连续性、导数以及积分的先决条件。本章将以严密的逻辑和极具挑战性的实战，带你彻底征服函数极限。

一、 函数极限的严格定义论​

在高中阶段，我们习惯用“当 xxx 无限接近 x0x_0x0​ 时，f(x)f(x)f(x) 无限接近 AAA”来描述极限。但在高等数学中，这种描述过于模糊。我们需要 ϵ−δ\epsilon-\deltaϵ−δ 语言来将其量化。

1. ϵ−δ\epsilon-\deltaϵ−δ 定义（自变量趋于有限点）​

设函数 f(x)f(x)f(x) 在点 x0x_0x0​ 的某个去心邻域 U˚(x0,δ0)\mathring{U}(x_0, \delta_0)U˚(x0​,δ0​) 内有定义。如果存在常数 AAA，满足： 对于任意给定的实数 ϵ>0\epsilon > 0ϵ>0，都总存在一个实数 δ>0\delta > 0δ>0（通常 δ≤δ0\delta \le \delta_0δ≤δ0​），使得当满足不等式： 0<∣x−x0∣<δ0 < |x - x_0| < \delta0<∣x−x0​∣<δ 时，对应的函数值都满足不等式： ∣f(x)−A∣<ϵ|f(x) - A| < \epsilon∣f(x)−A∣<ϵ 则称常数 AAA 为函数 f(x)f(x)f(x) 当 x→x0x \to x_0x→x0​ 时的极限，记作 lim⁡x→x0f(x)=A\lim_{x \to x_0} f(x) = Alimx→x0​​f(x)=A。

哲学剖析：

  • “去心”（0<∣x−x0∣0 < |x - x_0|0<∣x−x0​∣）：极限考量的是函数在 x0x_0x0​ 周围的行为，与 f(x0)f(x_0)f(x0​) 在该点本身是否有定义、定义为何值毫无关系。这正是极限能够处理 00\frac{0}{0}00​ 型未定式的根本原因。
  • δ\deltaδ 依赖于 ϵ\epsilonϵ：你要将函数值限制在宽为 2ϵ2\epsilon2ϵ 的带状区域内，就必须在 xxx 轴上找到一个足够窄的宽为 2δ2\delta2δ 的控制区间。上面的可视化实验直观地展示了这种“你缩我也缩”的动态平衡。

2. ϵ−M\epsilon-Mϵ−M 定义（自变量趋于无穷大）​

若 ∀ϵ>0,∃M>0\forall \epsilon > 0, \exists M > 0∀ϵ>0,∃M>0，使得当 ∣x∣>M|x| > M∣x∣>M 时，恒有 ∣f(x)−A∣<ϵ|f(x) - A| < \epsilon∣f(x)−A∣<ϵ，则称 lim⁡x→∞f(x)=A\lim_{x \to \infty} f(x) = Alimx→∞​f(x)=A。

  • 左极限：x→x0−x \to x_0^-x→x0−​，即 x0−δ<x<x0x_0 - \delta < x < x_0x0​−δ<x<x0​。记作 f(x0−)f(x_0^-)f(x0−​)。

2. 洛必达法则 (L'Hôpital's Rule)​
