分析学不等式全书 (The Compendium of Analysis Inequalities)

不等式是分析学的灵魂。从极限的 ϵ−δ\epsilon-\deltaϵ−δ 定义到算子的有界性估计，分析学的本质往往在于“放大”与“缩小”的艺术。本专题系统化整合了分析学中最为核心的不等式理论，旨在为零基础学习者构建一套完整的估计工具箱。

1. 基础代数不等式 (Fundamental Algebraic Inequalities)​

1.1 Bernoulli 不等式​

对于任意 x>−1x > -1x>−1：

  1. 若 α≥1\alpha \ge 1α≥1 或 α≤0\alpha \le 0α≤0，则 (1+x)α≥1+αx(1+x)^\alpha \ge 1 + \alpha x(1+x)α≥1+αx；
  2. 若 0≤α≤10 \le \alpha \le 10≤α≤1，则 (1+x)α≤1+αx(1+x)^\alpha \le 1 + \alpha x(1+x)α≤1+αx。

等号成立当且仅当 x=0x=0x=0 或 α=0,1\alpha = 0, 1α=0,1。

1.2 平均值不等式 (AM-GM-HM)​

对于正实数 a1,a2,…,ana_1, a_2, \dots, a_na1​,a2​,…,an​：

n∑1ai≤∏ain≤∑ain≤∑ai2n\frac{n}{\sum \frac{1}{a_i}} \le \sqrt[n]{\prod a_i} \le \frac{\sum a_i}{n} \le \sqrt{\frac{\sum a_i^2}{n}}∑ai​1​n​≤n∏ai​​≤n∑ai​​≤n∑ai2​​​

即：调和平均 ≤\le≤ 几何平均 ≤\le≤ 算术平均 ≤\le≤ 平方平均。

2. 凸函数与 Jensen 不等式 (Convexity and Jensen's)​

2.1 凸性定义​

若函数 f:I→Rf: I \to \mathbb{R}f:I→R 对任意 x,y∈Ix, y \in Ix,y∈I 及 λ∈[0,1]\lambda \in [0, 1]λ∈[0,1] 满足：

f(λx+(1−λ)y)≤λf(x)+(1−λ)f(y)f(\lambda x + (1-\lambda)y) \le \lambda f(x) + (1-\lambda)f(y)f(λx+(1−λ)y)≤λf(x)+(1−λ)f(y)

则称 fff 为 III 上的凸函数（Convex Function）。

2.2 Jensen 不等式 (积分形式)​

若 ϕ\phiϕ 是凸函数，fff 是 [a,b][a, b][a,b] 上的可积函数，则：

ϕ(1b−a∫abf(x)dx)≤1b−a∫abϕ(f(x))dx\phi\left( \frac{1}{b-a} \int_a^b f(x) dx \right) \le \frac{1}{b-a} \int_a^b \phi(f(x)) dxϕ(b−a1​∫ab​f(x)dx)≤b−a1​∫ab​ϕ(f(x))dx

这是导出后续所有经典不等式的“母定理”。

3. 经典分析不等式 (Classical Analysis Inequalities)​

3.1 Young 不等式​

设 a,b≥0a, b \ge 0a,b≥0，p,q>1p, q > 1p,q>1 且满足共轭关系 1p+1q=1\frac{1}{p} + \frac{1}{q} = 1p1​+q1​=1，则：

ab≤app+bqqab \le \frac{a^p}{p} + \frac{b^q}{q}ab≤pap​+qbq​

3.2 Hölder 不等式​

设 f,gf, gf,g 为可积函数，p,qp, qp,q 为共轭指数，则：

∫ab∣f(x)g(x)∣dx≤(∫ab∣f(x)∣pdx)1/p(∫ab∣g(x)∣qdx)1/q\int_a^b |f(x)g(x)| dx \le \left( \int_a^b |f(x)|^p dx \right)^{1/p} \left( \int_a^b |g(x)|^q dx \right)^{1/q}∫ab​∣f(x)g(x)∣dx≤(∫ab​∣f(x)∣pdx)1/p(∫ab​∣g(x)∣qdx)1/q

特例：当 p=q=2p=q=2p=q=2 时，即为 Cauchy-Schwarz 不等式。

3.3 Minkowski 不等式 (三角不等式的 LpL^pLp 推广)​

对于 p≥1p \ge 1p≥1：

(∫∣f+g∣p)1/p≤(∫∣f∣p)1/p+(∫∣g∣p)1/p\left( \int |f+g|^p \right)^{1/p} \le \left( \int |f|^p \right)^{1/p} + \left( \int |g|^p \right)^{1/p}(∫∣f+g∣p)1/p≤(∫∣f∣p)1/p+(∫∣g∣p)1/p

这保证了 LpL^pLp 空间的范数满足三角不等式。
