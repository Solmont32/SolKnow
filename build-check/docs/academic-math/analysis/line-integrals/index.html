第二十一章 曲线积分

曲线积分是微积分学从区间走向空间的里程碑。它不仅是定积分的直接推广，更是描述力场做功、流体环量等物理现象的核心数学工具。本章将对标《数学分析》Ch 21，构建从定义、计算到格林公式的完整理论链条。

一、 第一类曲线积分：对弧长的积分​

1. 定义与几何直观​

设 LLL 为空间段光滑曲线，其长度为 sss。若 f(P)f(P)f(P) 是定义在 LLL 上的连续函数，则其对弧长的曲线积分为： ∫Lf(P)ds=lim⁡∥Δsi∥→0∑i=1nf(Pi)Δsi\int_L f(P) ds = \lim_{\|\Delta s_i\| \to 0} \sum_{i=1}^n f(P_i) \Delta s_i∫L​f(P)ds=lim∥Δsi​∥→0​∑i=1n​f(Pi​)Δsi​

  • 几何意义：若 f(P)≡1f(P) \equiv 1f(P)≡1，则积分等于曲线 LLL 的长度。
  • 物理意义：若 f(P)f(P)f(P) 为线密度，则积分为物体的总质量。
  • 独立性：第一类曲线积分与曲线的方向无关（其元素 dsdsds 始终为正）。

2. 计算法则​

若 LLL 由参数方程 r(t)=(x(t),y(t),z(t))\mathbf{r}(t) = (x(t), y(t), z(t))r(t)=(x(t),y(t),z(t)) (a≤t≤ba \le t \le ba≤t≤b) 给出： ∫Lf(x,y,z)ds=∫abf(x(t),y(t),z(t))x′2(t)+y′2(t)+z′2(t)dt\int_L f(x, y, z) ds = \int_a^b f(x(t), y(t), z(t)) \sqrt{x'^2(t) + y'^2(t) + z'^2(t)} dt∫L​f(x,y,z)ds=∫ab​f(x(t),y(t),z(t))x′2(t)+y′2(t)+z′2(t)​dt

二、 第二类曲线积分：对坐标的积分​

1. 物理背景：变力做功​

设向量场 F(P)=(P,Q,R)\mathbf{F}(P) = (P, Q, R)F(P)=(P,Q,R) 作用于沿有向曲线 LLL 运动的质点。则 F\mathbf{F}F 在微小位移 dr=(dx,dy,dz)d\mathbf{r} = (dx, dy, dz)dr=(dx,dy,dz) 上做的功为 dW=F⋅drdW = \mathbf{F} \cdot d\mathbf{r}dW=F⋅dr。总功即为： W=∫LF⋅dr=∫LPdx+Qdy+RdzW = \int_L \mathbf{F} \cdot d\mathbf{r} = \int_L P dx + Q dy + R dzW=∫L​F⋅dr=∫L​Pdx+Qdy+Rdz

2. 性质与计算​

  • 方向性：第二类曲线积分依赖于 LLL 的方向。若 Γ−\Gamma^-Γ− 为 Γ+\Gamma^+Γ+ 的反向曲线，则 ∫Γ−=−∫Γ+\int_{\Gamma^-} = -\int_{\Gamma^+}∫Γ−​=−∫Γ+​。
  • 计算公式：代入参数方程，将所有坐标及其微分化为参数 ttt 的函数： ∫LF⋅dr=∫ab[P(x(t),… )x′(t)+Q(x(t),… )y′(t)+R(x(t),… )z′(t)]dt\int_L \mathbf{F} \cdot d\mathbf{r} = \int_a^b [P(x(t), \dots)x'(t) + Q(x(t), \dots)y'(t) + R(x(t), \dots)z'(t)] dt∫L​F⋅dr=∫ab​[P(x(t),…)x′(t)+Q(x(t),…)y′(t)+R(x(t),…)z′(t)]dt

三、 格林公式与平面环量密度​

格林公式是平面微积分的灵魂，它揭示了“局部旋转”与“边界环流”之间的等价性。

1. 格林公式 (Green's Theorem)​

设 DDD 是平面闭区域，其边界 LLL 是正向分段光滑闭曲线。若 P,QP, QP,Q 在 DDD 上具有一阶连续偏导数，则： ∮LPdx+Qdy=∬D(∂Q∂x−∂P∂y)dA\oint_L P dx + Q dy = \iint_D \left( \frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y} \right) dA∮L​Pdx+Qdy=∬D​(∂x∂Q​−∂y∂P​)dA

2. 物理内涵：环量密度​

在流体力学中，∮LV⋅dr\oint_L \mathbf{V} \cdot d\mathbf{r}∮L​V⋅dr 称为流速场沿 LLL 的环量 (Circulation)。

  • 表达式 (∂Q∂x−∂P∂y)(\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y})(∂x∂Q​−∂y∂P​) 代表了场在点 (x,y)(x, y)(x,y) 处的旋转强度（即旋度的 zzz 分量）。
  • 格林公式直观理解：区域内所有微小单元产生的“旋转”在内部相互抵消，最终只剩下边界上的“宏观环流”。

例题 2：非单连通区域的路径无关性​

例题 4：保守场与势函数​

已知 F=(2xy+z2,x2+2yz,y2+2xz)\mathbf{F} = (2xy+z^2, x^2+2yz, y^2+2xz)F=(2xy+z2,x2+2yz,y2+2xz)，证明该场为保守场，并求从 A(0,0,0)A(0,0,0)A(0,0,0) 到 B(1,1,1)B(1,1,1)B(1,1,1) 的线积分。

解析过程
  1. 验证旋度：计算 curl F=(2y−2y,2z−2z,2x−2x)=(0,0,0)\text{curl } \mathbf{F} = (2y-2y, 2z-2z, 2x-2x) = (0,0,0)curl F=(2y−2y,2z−2z,2x−2x)=(0,0,0)。故 F\mathbf{F}F 是保守场。
  2. 求势函数 uuu：
    • ∂u∂x=2xy+z2  ⟹  u=x2y+xz2+ϕ(y,z)\frac{\partial u}{\partial x} = 2xy+z^2 \implies u = x^2y + xz^2 + \phi(y, z)∂x∂u​=2xy+z2⟹u=x2y+xz2+ϕ(y,z)。
    • ∂u∂y=x2+∂ϕ∂y=x2+2yz  ⟹  ϕ=y2z+ψ(z)\frac{\partial u}{\partial y} = x^2 + \frac{\partial \phi}{\partial y} = x^2 + 2yz \implies \phi = y^2z + \psi(z)∂y∂u​=x2+∂y∂ϕ​=x2+2yz⟹ϕ=y2z+ψ(z)。
    • ∂u∂z=2xz+y2+ψ′(z)=y2+2xz  ⟹  ψ′(z)=0\frac{\partial u}{\partial z} = 2xz + y^2 + \psi'(z) = y^2 + 2xz \implies \psi'(z) = 0∂z∂u​=2xz+y2+ψ′(z)=y2+2xz⟹ψ′(z)=0。
    • 取 u=x2y+y2z+z2xu = x^2y + y^2z + z^2xu=x2y+y2z+z2x。
  3. 计算积分：∫ABF⋅dr=u(1,1,1)−u(0,0,0)=1+1+1=3\int_A^B \mathbf{F} \cdot d\mathbf{r} = u(1,1,1) - u(0,0,0) = 1+1+1 = 3∫AB​F⋅dr=u(1,1,1)−u(0,0,0)=1+1+1=3。
