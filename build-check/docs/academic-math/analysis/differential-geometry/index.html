空间曲线与曲面的微分几何

微分几何是利用微积分的方法研究空间图形几何性质的一门学科。在数学分析中，我们主要关注其“初步”部分：即如何利用多元函数导数来描述曲线的弯曲、扭转以及曲面的切平性质。

一、 空间曲线的局部性质​

设空间曲线 CCC 的参数方程为 r(t)=(x(t),y(t),z(t))\mathbf{r}(t) = (x(t), y(t), z(t))r(t)=(x(t),y(t),z(t))，t∈[a,b]t \in [a, b]t∈[a,b]。

1. 切向量与切线 (Tangent)​

若 r(t)\mathbf{r}(t)r(t) 可微且 r′(t)≠0\mathbf{r}'(t) \neq \mathbf{0}r′(t)=0，则曲线在点 P(t)P(t)P(t) 处的切向量为： Tvec=r′(t)=(x′(t),y′(t),z′(t))\mathbf{T}_{vec} = \mathbf{r}'(t) = (x'(t), y'(t), z'(t))Tvec​=r′(t)=(x′(t),y′(t),z′(t)) 切线方程： X−x(t)x′(t)=Y−y(t)y′(t)=Z−z(t)z′(t)\frac{X - x(t)}{x'(t)} = \frac{Y - y(t)}{y'(t)} = \frac{Z - z(t)}{z'(t)}x′(t)X−x(t)​=y′(t)Y−y(t)​=z′(t)Z−z(t)​

2. 法平面 (Normal Plane)​

垂直于切线的平面称为法平面。其方程为： x′(t)(X−x(t))+y′(t)(Y−y(t))+z′(t)(Z−z(t))=0x'(t)(X - x(t)) + y'(t)(Y - y(t)) + z'(t)(Z - z(t)) = 0x′(t)(X−x(t))+y′(t)(Y−y(t))+z′(t)(Z−z(t))=0

3. 弧长参数 (Arc Length)​

弧长 s(t)=∫at∣r′(u)∣dus(t) = \int_{a}^t |\mathbf{r}'(u)| dus(t)=∫at​∣r′(u)∣du。当以弧长 sss 为参数时，∣r′(s)∣=1|\mathbf{r}'(s)| = 1∣r′(s)∣=1，这极大简化了理论推导。

二、 Frenet 标架与曲率、挠率​

对于非退化曲线（r′′≠0\mathbf{r}'' \neq \mathbf{0}r′′=0），我们在每一点可以建立一个正交规范标架 {T,N,B}\{\mathbf{T}, \mathbf{N}, \mathbf{B}\}{T,N,B}。

1. 三个单位向量​

  • 单位切向量：T=r′(t)∣r′(t)∣\mathbf{T} = \frac{\mathbf{r}'(t)}{|\mathbf{r}'(t)|}T=∣r′(t)∣r′(t)​
  • 单位副法向量：B=r′(t)×r′′(t)∣r′(t)×r′′(t)∣\mathbf{B} = \frac{\mathbf{r}'(t) \times \mathbf{r}''(t)}{|\mathbf{r}'(t) \times \mathbf{r}''(t)|}B=∣r′(t)×r′′(t)∣r′(t)×r′′(t)​
  • 单位主法向量：N=B×T\mathbf{N} = \mathbf{B} \times \mathbf{T}N=B×T

2. 曲率 (Curvature) κ\kappaκ​

定义：描述曲线偏离直线的程度（切线方向的变化率）。 计算公式： κ=∣r′(t)×r′′(t)∣∣r′(t)∣3\kappa = \frac{|\mathbf{r}'(t) \times \mathbf{r}''(t)|}{|\mathbf{r}'(t)|^3}κ=∣r′(t)∣3∣r′(t)×r′′(t)∣​ 几何意义：κ\kappaκ 越大，曲线在该点弯曲得越厉害。曲率半径 R=1/κR = 1/\kappaR=1/κ。

3. 挠率 (Torsion) τ\tauτ​

定义：描述曲线偏离平面的程度（副法向量方向的变化率）。 计算公式： τ=(r′(t),r′′(t),r′′′(t))∣r′(t)×r′′(t)∣2\tau = \frac{(\mathbf{r}'(t), \mathbf{r}''(t), \mathbf{r}'''(t))}{|\mathbf{r}'(t) \times \mathbf{r}''(t)|^2}τ=∣r′(t)×r′′(t)∣2(r′(t),r′′(t),r′′′(t))​ 其中 (r′,r′′,r′′′)(\mathbf{r}', \mathbf{r}'', \mathbf{r}''')(r′,r′′,r′′′) 为向量的混合积。 几何意义：

  • τ=0  ⟺  \tau = 0 \iffτ=0⟺ 曲线为平面曲线。
  • τ>0\tau > 0τ>0 表示曲线呈“右手螺旋”状上升。

解析过程​

  1. 求各阶导数： r′=(−asin⁡t,acos⁡t,b)\mathbf{r}' = (-a \sin t, a \cos t, b)r′=(−asint,acost,b) r′′=(−acos⁡t,−asin⁡t,0)\mathbf{r}'' = (-a \cos t, -a \sin t, 0)r′′=(−acost,−asint,0) r′′′=(asin⁡t,−acos⁡t,0)\mathbf{r}''' = (a \sin t, -a \cos t, 0)r′′′=(asint,−acost,0)

  2. 计算模长与外积： ∣r′∣=a2sin⁡2t+a2cos⁡2t+b2=a2+b2|\mathbf{r}'| = \sqrt{a^2 \sin^2 t + a^2 \cos^2 t + b^2} = \sqrt{a^2 + b^2}∣r′∣=a2sin2t+a2cos2t+b2​=a2+b2​ r′×r′′=∣ijk−asin⁡tacos⁡tb−acos⁡t−asin⁡t0∣=(absin⁡t,−abcos⁡t,a2)\mathbf{r}' \times \mathbf{r}'' = \begin{vmatrix} \mathbf{i} & \mathbf{j} & \mathbf{k} \\ -a \sin t & a \cos t & b \\ -a \cos t & -a \sin t & 0 \end{vmatrix} = (ab \sin t, -ab \cos t, a^2)r′×r′′=​i−asint−acost​jacost−asint​kb0​​=(absint,−abcost,a2) ∣r′×r′′∣=a2b2sin⁡2t+a2b2cos⁡2t+a4=aa2+b2|\mathbf{r}' \times \mathbf{r}''| = \sqrt{a^2b^2 \sin^2 t + a^2b^2 \cos^2 t + a^4} = a\sqrt{a^2 + b^2}∣r′×r′′∣=a2b2sin2t+a2b2cos2t+a4​=aa2+b2​

  3. 计算曲率： κ=aa2+b2(a2+b2)3=aa2+b2\kappa = \frac{a\sqrt{a^2 + b^2}}{(\sqrt{a^2 + b^2})^3} = \frac{a}{a^2 + b^2}κ=(a2+b2​)3aa2+b2​​=a2+b2a​

  4. 计算挠率： 混合积 (r′,r′′,r′′′)=(r′×r′′)⋅r′′′(\mathbf{r}', \mathbf{r}'', \mathbf{r}''') = (\mathbf{r}' \times \mathbf{r}'') \cdot \mathbf{r}'''(r′,r′′,r′′′)=(r′×r′′)⋅r′′′ =(absin⁡t)(asin⁡t)+(−abcos⁡t)(−acos⁡t)+(a2)(0)=a2b= (ab \sin t)(a \sin t) + (-ab \cos t)(-a \cos t) + (a^2)(0) = a^2b=(absint)(asint)+(−abcost)(−acost)+(a2)(0)=a2b τ=a2b(aa2+b2)2=ba2+b2\tau = \frac{a^2b}{(a\sqrt{a^2 + b^2})^2} = \frac{b}{a^2 + b^2}τ=(aa2+b2​)2a2b​=a2+b2b​

结论​

圆柱螺旋线的曲率与挠率均为常数。这说明它是空间中均匀弯曲且均匀扭转的曲线。
