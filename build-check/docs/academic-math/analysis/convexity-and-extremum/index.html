凸函数、不等式与极值应用：分析学的几何灵魂

在微分学中，如果说导数刻画了函数的“速度”，那么凸性（Convexity）则刻画了函数的“趋势”。凸函数理论不仅是数学分析的核心，更是现代最优化理论、概率论与信息论的基石。本专题对标华东师大版《数学分析》第六章，深度系统化凸函数理论及其在不等式证明中的威力。

一、 凸函数的严密定义​

1. 几何定义与 Jensen 形式​

设 f(x)f(x)f(x) 为定义在区间 III 上的函数。若对 ∀x1,x2∈I\forall x_1, x_2 \in I∀x1​,x2​∈I 及 ∀λ∈(0,1)\forall \lambda \in (0, 1)∀λ∈(0,1)，恒有： f(λx1+(1−λ)x2)≤λf(x1)+(1−λ)f(x2)f(\lambda x_1 + (1-\lambda)x_2) \le \lambda f(x_1) + (1-\lambda)f(x_2)f(λx1​+(1−λ)x2​)≤λf(x1​)+(1−λ)f(x2​) 则称 f(x)f(x)f(x) 为 III 上的凸函数 (Convex Function)。

注意：华氏教材中，上述定义对应“下凸”，部分教材（如物理或老版教材）可能称之为“凹”。在本系统中，我们统一采用现代数学术语：开口向上为凸。

2. Jensen 不等式（离散形式）​

若 f(x)f(x)f(x) 是区间 III 上的凸函数，则对于 ∀xi∈I\forall x_i \in I∀xi​∈I 及 ∀λi>0\forall \lambda_i > 0∀λi​>0 且 ∑i=1nλi=1\sum_{i=1}^n \lambda_i = 1∑i=1n​λi​=1，恒有： f(∑i=1nλixi)≤∑i=1nλif(xi)f\left(\sum_{i=1}^n \lambda_i x_i\right) \le \sum_{i=1}^n \lambda_i f(x_i)f(∑i=1n​λi​xi​)≤∑i=1n​λi​f(xi​) 这是凸函数最本质的特征，也是推导所有分析学经典不等式的“母机”。

二、 凸性的判别法​

1. 一阶导数判别法（切线特征）​

设 f(x)f(x)f(x) 在 III 上可导，则 f(x)f(x)f(x) 为凸函数的充要条件是： f(y)≥f(x)+f′(x)(y−x),∀x,y∈If(y) \ge f(x) + f'(x)(y-x), \quad \forall x, y \in If(y)≥f(x)+f′(x)(y−x),∀x,y∈I 几何直观：凸函数的图像始终位于其任意一点切线的上方。

2. 二阶导数判别法（曲率特征）​

设 f(x)f(x)f(x) 在 III 上二阶可导，则：

  • f(x)f(x)f(x) 是凸函数的充要条件是 f′′(x)≥0f''(x) \ge 0f′′(x)≥0 对 ∀x∈I\forall x \in I∀x∈I 成立。
  • 若 f′′(x)>0f''(x) > 0f′′(x)>0，则 f(x)f(x)f(x) 是严格凸函数。

三、 核心不等式的推导：凸性之美​

利用凸函数理论（特别是 Jensen 不等式），我们可以优雅地推导分析学的三大支柱不等式。

1. Young 不等式​

设 p,q>1p, q > 1p,q>1 且 1p+1q=1\frac{1}{p} + \frac{1}{q} = 1p1​+q1​=1。对 ∀a,b>0\forall a, b > 0∀a,b>0，有： ab≤app+bqqab \le \frac{a^p}{p} + \frac{b^q}{q}ab≤pap​+qbq​ 证明概要：利用 ln⁡x\ln xlnx 的凹性（即 −ln⁡x-\ln x−lnx 的凸性）。 取 f(x)=−ln⁡xf(x) = -\ln xf(x)=−lnx，由 Jensen 不等式： −ln⁡(1pap+1qbq)≤1p(−ln⁡ap)+1q(−ln⁡bq)=−ln⁡(ab)-\ln(\frac{1}{p}a^p + \frac{1}{q}b^q) \le \frac{1}{p}(-\ln a^p) + \frac{1}{q}(-\ln b^q) = -\ln(ab)−ln(p1​ap+q1​bq)≤p1​(−lnap)+q1​(−lnbq)=−ln(ab) 两边取指数即得。

2. Hölder 不等式​

设 p,q>1,1p+1q=1p, q > 1, \frac{1}{p} + \frac{1}{q} = 1p,q>1,p1​+q1​=1。对数项 ai,bi≥0a_i, b_i \ge 0ai​,bi​≥0，有： ∑i=1naibi≤(∑i=1naip)1/p(∑i=1nbiq)1/q\sum_{i=1}^n a_i b_i \le \left(\sum_{i=1}^n a_i^p\right)^{1/p} \left(\sum_{i=1}^n b_i^q\right)^{1/q}∑i=1n​ai​bi​≤(∑i=1n​aip​)1/p(∑i=1n​biq​)1/q 这是 Cauchy-Schwarz 不等式（p=q=2p=q=2p=q=2 时）的广义形式。

3. Minkowski 不等式​

设 p≥1p \ge 1p≥1，则： (∑i=1n(ai+bi)p)1/p≤(∑i=1naip)1/p+(∑i=1nbip)1/p\left(\sum_{i=1}^n (a_i + b_i)^p\right)^{1/p} \le \left(\sum_{i=1}^n a_i^p\right)^{1/p} + \left(\sum_{i=1}^n b_i^p\right)^{1/p}(∑i=1n​(ai​+bi​)p)1/p≤(∑i=1n​aip​)1/p+(∑i=1n​bip​)1/p 其几何意义是 LpL^pLp 空间下的三角不等式。

四、 极值与最优化应用​

凸性提供了全局最优化的保证：

  1. 局部即全局：凸函数在凸集上的局部极小值即为全局最小值。
  2. 极值点判定：
    • 一阶必要条件：若 f(x)f(x)f(x) 可导且在 x0x_0x0​ 取得极值，则 f′(x0)=0f'(x_0) = 0f′(x0​)=0。
    • 二阶充分条件：若 f′(x0)=0f'(x_0) = 0f′(x0​)=0 且 f′′(x0)>0f''(x_0) > 0f′′(x0​)>0，则 x0x_0x0​ 为极小值点。
