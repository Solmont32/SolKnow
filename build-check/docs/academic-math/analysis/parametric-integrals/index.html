第十九章 含参量积分

在数学分析中，当我们考虑的积分不仅依赖于积分变量，还依赖于一个或多个参数时，就引入了含参量积分。它是研究特殊函数（如 Gamma、Beta 函数）、解决微分方程以及进行复杂积分计算的有力工具。

一、 含参量常义积分 (Proper Parametric Integrals)​

设函数 f(x,y)f(x, y)f(x,y) 定义在矩形区域 R=[a,b]×[c,d]R = [a, b] \times [c, d]R=[a,b]×[c,d] 上。称 I(y)=∫abf(x,y)dx,y∈[c,d]I(y) = \int_a^b f(x, y) dx, \quad y \in [c, d]I(y)=∫ab​f(x,y)dx,y∈[c,d] 为由 f(x,y)f(x, y)f(x,y) 确定的含参量常义积分。

1. 分析性质​

若 f(x,y)f(x, y)f(x,y) 在 RRR 上连续，则有：

  • 连续性：I(y)I(y)I(y) 在 [c,d][c, d][c,d] 上连续。
  • 可积性：I(y)I(y)I(y) 在 [c,d][c, d][c,d] 上可积，且积分顺序可以交换： ∫cdI(y)dy=∫cd(∫abf(x,y)dx)dy=∫ab(∫cdf(x,y)dy)dx\int_c^d I(y) dy = \int_c^d \left( \int_a^b f(x, y) dx \right) dy = \int_a^b \left( \int_c^d f(x, y) dy \right) dx∫cd​I(y)dy=∫cd​(∫ab​f(x,y)dx)dy=∫ab​(∫cd​f(x,y)dy)dx

二、 含参量反常积分的一致收敛性 (Uniform Convergence)​

设 f(x,y)f(x, y)f(x,y) 定义在 a≤x<+∞,c≤y≤da \le x < +\infty, c \le y \le da≤x<+∞,c≤y≤d 上。若对每个固定的 yyy，反常积分 ∫a+∞f(x,y)dx\int_a^{+\infty} f(x, y) dx∫a+∞​f(x,y)dx 都收敛，则定义了含参量反常积分： I(y)=∫a+∞f(x,y)dxI(y) = \int_a^{+\infty} f(x, y) dxI(y)=∫a+∞​f(x,y)dx

    1. ∫a+∞f(x,y)dx\int_a^{+\infty} f(x, y) dx∫a+∞​f(x,y)dx 在 [c,d][c, d][c,d] 上一致收敛；

三、 Beta 函数与 Gamma 函数 (Beta and Gamma Functions)​

1. Gamma 函数 (The Gamma Function)​

严格定义：对于 s>0s > 0s>0，Γ(s)=∫0+∞xs−1e−xdx\Gamma(s) = \int_0^{+\infty} x^{s-1} e^{-x} dxΓ(s)=∫0+∞​xs−1e−xdx。该积分在 (0,+∞)(0, +\infty)(0,+∞) 的任何闭子区间上一致收敛。

进阶性质：

  • 递推性质：Γ(s+1)=sΓ(s)\Gamma(s+1) = s\Gamma(s)Γ(s+1)=sΓ(s)，且 Γ(n+1)=n!\Gamma(n+1) = n!Γ(n+1)=n!。
  • 余元公式 (Reflection Formula)：Γ(s)Γ(1−s)=πsin⁡(πs)(0<s<1)\Gamma(s)\Gamma(1-s) = \frac{\pi}{\sin(\pi s)} \quad (0 < s < 1)Γ(s)Γ(1−s)=sin(πs)π​(0<s<1)。
  • 倍元公式 (Duplication Formula)：Γ(2s)=22s−1πΓ(s)Γ(s+12)\Gamma(2s) = \frac{2^{2s-1}}{\sqrt{\pi}} \Gamma(s)\Gamma(s+\frac{1}{2})Γ(2s)=π​22s−1​Γ(s)Γ(s+21​)。
  • Stirling 公式 (渐近展开)：当 x→+∞x \to +\inftyx→+∞ 时，Γ(x+1)∼2πx(xe)x\Gamma(x+1) \sim \sqrt{2\pi x} (\frac{x}{e})^xΓ(x+1)∼2πx​(ex​)x。

2. Beta 函数 (The Beta Function)​

严格定义：对于 p>0,q>0p > 0, q > 0p>0,q>0，B(p,q)=∫01xp−1(1−x)q−1dxB(p, q) = \int_0^1 x^{p-1} (1-x)^{q-1} dxB(p,q)=∫01​xp−1(1−x)q−1dx。

不同表达形式：

  • 三角形式：B(p,q)=2∫0π/2sin⁡2p−1θcos⁡2q−1θdθB(p, q) = 2 \int_0^{\pi/2} \sin^{2p-1} \theta \cos^{2q-1} \theta d\thetaB(p,q)=2∫0π/2​sin2p−1θcos2q−1θdθ。
  • 无穷限形式：B(p,q)=∫0+∞yp−1(1+y)p+qdyB(p, q) = \int_0^{+\infty} \frac{y^{p-1}}{(1+y)^{p+q}} dyB(p,q)=∫0+∞​(1+y)p+qyp−1​dy。

3. 两者的纽带​

B(p,q)=Γ(p)Γ(q)Γ(p+q)B(p, q) = \frac{\Gamma(p)\Gamma(q)}{\Gamma(p+q)}B(p,q)=Γ(p+q)Γ(p)Γ(q)​ 利用此公式，可将大量三角积分和分式反常积分转化为 Gamma 函数计算。
