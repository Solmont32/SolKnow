第十四章 幂级数 (Power Series)

幂级数是函数项级数中最重要、性质最完整的一类。它不仅是研究解析函数的工具，也是将复杂函数转化为代数多项式处理的核心手段。

1. 收敛半径与收敛域 (Convergence)​

形如 ∑n=0∞an(x−x0)n\sum_{n=0}^\infty a_n (x - x_0)^n∑n=0∞​an​(x−x0​)n 的级数称为 幂级数。通常取 x0=0x_0 = 0x0​=0 进行讨论。

1.1 Cauchy-Hadamard 定理​

对于任意幂级数 ∑anxn\sum a_n x^n∑an​xn，其收敛性由唯一的 收敛半径 RRR 决定：

  • 若 ∣x∣<R|x| < R∣x∣<R，级数绝对收敛；
  • 若 ∣x∣>R|x| > R∣x∣>R，级数发散；
  • 若 ∣x∣=R|x| = R∣x∣=R，敛散性不确定，需单独分析。
收敛半径计算公式
  1. Cauchy-Hadamard 公式： 1R=lim sup⁡n→∞∣an∣n\frac{1}{R} = \limsup_{n \to \infty} \sqrt[n]{|a_n|}R1​=limsupn→∞​n∣an​∣​
  2. 比值判别法 (常用)： R=lim⁡n→∞∣anan+1∣(前提是极限存在或为 ∞)R = \lim_{n \to \infty} \left| \frac{a_n}{a_{n+1}} \right| \quad (\text{前提是极限存在或为 } \infty)R=limn→∞​​an+1​an​​​(前提是极限存在或为 ∞)

1.2 缺项与特殊幂级数​

对于缺项幂级数（如 ∑anx2n\sum a_n x^{2n}∑an​x2n）或复合形式 ∑an[g(x)]n\sum a_n [g(x)]^n∑an​[g(x)]n，建议直接使用 根值判别法或比值判别法 对整体项 un(x)u_n(x)un​(x) 进行敛散性判定，而非死套 RRR 的公式。

2. 幂级数的一致收敛性与分析性质​

2.1 Abel 第一定理​

定理：若幂级数 ∑anxn\sum a_n x^n∑an​xn 在 x=x1≠0x = x_1 \neq 0x=x1​=0 处收敛，则对于满足 ∣x∣<∣x1∣|x| < |x_1|∣x∣<∣x1​∣ 的所有 xxx，该级数绝对收敛。

推论：幂级数在收敛区间 (−R,R)( -R, R )(−R,R) 内的任何闭子区间 [a,b]⊂(−R,R)[a, b] \subset (-R, R)[a,b]⊂(−R,R) 上均 一致收敛。

2.2 和函数的解析性质​

在收敛区间 (−R,R)(-R, R)(−R,R) 内，和函数 S(x)=∑n=0∞anxnS(x) = \sum_{n=0}^\infty a_n x^nS(x)=∑n=0∞​an​xn 具有极好的性质：

  1. 连续性：S(x)S(x)S(x) 在 (−R,R)(-R, R)(−R,R) 内连续。
  2. 逐项求导：S′(x)=∑n=1∞nanxn−1S'(x) = \sum_{n=1}^\infty n a_n x^{n-1}S′(x)=∑n=1∞​nan​xn−1。求导后的级数与原级数具有相同的收敛半径。
  3. 逐项积分：∫0xS(t)dt=∑n=0∞ann+1xn+1\int_0^x S(t) dt = \sum_{n=0}^\infty \frac{a_n}{n+1} x^{n+1}∫0x​S(t)dt=∑n=0∞​n+1an​​xn+1。积分后的级数与原级数具有相同的收敛半径。
技巧：求和函数的核心策略
  1. 微分法 (处理分子项 nnn)：若项中含有 nnn 或 nkn^knk，考虑通过对低阶级数求导来“产生”这些项。

Abel 第二定理 (边界收敛性与左连续性)

定理内容：设幂级数 ∑n=0∞anxn\sum_{n=0}^\infty a_n x^n∑n=0∞​an​xn 的收敛半径为 R>0R > 0R>0。若该级数在右端点 x=Rx=Rx=R 处收敛，则级数在闭区间 [0,R][0, R][0,R] 上一致收敛。 由此可得，其和函数 S(x)S(x)S(x) 在 x=Rx=Rx=R 处是 左连续 的，即： lim⁡x→R−∑n=0∞anxn=∑n=0∞anRn\lim_{x \to R^-} \sum_{n=0}^\infty a_n x^n = \sum_{n=0}^\infty a_n R^nlimx→R−​∑n=0∞​an​xn=∑n=0∞​an​Rn (同理，若在 x=−Rx=-Rx=−R 处收敛，则在 [−R,0][-R, 0][−R,0] 上一致收敛且在该点右连续。)

2.3 Abel 第二定理的深度理解​

  1. 核心价值：该定理建立了“幂级数在开区间内的分析性质”与“边界处项级数的收敛性”之间的桥梁。它允许我们通过取极限的方式计算数项级数的和。
  2. 证明思路 (Abel 变换)：利用分部求和法（Abel 变换），将级数的部分和表示为与边界收敛项相关的形式，结合控制收敛的技巧证明一致收敛。
  3. 注意项：若级数在 x=Rx=Rx=R 处 发散，则和函数 S(x)S(x)S(x) 当 x→R−x \to R^-x→R− 时必然趋于无穷（Frobenius 定理的逆性质）。
