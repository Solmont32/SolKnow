第一章 实数集与函数：数学分析的基石

零基础视角：如果数学是一座大厦，实数系就是地基。没有实数的“连续性”，极限和导数将失去意义。本章将从严格的公理化视角，重新审视我们在初等数学中习以为常的数集与映射。

1. 核心理论：确界原理 (The Supremum Principle)​

实数系与有理数系最本质的区别在于完备性（即没有“缝隙”）。确界原理是描述这种完备性的核心命题。

1.1 定义与基本性质​

设 SSS 为一个非空数集。

  • 上确界 (Supremum)：若数 β\betaβ 满足：
    1. 对任意 x∈Sx \in Sx∈S，有 x≤βx \leq \betax≤β（β\betaβ 是上界）。
    2. 对任意 ϵ>0\epsilon > 0ϵ>0，存在 x0∈Sx_0 \in Sx0​∈S，使得 x0>β−ϵx_0 > \beta - \epsilonx0​>β−ϵ（β\betaβ 是最小上界）。 记作 β=sup⁡S\beta = \sup Sβ=supS。
  • 下确界 (Infimum)：同理定义 α=inf⁡S\alpha = \inf Sα=infS。

1.2 确界存在定理的严格证明 (Strict Proof)​

定理 (确界存在定理)

非空有上界的数集必有上确界。

证明思路 (基于戴德金分割公理)： 设 SSS 是非空有上界的数集。我们构造一个实数集的分割 (A,B)(A, B)(A,B)：

  1. 令 B={y∈R∣y 是 S 的一个上界}B = \{ y \in \mathbb{R} \mid y \text{ 是 } S \text{ 的一个上界} \}B={y∈R∣y 是 S 的一个上界}。由于 SSS 有上界，故 B≠∅B \neq \emptysetB=∅。
  2. 令 A={x∈R∣x 不是 S 的上界}A = \{ x \in \mathbb{R} \mid x \text{ 不是 } S \text{ 的上界} \}A={x∈R∣x 不是 S 的上界}。由于 SSS 非空，取 s∈Ss \in Ss∈S，则 s−1∈As-1 \in As−1∈A，故 A≠∅A \neq \emptysetA=∅。
  3. 易证 A∪B=RA \cup B = \mathbb{R}A∪B=R 且对任意 a∈A,b∈Ba \in A, b \in Ba∈A,b∈B 有 a<ba < ba<b。

根据 戴德金定理，存在唯一的实数 ξ\xiξ，使得对任意 a∈A,b∈Ba \in A, b \in Ba∈A,b∈B，有 a≤ξ≤ba \leq \xi \leq ba≤ξ≤b。

  • 验证 ξ\xiξ 是上确界：
    • 对任意 s∈Ss \in Ss∈S，由于 sss 的任何上界 bbb 满足 s≤bs \leq bs≤b，根据 ξ\xiξ 的定义，ξ\xiξ 是 BBB 的下界，即 ξ≤b\xi \leq bξ≤b。实际上可以证明 ξ\xiξ 也是 SSS 的一个上界（若存在 s0>ξs_0 > \xis0​>ξ，则可在 (ξ,s0)(\xi, s_0)(ξ,s0​) 中取一数 a∈Aa \in Aa∈A，产生矛盾）。
    • 对任意 ϵ>0\epsilon > 0ϵ>0，ξ−ϵ<ξ\xi - \epsilon < \xiξ−ϵ<ξ，故 ξ−ϵ∈A\xi - \epsilon \in Aξ−ϵ∈A。根据 AAA 的定义，ξ−ϵ\xi - \epsilonξ−ϵ 不是 SSS 的上界，即存在 x0∈Sx_0 \in Sx0​∈S 使得 x0>ξ−ϵx_0 > \xi - \epsilonx0​>ξ−ϵ。

2. 复合函数：分解、判定与应用​

在复杂系统的建模中，函数往往不是单一的，而是多个环节的嵌套。

2.1 复合的判定准则​

设 y=f(u),u=g(x)y = f(u), u = g(x)y=f(u),u=g(x)。要使复合函数 f∘gf \circ gf∘g 有意义，必须满足： ggg 的值域 RgR_gRg​ 与 fff 的定义域 DfD_fDf​ 的交集非空，即 Rg∩Df≠∅R_g \cap D_f \neq \emptysetRg​∩Df​=∅。

将复杂函数分解为初等函数，是求导、求极限的第一步。 例：y=ln⁡(sin⁡x)y = \sqrt{\ln(\sin x)}y=ln(sinx)​

  1. y=uy = \sqrt{u}y=u​
  2. u=ln⁡vu = \ln vu=lnv
  3. v=sin⁡xv = \sin xv=sinx 判定：需满足 sin⁡x>0\sin x > 0sinx>0（使 ln⁡v\ln vlnv 有意义）且 ln⁡(sin⁡x)≥0\ln(\sin x) \geq 0ln(sinx)≥0（使 u\sqrt{u}u​ 有意义）。

3. 反函数：存在性与严格单调性​

3.1 存在性定理​

若函数 f:D→Rf: D \to Rf:D→R 是严格单调的，则 fff 必存在反函数 f−1:R→Df^{-1}: R \to Df−1:R→D，且 f−1f^{-1}f−1 在其定义域上也是严格单调的。

3.2 实战例题：超越函数的反函数​

例：证明 f(x)=x+exf(x) = x + e^xf(x)=x+ex 在 R\mathbb{R}R 上存在反函数。 解析：

  1. 单调性检查：由于 f′(x)=1+ex>0f'(x) = 1 + e^x > 0f′(x)=1+ex>0，函数在 R\mathbb{R}R 上严格单调递增。
  2. 值域检查：当 x→−∞x \to -\inftyx→−∞ 时，f(x)→−∞f(x) \to -\inftyf(x)→−∞；当 x→+∞x \to +\inftyx→+∞ 时，f(x)→+∞f(x) \to +\inftyf(x)→+∞。故 Rf=RR_f = \mathbb{R}Rf​=R。
  3. 结论：反函数 f−1f^{-1}f−1 存在且定义域为 R\mathbb{R}R。
