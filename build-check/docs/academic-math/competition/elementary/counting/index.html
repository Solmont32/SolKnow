奥数计数与组合：逻辑与秩序的艺术

组合板块研究的是“有多少种可能”，核心在于分类要 “不重不漏”。

一、 核心知识点讲解​

1. 两大基本原理​

  • 加法原理（分类计数）：完成一件事有 nnn 类办法，每一类办法都能独立完成这件事。总数 = 每一类方法数之 和。
  • 乘法原理（分步计数）：完成一件事需要分 nnn 个步骤，缺一不可。总数 = 每一步方法数之 积。

2. 排列与组合初步​

  • 排列：与顺序有关。从 nnn 个不同元素中取出 mmm 个排成一列。
  • 组合：与顺序无关。从 nnn 个不同元素中取出 mmm 个合成一组。

3. 抽屉原理 (Pigeonhole Principle)​

  • 基本形式：把 n+1n+1n+1 个苹果放进 nnn 个抽屉，至少有一个抽屉里至少有 222 个苹果。
  • 一般形式：把 kn+1kn+1kn+1 个苹果放进 nnn 个抽屉，至少有一个抽屉里至少有 k+1k+1k+1 个苹果。

4. 容斥原理​

  • 用于解决有重叠部分的计数问题。
  • 两个集合：A∪B=A+B−A∩BA \cup B = A + B - A \cap BA∪B=A+B−A∩B。
计数口诀

先分类，再分步； 重复的，要减去； 遗漏的，要加上。

二、 经典例题实战​

例题 1：乘法原理的灵活应用​

用 0,1,2,30, 1, 2, 30,1,2,3 这四个数字，可以组成多少个没有重复数字的三位数？

点击查看解析与答案

解析过程​

  1. 分步思考：组成三位数需要选定“百位”、“十位”和“个位”。
  2. 第一步（百位）：由于最高位不能为 000，只能从 1,2,31, 2, 31,2,3 中选，有 333 种 选择。
  3. 第二步（十位）：从剩下的 333 个数字（包含 000）中选，有 333 种 选择。
  4. 第三步（个位）：从剩下的 222 个数字中选，有 222 种 选择。
  5. 计算总数：根据乘法原理，3×3×2=183 \times 3 \times 2 = 183×3×2=18。

答案​

181818 个。

例题 2：抽屉原理的构造​

口袋里有红、黄、蓝、白四种颜色的球各 101010 个。至少要摸出多少个球，才能保证有 333 个球的颜色相同？

点击查看解析与答案

解析过程​

  1. 寻找“最坏情况”：为了“不保证”，我们要尽可能让每种颜色的球都摸得很多但又达不到 333 个。
  2. 构造最差状态：每种颜色的球都摸出了 222 个。
    • 红：222 个
    • 黄：222 个
    • 蓝：222 个
    • 白：222 个
    • 此时共摸出了 2×4=82 \times 4 = 82×4=8 个球，依然没有 333 个同色的。
  3. 达成目标：再摸出 111 个 球，无论是什么颜色，都会使某种颜色的球达到 333 个。
  4. 最终数量：8+1=98 + 1 = 98+1=9。

答案​

999 个。

例题 3：插板法（高阶计数）​

将 777 个相同的玩具分给 333 个小朋友，每人至少分到一个，共有多少种分法？

点击查看解析与答案

解析过程​

  1. 模型转化：将 777 个玩具排成一排，中间形成了 666 个空隙。
  2. 放置“隔板”：我们要把玩具分成 333 份，只需要在 666 个空隙中插入 222 块 隔板即可。
  3. 组合计算：即从 666 个位置中选出 222 个，方法数为 C(6,2)C(6, 2)C(6,2)。
  4. 计算结果：(6×5)÷2=15(6 \times 5) \div 2 = 15(6×5)÷2=15。

答案​

151515 种。
