奥数几何：面积模型与比例之美

几何问题的核心在于“转换”：将不规则图形转化为规则图形，将长度关系转化为面积比例。

一、 核心知识点讲解​

1. 等底同高模型​

  • 两个三角形如果 底相等、高相等，则它们的面积一定相等。
  • 推论：若两个三角形高相等，则面积之比等于底之比。

2. 蝴蝶模型​

在梯形（或任意四边形）中，对角线交点形成的四个三角形：

  • 左右对称：S△AOD=S△BOCS_{\triangle AOD} = S_{\triangle BOC}S△AOD​=S△BOC​（仅限梯形）。
  • 乘积关系：S1×S3=S2×S4S_1 \times S_3 = S_2 \times S_4S1​×S3​=S2​×S4​（任意四边形均成立）。

3. 燕尾模型​

在一个大三角形 ABCABCABC 中，从顶点出发的三条线段交于一点 OOO，形成的侧翼三角形与底边比例关系：

  • S△ABO:S△ACO=BD:DCS_{\triangle ABO} : S_{\triangle ACO} = BD : DCS△ABO​:S△ACO​=BD:DC。

4. 圆与扇形​

  • 圆面积：S=πr2S = \pi r^2S=πr2。
  • 扇形面积：S=n360πr2S = \frac{n}{360} \pi r^2S=360n​πr2。
  • 解题思想：割补法、容斥法（红领巾模型、叶形模型）。
解题秘籍

看到“中点”找等积变换；看到“平行线”找同高三角形；看到“对角线”找蝴蝶模型。

二、 经典例题实战​

例题 1：蝴蝶模型的综合计算​

已知梯形 ABCDABCDABCD 的上底 AB∥AB \parallelAB∥ 下底 CDCDCD。对角线交于点 OOO。若 △AOB\triangle AOB△AOB 面积为 444 平方厘米，△BOC\triangle BOC△BOC 面积为 888 平方厘米。求梯形 ABCDABCDABCD 的总面积。

解析过程​

  1. 利用梯形特性：在梯形中，对角线分出的两侧三角形面积相等。故 S△AOD=S△BOC=8S_{\triangle AOD} = S_{\triangle BOC} = 8S△AOD​=S△BOC​=8。
  2. 应用蝴蝶模型比例：S△AOB×S△COD=S△AOD×S△BOCS_{\triangle AOB} \times S_{\triangle COD} = S_{\triangle AOD} \times S_{\triangle BOC}S△AOB​×S△COD​=S△AOD​×S△BOC​。
  3. 代入计算：4×S△COD=8×84 \times S_{\triangle COD} = 8 \times 84×S△COD​=8×8。
    • 4×S△COD=644 \times S_{\triangle COD} = 644×S△COD​=64。
    • S△COD=16S_{\triangle COD} = 16S△COD​=16。
  4. 汇总全图面积：S=4+8+8+16=36S = 4 + 8 + 8 + 16 = 36S=4+8+8+16=36。

答案​

363636 平方厘米。

例题 2：燕尾模型求底边比​

在 △ABC\triangle ABC△ABC 中，点 DDD 在 BCBCBC 上，OOO 为 △ABC\triangle ABC△ABC 内一点。已知 S△ABO=15S_{\triangle ABO} = 15S△ABO​=15，S△ACO=10S_{\triangle ACO} = 10S△ACO​=10。求 BD:DCBD : DCBD:DC 的值。

点击查看解析与答案

解析过程​

  1. 模型识别：这是一个典型的燕尾模型场景。
  2. 套用结论：燕尾定理指出，顶点连线两侧的三角形面积比等于底边的分段比。
  3. 比例计算：BD:DC=S△ABO:S△ACOBD : DC = S_{\triangle ABO} : S_{\triangle ACO}BD:DC=S△ABO​:S△ACO​。
  4. 化简：15:10=3:215 : 10 = 3 : 215:10=3:2。

答案​

3:23 : 23:2。

例题 3：割补法求阴影面积​

在一个边长为 101010 厘米的正方形内，以各边为直径向内作半圆。求中心交叠形成的“花瓣形”（四叶草）阴影部分的面积。

点击查看解析与答案

解析过程​

  1. 容斥原理视角：四个半圆的面积之和，覆盖了整个正方形区域，且中心的“花瓣”部分被重复计算了多次。
  2. 计算四个半圆总面积：每个半圆半径 r=5r = 5r=5。总面积 = 4×(12π×52)=2π×25=50π4 \times (\frac{1}{2} \pi \times 5^2) = 2 \pi \times 25 = 50\pi4×(21​π×52)=2π×25=50π。
  3. 计算正方形面积：10×10=10010 \times 10 = 10010×10=100。
  4. 差异分析：四个半圆覆盖的面积 =正方形+重复的花瓣部分= \text{正方形} + \text{重复的花瓣部分}=正方形+重复的花瓣部分。
  5. 结果：花瓣面积 =50π−100≈50×3.14−100=157−100=57= 50\pi - 100 \approx 50 \times 3.14 - 100 = 157 - 100 = 57=50π−100≈50×3.14−100=157−100=57。

答案​

50π−10050\pi - 10050π−100（约为 575757 平方厘米）。
