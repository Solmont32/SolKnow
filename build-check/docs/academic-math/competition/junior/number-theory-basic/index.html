竞赛数论：整除、同余与不定方程

初中数竞数论是研究整数结构的起点，重点在于对同余系的深刻理解。

一、 核心知识点讲解​

1. 唯一分解定理与约数​

  • 每一个大于 1 的整数都能唯一分解为质数的乘积。
  • 约数个数定理：若 n=p1a1p2a2…n = p_1^{a_1} p_2^{a_2} \dotsn=p1a1​​p2a2​​…，则约数个数为 ∏(ai+1)\prod (a_i + 1)∏(ai​+1)。

2. 同余的高阶性质​

  • 费马小定理：若 ppp 为质数，则 ap≡a(modp)a^p \equiv a \pmod pap≡a(modp)。
  • 裴蜀定理 (Bézout's Identity)：关于 x,yx, yx,y 的方程 ax+by=cax + by = cax+by=c 有整数解当且仅当 gcd(a,b)∣cgcd(a, b) | cgcd(a,b)∣c。

3. 不定方程​

  • 一次不定方程：利用辗转相除法（欧几里得算法）求解。
  • 勾股方程：x2+y2=z2x^2 + y^2 = z^2x2+y2=z2 的整数解形式。
重要提醒

在处理大指数同余问题时，优先考虑 欧拉定理 或寻找 同余周期。

二、 经典例题实战​

例题 1：裴蜀定理的证明与应用​

例题 2：约数个数的反向构造​
