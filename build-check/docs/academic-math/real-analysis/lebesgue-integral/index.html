Lebesgue 积分：测度论视野下的现代积分理论

“黎曼积分是将函数定义域切碎，而勒贝格积分是将函数的值域切碎。” —— 亨利·勒贝格 (Henri Lebesgue)

黎曼积分（Riemann Integral）虽然在微积分初期取得了辉煌成就，但其局限性也日益明显：它无法处理像 Dirichlet 函数（有理数点为 1，无理数点为 0）这样处处不连续的函数，且在函数项级数的极限号与积分号交换问题上限制极其苛刻。勒贝格积分通过引入测度论，彻底革新了积分的概念。

一、 为什么要建立 Lebesgue 积分？​

1. Riemann 积分的局限性​

Riemann 积分要求函数必须是“几乎处处连续”的。对于复杂的点集（如 Cantor 集或有理数集），Riemann 积分往往束手无策。

  • 反例：Dirichlet 函数 D(x)=χQ(x)D(x) = \chi_{\mathbb{Q}}(x)D(x)=χQ​(x)。 在任何区间内，D(x)D(x)D(x) 的上和总为 1，下和总为 0，因此 Riemann 不可积。但直觉上，有理数集是“稀疏”的，其积分应该为 0。

2. 极限理论的缺失​

在 Riemann 积分框架下，若 fn→ff_n \to ffn​→f 且 fnf_nfn​ 可积，推导 lim⁡∫fn=∫f\lim \int f_n = \int flim∫fn​=∫f 需要极其强的条件（如一致收敛）。但在许多物理和工程问题中，我们只能得到逐点收敛。

二、 Lebesgue 积分的定义步骤​

勒贝格积分的建立遵循“由易到难”的阶梯式路径：简单函数 →\to→ 非负可测函数 →\to→ 一般可测函数。

1. 简单函数的积分​

设 EEE 是可测集，称函数 ϕ(x)\phi(x)ϕ(x) 为简单函数，若其值域仅包含有限个实数值 {a1,a2,…,an}\{a_1, a_2, \dots, a_n\}{a1​,a2​,…,an​}。它可以写成： ϕ(x)=∑i=1naiχEi(x)\phi(x) = \sum_{i=1}^n a_i \chi_{E_i}(x)ϕ(x)=∑i=1n​ai​χEi​​(x) 其中 Ei={x∈E∣ϕ(x)=ai}E_i = \{x \in E \mid \phi(x) = a_i\}Ei​={x∈E∣ϕ(x)=ai​}。 定义：ϕ(x)\phi(x)ϕ(x) 在 EEE 上的 Lebesgue 积分为： ∫Eϕ(x)dx=∑i=1naim(Ei)\int_E \phi(x) dx = \sum_{i=1}^n a_i m(E_i)∫E​ϕ(x)dx=∑i=1n​ai​m(Ei​) 注：这里 m(Ei)m(E_i)m(Ei​) 为 Lebesgue 测度。若某个 ai=0a_i = 0ai​=0 且 m(Ei)=∞m(E_i) = \inftym(Ei​)=∞，约定 0⋅∞=00 \cdot \infty = 00⋅∞=0。

2. 非负可测函数的积分​

对于一般的非负可测函数 f(x)≥0f(x) \ge 0f(x)≥0，利用简单函数序列逼近的思想： 定义： ∫Ef(x)dx=sup⁡{∫Eϕ(x)dx∣0≤ϕ≤f,ϕ 为简单函数}\int_E f(x) dx = \sup \left\{ \int_E \phi(x) dx \mid 0 \le \phi \le f, \phi \text{ 为简单函数} \right\}∫E​f(x)dx=sup{∫E​ϕ(x)dx∣0≤ϕ≤f,ϕ 为简单函数} 如果此上确界有限，称 fff 在 EEE 上 Lebesgue 可积。

3. 一般可测函数的积分​

对于任意可测函数 f(x)f(x)f(x)，定义其正部 f+(x)=max⁡{f(x),0}f^+(x) = \max\{f(x), 0\}f+(x)=max{f(x),0} 和负部 f−(x)=max⁡{−f(x),0}f^-(x) = \max\{-f(x), 0\}f−(x)=max{−f(x),0}。 显然 f=f+−f−f = f^+ - f^-f=f+−f− 且 ∣f∣=f++f−|f| = f^+ + f^-∣f∣=f++f−。 定义：若 ∫Ef+dx\int_E f^+ dx∫E​f+dx 和 ∫Ef−dx\int_E f^- dx∫E​f−dx 中至少有一个有限，则定义： ∫Efdx=∫Ef+dx−∫Ef−dx\int_E f dx = \int_E f^+ dx - \int_E f^- dx∫E​fdx=∫E​f+dx−∫E​f−dx 若两者皆有限，则称 fff 在 EEE 上可积（或绝对可积）。

三、 三大核心收敛定理（深度解析）​

这是勒贝格积分理论最耀眼的皇冠，也是解决极限与积分交换问题的终极武器。

定理 1：单调收敛定理 (Monotone Convergence Theorem, MCT)

设 {fn}\{f_n\}{fn​} 是 EEE 上的非负可测函数序列，且单调不减，即 0≤f1≤f2≤⋯≤fn≤…0 \le f_1 \le f_2 \le \dots \le f_n \le \dots0≤f1​≤f2​≤⋯≤fn​≤…。 若 lim⁡n→∞fn(x)=f(x)\lim_{n \to \infty} f_n(x) = f(x)limn→∞​fn​(x)=f(x) 几乎处处成立，则： lim⁡n→∞∫Efndx=∫Efdx\lim_{n \to \infty} \int_E f_n dx = \int_E f dxlimn→∞​∫E​fn​dx=∫E​fdx

证明要点： 由于 fn≤ff_n \le ffn​≤f，显然 lim⁡∫fn≤∫f\lim \int f_n \le \int flim∫fn​≤∫f。 反向不等式证明较为微妙：对于任何满足 0≤ϕ≤f0 \le \phi \le f0≤ϕ≤f 的简单函数 ϕ\phiϕ 和常数 c∈(0,1)c \in (0, 1)c∈(0,1)，定义集合 En={x∈E∣fn(x)≥cϕ(x)}E_n = \{x \in E \mid f_n(x) \ge c\phi(x)\}En​={x∈E∣fn​(x)≥cϕ(x)}。由于 fnf_nfn​ 单调增，EnE_nEn​ 也是单调增的集列且 ∪En=E\cup E_n = E∪En​=E。 利用测度的连续性，可证 lim⁡∫fn≥∫Enfn≥c∫Enϕ\lim \int f_n \ge \int_{E_n} f_n \ge c \int_{E_n} \philim∫fn​≥∫En​​fn​≥c∫En​​ϕ。令 n→∞n \to \inftyn→∞，得到 lim⁡∫fn≥c∫Eϕ\lim \int f_n \ge c \int_E \philim∫fn​≥c∫E​ϕ。 最后令 c→1c \to 1c→1 且对所有 ϕ\phiϕ 取上确界，即证。

定理 2：法图引理 (Fatou's Lemma)

设 {fn}\{f_n\}{fn​} 是 EEE 上的非负可测函数序列，则： ∫Elim inf⁡n→∞fndx≤lim inf⁡n→∞∫Efndx\int_E \liminf_{n \to \infty} f_n dx \le \liminf_{n \to \infty} \int_E f_n dx∫E​liminfn→∞​fn​dx≤liminfn→∞​∫E​fn​dx

直观理解： 积分的下极限不会超过下极限的积分。它是单调收敛定理的直接推论（考虑 gn=inf⁡k≥nfkg_n = \inf_{k \ge n} f_kgn​=infk≥n​fk​ 构成的单调增序列）。

定理 3：勒贝格受控收敛定理 (Dominated Convergence Theorem, DCT)

设 {fn}\{f_n\}{fn​} 是可测函数序列，满足：

  1. lim⁡n→∞fn(x)=f(x)\lim_{n \to \infty} f_n(x) = f(x)limn→∞​fn​(x)=f(x) 几乎处处成立。
  2. 存在一个可积函数 G(x)G(x)G(x)（称为控制函数），使得对于所有 nnn，满足 ∣fn(x)∣≤G(x)|f_n(x)| \le G(x)∣fn​(x)∣≤G(x) 几乎处处成立。 则 fff 可积，且： lim⁡n→∞∫Efndx=∫Efdx\lim_{n \to \infty} \int_E f_n dx = \int_E f dxlimn→∞​∫E​fn​dx=∫E​fdx

证明路径： 由于 G±fn≥0G \pm f_n \ge 0G±fn​≥0，直接对这两个非负序列应用法图引理即可。 这是实际应用中最频繁使用的定理，因为它只需找到一个“盖住”所有项的可积函数。

计算 ∫01D(x)dx\int_0^1 D(x) dx∫01​D(x)dx，其中 D(x)=χQ(x)D(x) = \chi_{\mathbb{Q}}(x)D(x)=χQ​(x)。

五、 Lebesgue 积分与 Riemann 积分的关系​

  1. 若 Riemann 可积，则 Lebesgue 必可积，且积分值相等。
  2. Riemann 不可积，Lebesgue 可能可积（如 Dirichlet 函数）。
  3. 广义 Riemann 积分与 Lebesgue 积分不完全等价：
    • 如果广义积分是绝对收敛的，则两者一致。
    • 如果是条件收敛（如 ∫0∞sin⁡xxdx\int_0^\infty \frac{\sin x}{x} dx∫0∞​xsinx​dx），则它在 Lebesgue 意义下不可积，因为 Lebesgue 要求绝对可积 ∫∣f∣<∞\int |f| < \infty∫∣f∣<∞。

六、 总结与进阶建议​

Lebesgue 积分不仅是纯数学的基石，在概率论（期望即积分）、调和分析、量子力学等领域有着不可替代的作用。掌握它的关键在于：

  • 跳出“切分 xxx 轴”的思维定势。
  • 熟练运用三大收敛定理，这是考试和科研中最强大的工具。
  • 关注“几乎处处” (a.e.) 概念，理解测度零集如何影响积分。
