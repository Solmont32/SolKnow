行列式 (Determinant)

行列式是一个将方阵映射为标量的函数，反映了线性变换对“体积”的缩放。

基本性质​

  1. 转置不变：∣A∣=∣AT∣|A| = |A^T|∣A∣=∣AT∣。
  2. 两行互换：行列式变号。
  3. 单行倍乘：行列式随之倍乘。
  4. 单行倍加：将一行的 kkk 倍加到另一行，值不变。
计算技巧

对于阶数较高的行列式，优先通过初等行变换将其转化为 上三角行列式，此时值等于对角线元素之积。
